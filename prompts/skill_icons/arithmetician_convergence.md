# 前提

算術士の立ち絵を参照画像として一緒に入力する。立ち絵はキャラクターデザインの確認にのみ使用し、構図・ポーズ・背景はプロンプトへ持ち込まない。

# プロンプト

```text
ゲーム用スキルアイコンの前景ロゴを作成してください。

テーマは「最適解への収束」です。

添付画像の算術士のキャラクターデザインを参照し、博士帽、暗色の長髪、紺のローブ、細身の杖などの主要な識別要素だけをアイコンへ反映してください。添付画像の構図、ポーズ、背景、画面レイアウトは使用しないでください。

算術士を正面向き、真正面から見た左右対称に近い構図で中央へ配置してください。博士帽、暗色の長髪、紺のローブ、細身の杖など、算術士だと分かる主要な識別要素を簡略化して残してください。斜め向き、横向き、背面、強い遠近感、動きのある斜め構図は禁止です。

正面を向いた算術士の身体が、中心へ収束するように幾何学的な断片へ分解され、静かに消えていく瞬間を表現してください。人物の上半身または全身を中央に配置し、身体の片側、ローブの裾、杖の一部が小さな幾何学片へ変化し、中央または上方向へ吸い込まれているようにしてください。

「正面向きの人物」「透明化」「最適解への収束」が一目で伝わる、シンプルで知的な魔導ロゴにしてください。透明な人物そのものを描くのではなく、金色のシルエットが部分的に欠け、幾何学的に分解されていく形で表現してください。

ロゴの色は算術士のアクセントカラーである金色 #E6B072 の単色のみ。色のグラデーション、複数色、半透明による色分けは禁止。背景は完全な透明。RGBA透過PNG向け。

正方形キャンバスの中央に配置し、人物と分解片が外周や四隅へ広がりすぎないようにしてください。180×180px程度に縮小しても、正面の人物が消えていくことを判別できる太く明快なシルエットにしてください。

背景、背景装飾、風景、文字、具体的な数式、数字、ひし形フレーム、キー番号、クールダウン表示、煙、霧、過度な発光、複雑な魔法陣は含めないでください。
```
