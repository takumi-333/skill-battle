# キャラクターアセット制作

## 目的

プロジェクトの仕様に合ったキャラクター画像素材を作る。

## 参照先と責任

- キャラクター個別の外見とゲーム上の要件は `docs/specs/キャラクター設定.md` を確認する。
- 共通の世界観・アート方針は `docs/specs/世界観・アートディレクション.md` を確認する。
- スプライト素材は `docs/guides/8方向スプライト素材作成ガイドライン/` を参照する

## 手順
1. まずユーザの要求を理解する
2. ガイドラインを読み込む
3. 方向性の確認のためタスクの概要をユーザに確認する。（認識のずれ防止）
4. ガイドラインに沿って進める
