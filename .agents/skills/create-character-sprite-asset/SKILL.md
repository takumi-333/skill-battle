# キャラクターアセット制作

## 目的

さまざまなキャラクターのスプライト画像素材を作成する。

## 基本的な方針

- ゲームでは一貫性が非常に重要となるため各キャラクターアセット間での矛盾・不整合は致命的となる
- 立ち絵がそのキャラクターの正の姿であるため、立ち絵が存在した場合はその立ち絵との不整合がないようにする（assets/characters/portraitsに格納されている）

## 参照先と責任

- キャラクター個別の外見とゲーム上の要件は `docs/specs/キャラクター設定.md` を確認する。
- 共通の世界観・アート方針は `docs/specs/世界観・アートディレクション.md` を確認する。
- スプライト素材の作成方法・ノウハウは `docs/guides/スプライト素材作成ガイドライン/` を参照する

## 手順

具体的にはガイドラインを参照する。概略を以下に示す。

1. ユーザの依頼をもとに企画書を作成する。ユーザが承認するまでは次のステップに進まず、企画書のブラッシュアップを行う。
2. 企画書をもとに仕様書を作成する。一通り作成したら、ユーザにRVしてもらい、承認をもらえたら次のステップに進む。
3. 基準となるキーフレームを作成する。まず１枚だけ作成して、ユーザにRVしてもらい、承認をもらえたら次のステップに進む。
4. キーフレームをもとに代表の動作パターンを1通り作成（１パターンしかないなら全量）。こちらはツールを使って、ユーザが実際の動作を確認できるようにしたうえで、RVを依頼する。承認をもらえたら次のステップに進む。
5. 全量作成し、各ツールで組版・検査・採用まで行う。
6. ユーザが一通りの動作をRVする。
