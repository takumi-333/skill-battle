# キャラクターアセット制作

## 目的

プロジェクトの仕様に合ったキャラクター画像素材を作る。

## 参照先と責任

- 個別の外見とゲーム上の要件は `docs/specs/キャラクター設定.md` を確認する。
- 共通の世界観・アート方針は `docs/specs/世界観・アートディレクション.md` を確認する。
- ファイル形式、生成方法、正規化、検査、配置の詳細は `docs/guides/キャラクターアセット制作ガイド.md` を唯一の正とする。

このスキルは、依頼の入口と制作時の判断を扱う。制作手順や数値仕様をここへ重複して記載しない。

## 着手時

依頼されたキャラクターと素材の範囲を確認する。仕様からデザイン契約をまとめ、必要な要素が未確定なら固定せず確認する。

既存のゲーム用スプライトが採用済みなら、頭身・輪郭・配色・セル内での占有率を確認し、新素材がゲーム上で浮かないようにする。ただし、既存画像が仕様に反する場合は基準にしない。

制作と検査はガイドに従う。ゲーム表示への組み込みも依頼された場合は、既存の表示コードとガイドの両方を確認して整合させる。
