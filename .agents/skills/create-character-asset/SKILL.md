# キャラクターアセット制作

## 目的

このプロジェクト用に、1キャラクター分の立ち絵と対戦用8方向スプライトを一貫したデザインで作成する。仕様の正は `docs/specs/キャラクター設定.md`、制作・検査方法の正は `docs/guides/キャラクターアセット制作ガイド.md` とする。

## 着手前

必ず上記2ファイルを読み、対象キャラクターについて次をデザイン契約として抽出する。

- モチーフと、それを表す性格・雰囲気
- テーマカラー（メイン・アクセント）
- 髪、帽子・眼鏡、衣装のシルエット、固定小物
- 年齢層・体格・性別などの固定要素
- 禁止事項

キャラクターIDまたはデザイン契約に必要な項目が仕様で未確定なら、勝手に固定せずユーザーへ確認する。既存キャラクターを更新する場合も、仕様に反する既存画像を基準にしない。

## 制作手順

1. 対象IDとデザイン契約をユーザーに簡潔に共有する。
2. まず立ち絵を生成する。全身・右向き3/4立ち・正方形・透過RGBA・背景なしのアニメ調ファンタジーイラストとし、`assets/characters/<id>_idle.png` に配置する。
3. 立ち絵を確認し、デザイン契約と透過・全身構図を満たさなければ修正または再生成する。
4. 同じデザイン契約を明記して、8方向・停止1行＋歩行4行のスプライトシートを生成する。立ち絵だけを参照に任せず、髪・衣装・小物・配色をプロンプトへ文字で含める。
5. シートを8列×5行に分割できる素材から、各セルを縦横比を保つ最近傍補間で64×64pxへ正規化し、足元をセル下端に揃える。最終結果を透過RGBA・512×320pxで `assets/characters/<id>_pixel_8dir.png` に配置する。
6. 最終画像を目視・寸法検査し、問題があれば修正する。隣接セルへのはみ出し、孤立した切れ端、方向やフレームの欠落は、切り貼りでごまかさず、必要に応じて余白を指定して再生成する。

## 立ち絵の必須条件

- 1人だけの全身立ち絵、右向きの3/4立ち姿、正方形キャンバス
- 透過RGBA背景のみ。地面、影、背景、文字、ロゴ、透かし、枠は含めない
- おおむね1254×1254pxのアニメ調ファンタジーゲーム向けイラスト
- 武器など、デザイン契約にない目立つ要素を追加しない

## スプライトの必須条件

- 512×320pxの透過RGBA PNG。64×64pxセルを8列×5行、合計40フレーム
- 列順は `下 / 下左 / 左 / 上左 / 上 / 上右 / 右 / 下右`
- 行順は `停止 / 歩行1 / 歩行2 / 歩行3 / 歩行4`。歩行は接地・中間・逆接地・中間のループ
- 3/4トップダウン視点で、頭頂・肩・足元を見せる。本物の硬いピクセル輪郭で描き、アンチエイリアスや塗り絵調を避ける
- 8方向は個別に描く。左右反転に依存しない
- 全フレームで同一人物・同一デザイン契約を維持する
- 背景、床、影、発光、罫線、文字、ラベル、透かしを含めない

生成元が既に透過なら背景除去をしない。濃い髪や衣装まで透明化されるおそれがあるためである。

## 完了条件

- `assets/characters/<id>_idle.png` と `assets/characters/<id>_pixel_8dir.png` が存在する
- スプライトが512×320px、RGBA、40セルである
- 40セルすべてにキャラクター画素があり、8方向・停止・歩行4フレームを判別できる
- セル外へのはみ出し、混入、切れ端、欠けがない
- 両素材がデザイン契約とテーマカラーに一致する

ゲーム表示への組み込みも依頼された場合は、能力・課題用の内部IDを変えず、表示用IDからスプライトを参照する。`facing` は45度単位、停止は行0、移動は行1〜4を8fpsで使い、画像色は `Color.WHITE` のまま描画する。
