# キャラクターアセット制作

## 目的

このプロジェクト用に、1キャラクター分の立ち絵と、対戦用の移動・攻撃・集中アニメーションを一貫したデザインで作成する。
仕様の正は `docs/specs/世界観・アートディレクション.md` と `docs/specs/キャラクター設定.md`、制作・検査方法の正は `docs/guides/キャラクターアセット制作ガイド.md` とする。

## 着手前

必ず上記3ファイルを読み、対象キャラクターについて次をデザイン契約として抽出する。

- モチーフと、それを表す性格・雰囲気・所作
- テーマカラー（メイン・アクセント・暗色ベース）
- 髪、帽子・眼鏡、武器、キャラクターシンボル、衣装のシルエット、固定小物
- 年齢層・体格・性別などの固定要素
- 禁止事項

キャラクターIDまたはデザイン契約に必要な項目が仕様で未確定なら、勝手に固定せずユーザーへ確認する。既存キャラクターを更新する場合も、仕様に反する既存画像を基準にしない。

## 制作手順

基本は、 `docs/guides/キャラクターアセット制作ガイド.md` に従う。
1. 対象IDとデザイン契約をユーザーに簡潔に共有する。
2. まずは立ち絵を生成する。指定された武器とシンボルは含め、背景・床・環境エフェクトは含めない。合格前の画像は `assets/characters/.staging/<id>/` に置き、正式なファイル名・配置にはしない。
3. 立ち絵を確認し、デザイン契約と透過・全身構図を満たさなければ修正または再生成する。
4. 同じデザイン契約を明記して、移動・攻撃・集中の各8方向アニメーションシートを生成する。立ち絵だけを参照に任せず、髪・衣装・武器・小物・配色・記号をプロンプトへ文字で含める。
5. 各シートを8列×8行に分割できる素材から、各セルを縦横比を保つ最近傍補間で64×64pxへ正規化し、足元をセル下端に揃える。結果を透過RGBA・512×512pxで、仮置きディレクトリに保存する。
6. 各モーションをフレーム順に確認し、移動・集中が循環し、攻撃に予備動作から戻りまでの重心移動があることを検査する。
7. 正規化後の全画像を、制作を担当していないサブエージェントへ渡して品質レビューを依頼する。レビューの合格後にのみ最終素材として扱う。
8. 不合格なら、指摘に応じて再生成または修正してから再レビューする。全項目が合格した画像だけを `assets/characters/<id>_idle.png`、`<id>_move_8dir.png`、`<id>_attack_8dir.png`、`<id>_focus_8dir.png` として正式配置する。

## 完了条件

- `assets/characters/<id>_idle.png`、`<id>_move_8dir.png`、`<id>_attack_8dir.png`、`<id>_focus_8dir.png` が存在する
- 独立したサブエージェントの品質レビューが全項目 `PASS` である

ゲーム表示への組み込みも依頼された場合は、能力・課題用の内部IDを変えず、表示用IDからモーション別シートを参照する。`facing` は45度単位で列を選び、移動は行0～7を12fpsで循環、攻撃は行0～7を12fpsで一回再生、集中は行0～7を10fpsで循環する。画像色は `Color.WHITE` のまま描画する。
