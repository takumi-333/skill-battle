# スキルアイコン生成プロンプト作成

## 目的

ユーザーが外部の画像生成AIへ渡すための、キャラクター固有スキルアイコンの**前景ロゴ用プロンプト**を作成する。画像生成、アセットの追加・更新、プロンプトファイルの保存は行わない。ユーザーが明示的に求めない限り、返す成果物は会話内のプロンプトだけとする。

## 最初に確認するもの

要求に関係する範囲だけ、次を確認する。

- 共通のUI要件: `docs/specs/UI規格/キャラクタースキルアイコン規格.md`
- 世界観とアート方針: `docs/specs/世界観・アートディレクション.md`
- 既存キャラクターの識別要素・色: `docs/specs/キャラクター設定.md`
- 既存の作例プロンプト: `prompts/skill_icons/*.md`
- 同じキャラクターの既存アイコン: `assets/ui/skill_icons/`
- キャラクターを描く必要がある場合の正の外見資料: `assets/characters/portraits/` 内の立ち絵

## アイコンとして守ること

- 出力対象は、背景と分離された前景ロゴ。完全な透明背景の RGBA PNG 向けにする。
- ロゴ色は対象キャラクターのアクセントカラー**1色のみ**。色コードをプロンプトへ明記し、グラデーション、多色、半透明による色分けを禁止する。
- 主題は正方形キャンバスの中央へ大きく置き、small（112 px）でも読める太く明快なシルエットにする。外周・四隅には重要な形状を置かず、ひし形マスクで欠けない安全な余白を残す。
- 背景、背景装飾、風景、ひし形フレーム、キー番号、文字、数字、クールダウン表示は含めない。
- 効果は、主題の姿勢、輪郭、少数の軌道や記号で読ませる。小サイズで判別不能になる細密描写、長すぎる残像、過度な発光、煙、霧、強い質感は避ける。
- 人物を描くときは、キャラクター設定の固定要素を少数に絞り、シルエットとして判別できるようにする。立ち絵を参照に使う場合は、デザイン確認だけに使い、その構図・ポーズ・背景・画面レイアウトを持ち込まない。
- 既存アイコンと同じスキル系統では、主題や構図を明確に差別化する。同じキャラクターらしさは、アクセント色と固有モチーフで保つ。

## 出力形式

情報がそろったら、説明を最小限にして次の順番で返す。

1. `添付する参照素材` — 外部画像生成AIへユーザーが一緒に渡すべきローカル素材を箇条書きにする。不要なら「なし」とする。立ち絵は人物を描く場合だけ挙げ、既存アイコンは、スタイル・安全余白・単色表現の参考として有効なものだけを挙げる。
2. `生成プロンプト` — そのままコピーできる日本語の単一コードブロックにする。

生成プロンプトは、次の情報を自然な文章で必ず含める。

- 「ゲーム用スキルアイコンの前景ロゴ」を作る依頼
- スキル名またはテーマ、スキル効果が一目で伝わる主題と構図
- 必要なキャラクター固有モチーフ、または人物の識別要素
- 小サイズで読める構図・シルエット・安全余白の指示
- アクセントカラーの色コード1色、透明背景、RGBA PNG の指示
- 禁止事項。共通禁止事項に加え、スキルの題材に応じた誤解を防ぐ禁止事項

生成AIの出力がルールを外れやすい題材では、禁止事項を具体化する。例: 数学系では可読な数式や数字を避ける、射撃系では長い発光線を避ける、魔法陣系では細かすぎるルーンや複雑な背景を避ける。

背景レイヤーが必要かをユーザーに案内する場合は、アイコンの生成プロンプトとは分けて短く伝える。背景はキャラクターのメインテーマカラーの単色または下方へ少し暗くなる穏やかなグラデーションであり、前景ロゴへ合成しない。

## 禁止する作業

- 画像生成ツールを呼び出さない。
- `assets/`、`prompts/`、仕様書を変更しない。
- 画像を直接添付できると仮定しない。必要なローカル参照パスをユーザーへ示す。
