# 8方向スプライト素材作成ガイドライン

## 目的と適用範囲

本書は、新規キャラクターの8方向スプライトを制作・採用する際の規格と品質基準を定める。対象は、1セル64×64px、8方向×（停止1枚＋歩行4枚）の計40フレームから成るRGBA PNGである。

キャラクターが増えても、制作担当者や生成手段に依存せず、ゲームへ追加できる素材を再現性を持って作ることを目的とする。新規作成時の世界観・配色・質感の共通基準は[世界観・アートディレクション](../../specs/世界観・アートディレクション.md)、キャラクターごとの外見設定は[キャラクター設定](../../specs/キャラクター設定.md)を正とする。本書は、画像生成・検査・配置のノウハウを扱う。既存のasset spec、motion specがある場合はそれらを優先する。

AI生成は外見・ポーズの候補を得る工程であり、完成品質を保証する工程ではない。最終素材は、背景除去、正規化、セル内配置、機械検査、人間レビューを経て確定する。

## 完成条件

| 項目 | 基準 |
| --- | --- |
| 出力 | 512×320px、RGBA PNG、64×64pxセル40枚 |
| 構成 | 8方向 × 停止1枚・歩行4枚 |
| 配置 | 各フレームのrootを原則 `x=32, y=56` に配置する |
| 身体高さ | alpha閾値適用後の身体前景で原則56px、許容差は±3px |
| 横幅 | 正規化後の全前景bboxは原則60px以下。例外は理由とセル越境確認を記録する |
| 停止／歩行の整合 | 代表高さ比を `0.93〜1.07` に収める |
| alpha | 最終成果物のalphaは `0` または `255` のみ |
| パレット | asset specの固定パレットへexact remapし、不透明画素を100%一致させる |
| 視覚品質 | 背景・床・影・文字・グリッドがなく、外見・向き・輪郭・歩行が連続している |

56pxは現行の打鍵士を含む既存素材の実測値（停止平均56.1px、歩行平均56.4px）を基準とする。キャラクター固有の例外は、asset specに基準値と理由を記録してレビュー対象とする。

## 制作上の原則

1. **1回の出力は1フレーム、判断は系列単位にする。** 40セルのシートをAIに一度に描かせず、停止・歩行の連続性を比較して候補を選ぶ。
2. **主参照を固定する。** 全フレームでCharacter Master、Direction Reference、Style Reference、Pose Guideを使う。隣接フレームは補助参照にとどめ、連鎖的な主参照にはしない。
3. **縮尺は閾値後の前景で決める。** `alpha_bbox_threshold`を適用した前景マスクからbboxを取得し、半透明ノイズを人物サイズに含めない。
4. **身体スケールと全体の収まりを分けて扱う。** 頭頂〜足元を主基準とし、武器や装飾を含む全前景bboxはセル越境を防ぐ副制約とする。
5. **停止と歩行は同じ正規化規則を通す。** alpha処理、目標高さ、横幅制約、pixelization、パレット、alpha二値化の差を設けない。
6. **色と透明度は後処理で確定する。** AIの出力に依存せず、固定パレットと二値alphaを決定論的に適用する。意図しないditherは使わない。
7. **自動検査と目視を分ける。** validatorは規格不整合を止めるハードゲートであり、キャラクターの同一性や歩行の自然さは人間レビューで判断する。

## 仕様として事前に定める情報

### asset spec

asset specは、キャラクターごとの出力規格を表す正本である。少なくともキャンバス、セルサイズ、足元アンカー、列・行順、正規化条件、固定パレットを持つ。

標準の正規化値は次のとおりとする。

```json
{
  "normalization": {
    "alpha_bbox_threshold": 8,
    "target_visible_height": 56,
    "height_tolerance": 3,
    "max_visible_width": 60,
    "idle_walk_height_ratio": [0.93, 1.07],
    "binary_alpha_threshold": 8
  }
}
```

パレットの色数は固定しない。asset specには、作品とキャラクターに必要な全RGB色を記載する。パレット未定義の試作素材は採用対象にしない。

### motion spec

motion specは、40フレームのID、方向、位相、root、接地情報の正本である。rootが未定義の既存素材に限り、前景bboxのbottom-centerを配置用のfallbackにできる。武器、浮いた足、跳躍があるフレームではrootと接地点を定義する。

### 参照素材とPose Guide

| 参照 | 固定する内容 |
| --- | --- |
| Character Master | 顔、服、武器、配色、キャラクターの同一性 |
| Direction Reference | 8方向ごとの見え方 |
| Style Reference | ドット密度、輪郭、陰影、色数 |
| Pose Guide | 頭頂、root、接地足、足元、武器位置 |

Pose Guideのランドマークは、武器の先端や髪・マントの一時的なはみ出しによって身体高さが変わらないようにするためにも用いる。

## 品質と採用の基準

validatorは、画像形式、シート寸法、空セル、二値alpha、固定パレット、身体高さ、横幅、停止／歩行比、root／接地を検査する。検査レポートにはフレームごとのbbox、高さ、幅、占有率、root／接地点、alpha・パレット検査結果を残す。不合格の候補は採用しない。

validator合格後は、等倍・4倍nearest・通常速度・0.25倍・ループ・シルエット表示で目視確認する。特に、方向・武器・手足の読みやすさ、body bob、foot sliding、ループ端、顔・髪・服・武器・配色の同一性、セル越境を確認する。

採用候補ごとに `work/<character-id>/manifest.json` を保存し、生成器、モデル、seed（指定できる場合）、プロンプト版、参照素材とその出所、asset spec、motion spec、パレット、後処理、人間レビュー結果を追跡可能にする。参照素材の利用権、モデルやLoRAのライセンス、第三者IPとの類似性の確認結果も記録する。
