# 8方向スプライト素材作成ガイドライン

このディレクトリは、Godot用の8方向キャラクタースプライトを、再現性を持って制作・採用するためのガイド群である。
AI生成は候補を作る工程であり、最終素材の規格・配置・検査は決定論的な処理とレビューで確定する。

## 文書の役割

| 文書 | 記載する内容 | 更新する場面 |
| --- | --- | --- |
| [8方向スプライト素材作成ガイドライン.md](8方向スプライト素材作成ガイドライン.md) | 目的、適用範囲、完成条件、制作上の原則、品質・採用基準 | 規格や品質基準を変えるとき |
| [8方向スプライト素材作成フロー.md](8方向スプライト素材作成フロー.md) | 実際の作業順、各工程の手順、差し戻し方、実行例、チェックリスト | 制作の進め方を変えるとき |
| [ツール一覧.md](ツール一覧.md) | 各ツールの入力・出力・責務・責務外 | ツールのインターフェースや担当範囲を変えるとき |

## 読み方

1. 初めて制作する場合は、まずガイドラインで完成条件と守るべき原則を確認する。
2. 実際の制作ではフローに従って工程を進める。
3. コマンド、入出力、どのツールが何を保証するかを確認したい場合はツール一覧を参照する。

数値などの規格の正本はガイドライン、作業順の正本はフロー、ツールの仕様の正本はツール一覧とする。同じ説明を複数の文書へ重ねて書かず、必要な場合は正本へリンクする。
