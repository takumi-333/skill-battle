# スプライト制作ツール一覧

各ツールはasset specとanimation specを読み、素材の意味（方向、停止、歩行、攻撃）をハードコードしない。アニメーション定義には`--animation`を指定する。

| ツール | 主な責務 | profileとの関係 |
| --- | --- | --- |
| `extract_sheet_frames.py` | sheetからanimation specの各frame矩形を展開する | 共通 |
| `extract_alpha.py` | native alphaを保持、または背景を透過化する | 共通 |
| `pixelize_frame.py` | frameを指定矩形へpixelization・palette・二値alpha処理する | 共通 |
| `cleanup_frame_artifacts.py` | 分離した不要成分を検査・除去する | character既定、effect/projectileは既定無効 |
| `sprite_editor.py` | PNGを1px単位で手修正する | 任意のセル幅・高を選択可能 |
| `build_sprite.py` | frameをgridまたはatlasへ組版しbuild reportを作る | anchorを適用 |
| `validate_sprite.py` | 共通検査とprofile別検査を行う | profileを適用 |
| `preview_sprite_animation.py` | clip / variant / eventsをブラウザで再生する | 共通 |
| `promote_sprite.py` | validator通過済みsheetだけを採用先へコピーする | 共通 |

## 共通入力

- `--spec`にはasset spec、`--animation`にはanimation specを指定する。
- asset specはcanvas・layout・profileを、animation specは全frameの配置と再生順を提供する。
- atlasはanimation specなしに検査できないため、`validate_sprite.py`でも`--animation`を必須にする。

## 主要コマンド

```text
# 個別フレームを組版する
python tools/build_sprite.py --spec <asset-spec.json> --animation <animation-spec.json> --frames-dir <frames-dir> --output <sheet.png> --report <build.json>

# sheetを検査する
python tools/validate_sprite.py --spec <asset-spec.json> --animation <animation-spec.json> --build-report <build.json> --input <sheet.png> --report <validation.json>

# clip / variantのHTMLレビューを生成する
python tools/preview_sprite_animation.py --spec <asset-spec.json> --animation <animation-spec.json> --input <sheet.png> --output <review.html>

# sheetをframeへ戻す
python tools/extract_sheet_frames.py --sheet <sheet.png> --spec <asset-spec.json> --animation <animation-spec.json> --output-dir <frames-dir>
```

`pixelize_frame.py`は従来の`--size`に加え、長方形frameの`--width`と`--height`を受け付ける。`sprite_editor.py`はブラウザで開いた後、セル幅・高を指定してグリッド編集する。atlasの個別矩形選択はanimation specを参照して判断し、不要なセル範囲を編集しない。

## 保証しないこと

ツールはキャラクターの同一性、攻撃の気持ちよさ、エフェクトの演出意図、hit eventがゲームロジックと実際に接続されていることを自動で保証しない。これらは企画書、RV-1〜RV-4、Godot側実装のテストで確認する。
