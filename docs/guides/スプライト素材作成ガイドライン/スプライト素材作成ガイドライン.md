# スプライト素材作成ガイドライン

## この文書の役割

- 本書は、Godotで使うキャラクター、武器、飛び道具、エフェクトなどのアニメーションスプライトを、再現可能に制作・採用するための**全体方針**を示す。

- AIによる画像生成を取り入れる一方で、生成結果をそのまま完成素材とは扱わない。ゲームで必要な見た目・動き・配置・再利用性を満たすまで、仕様化、整形、検査、レビューを行う。

## 基本方針

1. **生成は出発点、採用は検証後**

   AI生成は外見・ポーズ・動きの候補を得るために使う。背景、サイズ、アンカー、パレット、フレーム間の整合性などは、後処理と検査、人間の確認を経て初めて採用する。

2. **一枚の絵ではなく、再生される素材として評価する**

   1フレームの見栄えだけで判断しない。キャラクターの同一性、方向、接地点、動きの流れ、ループ、ゲーム内イベントとの同期を、対象clip全体で確認する。

3. **意図と制約を先に定義する**

   制作前に、素材のゲーム上の役割、演出意図、必須要素、完成条件を明確にする。必要なclip・variant・frame、レイアウト、アンカーなどの実装上の契約は、制作開始前に仕様へ落とし込む。

4. **基準を固定してから量産する**

   先にキャラクターの基準画像や代表動作を確認し、見た目・視点・ポーズ・配置の基準を固める。残りのフレームはその基準を保ちながら制作し、フレームごとの生成品質の揺れを抑える。

5. **素材種ごとの性質を尊重する**

   キャラクター、武器、飛び道具、エフェクトでは、必要なアンカー、許容する粒子・残像、確認すべき品質が異なる。同じ機械検査を一律に当てはめず、素材の役割に応じた仕様とレビュー基準を用いる。

6. **来歴と判断を残す**

   使用した生成手段・参照素材・後処理・レビュー結果・採用理由を記録する。これにより、再生成、修正、権利確認、品質問題の追跡を可能にする。

## 全体の流れ

制作は、次の順序で進める。各工程の具体的な手順、レビュー項目、コマンドは[スプライト素材作成フロー](スプライト素材作成フロー.md)を参照する。

```text
企画・承認
  → 仕様と参照素材の準備
  → 基準画像・代表動作の確認
  → 全フレームの制作
  → 組版・自動検査・再生レビュー
  → 記録・採用
```

早い段階で問題を見つけることを重視する。特に、基準画像と代表動作が承認される前に、全フレームの量産へ進まない。

## 判断の分担

| 担当 | 主な責任 |
| --- | --- |
| 人間 | ゲーム上の目的、演出意図、世界観、採用基準、最終的な採否を決める |
| AI | 企画・仕様のたたき台、画像候補、制作指示の整理、レビュー補助を行う |
| スクリプト・検査ツール | 画像の整形、組版、仕様との照合、機械的な品質確認を行う |

AIやツールは判断を支援するものであり、演出意図や採否を単独で決定しない。
