# スプライト企画書テンプレート

企画書は「何を作るか」を決める人間向けの文書である。人間が目的と採用判断を担い、AIは質問、たたき台作成、仕様への整理を支援する。承認済みの企画書をもとにasset spec、animation spec、Pose Guideを作る。
あくまでテンプレートで完全にこれに準拠しなくてもよい。（この企画書を解釈するのはAIであるため）
```markdown
# <アセット名> スプライト企画書

## 1. 概要

- 企画ID:
- 対象キャラクター／スキル／演出:
- 作成目的: どの画面・どのゲーム状態で、何をプレイヤーへ伝えるか
- 担当・承認者:

## 2. ゲーム上の役割

- 表示開始条件:
- 表示終了条件:
- 表示位置・追従対象: キャラクターの足元／手元／発射点／着弾点／画面固定など
- ゲームイベント: hit、発射、効果音、カメラ揺れなどと同期する瞬間
- 再生方針: ループするか、再生速度の目安、途中で中断できるか

## 3. 演出・見た目

- 動作の流れ: 予備動作 → 主動作 → 最大強度 → 余韻、のように時系列で記す
- 必須の見た目: 武器、色、形、シルエット、発光、粒子など
- 変えてよい要素／変えてはいけない要素:
- 背景・床・影・文字の扱い:
- 参照素材と利用目的・出所:
- 禁止事項:

## 4. 必要なアニメーション

| clip | variant | 概要 | フレーム数の目安 | ループ | event |
| --- | --- | --- | --- | --- | --- |
| <例: walk> | <例: down> | 下向き歩行 | 4 | はい | 足音 |

- RV-3の代表パターン: 全frameを先行して生成・再生確認するclip / variantを一つ選ぶ

## 5. 完成条件とレビュー観点

- ゲーム上で読み取れるべき情報:
- 動き・ループ・hit同期の合格条件:
- 画風・世界観の合格条件:
- profile候補: character / weapon_attack / projectile / effect
- 想定する例外: 分離粒子、セル外へ見える武器、可変サイズなど

## 6. 承認記録

- RV-0判定: 承認／差し戻し
- 判定者・日付:
- 差し戻し内容:
```
