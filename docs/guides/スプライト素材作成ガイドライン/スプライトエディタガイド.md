# スプライトエディタ

`tools/sprite_editor.py` は、生成済みスプライトの不要なドットを人が直接取り除くためのローカルツールです。ChromeまたはEdgeで開き、保存は開いた既存PNGへの上書きです。

## 起動

PowerShellで、編集したいPNGを指定して起動します。

```powershell
python tools/sprite_editor.py
```

ローカルURLを開いたままにするため、起動したPowerShellは閉じずに使います。終了するときは、そのPowerShellで `Ctrl+C` を押します。画面の `既存PNGを開く` から `assets/` 配下のPNGを選びます。

## 編集

- `シート全体` はスプライトシート全域を、`セル範囲` は右のセル番号を選んだ1コマだけを拡大表示します。セル幅・高は既定の64pxから任意のgridサイズへ変更できます。atlasは対象frameの矩形を確認してから、対応する範囲を編集してください。
- ペンは選んだ色と不透明度で1pxずつ描画します。色ボタンを押すと任意の色を選べます。
- `透明色にする` はペンの不透明度を0にします。消しゴムは色に関係なく完全に透明にします。
- 塗りつぶしは、現在の編集範囲（シート全体または選択セル）からはみ出しません。
- `元に戻す` と `やり直す` で、直近50操作を戻せます。

## 保存と確認

`上書き保存` を押すと、ブラウザーから書き込み許可を求められた後、開いたPNGファイルに直ちに保存します。別名保存やダウンロードはしないため、戻したい場合は編集前にファイルをコピーしてください。

編集後は既存の検証フローに戻り、`validate_sprite.py` と必要に応じて `cleanup_frame_artifacts.py --check-only` を実行してください。
