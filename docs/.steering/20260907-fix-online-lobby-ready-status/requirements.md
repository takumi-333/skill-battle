# 要求内容

## 概要

Dedicated Server を利用するオンライン対戦ロビーで、どちらの参加スロットからでも「準備完了」を操作でき、サーバーが確定した準備状態をチェック表示へ反映する。

## 背景

スロット2の準備完了ボタンが実行時に接続されておらず、参加者側の操作が Dedicated Server へ届かない。結果として準備済みチェックが表示されず、両者がゲーム開始可能か判断できない。

## 実装対象の機能

### 1. 両スロットの準備完了操作

- スロット1・スロット2の可視側「準備完了」ボタンを同一のローカル準備操作へ接続する。
- GUI シグナルを補うマウス入力処理も、可視のローカル準備ボタンを対象にする。

### 2. 準備状態の表示

- Dedicated Server から届く snapshot の `ready` 状態を両プレイヤーのステータスアイコンと準備ボタン文言に反映する。
- 両者が準備済みになったときは、既存のサーバー権威による試合開始へ遷移する。

## 受け入れ条件

### 両スロットの準備完了操作

- [ ] slot 1 のクライアントが準備完了を押すと `set_room_ready(true)` が Dedicated Server へ送信される。
- [ ] slot 2 のクライアントが準備完了を押しても同じ要求が送信される。
- [ ] キーボードおよびマウス操作で、同じ準備状態を二重に反転させない。

### 準備状態の表示

- [ ] サーバー snapshot の `ready[1]` / `ready[2]` が対応するチェック表示へ反映される。
- [ ] 両者が準備済みになると Dedicated Server が試合を開始し、クライアントが試合画面へ遷移する。

## スコープ外

- 旧プレイヤーホスト方式のロビー仕様変更。
- ロビー予約、token、試合ルールの変更。
