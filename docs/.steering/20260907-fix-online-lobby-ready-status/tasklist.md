### 計画と実績の差分

- slot 2 の `PlayerTwoReady` に `pressed` シグナル接続がないことが直接原因だった。加えて、GUI シグナルを補うマウス処理が `PlayerOneReady` に固定されていた。
- `get_local_lobby_ready_button()` を追加し、slot 判定をロビー更新とマウス処理で共有した。
- 実機2台による通信試験の代わりに、ロビーシーン初期化テストと `MatchSession` の開始契約テストを追加した。

### 学んだこと

- UI の固定ボタンは、スロット別に存在するすべての操作部品を実行時接続する必要がある。
- 準備済みの表示はクライアントの楽観更新ではなく、Dedicated Server の snapshot を正とすることで、開始可否と表示が一致する。

### 次回への改善提案

- slot 依存の UI 操作は、対象ノードを選ぶ小さなヘルパーに集約し、片方のスロットだけを固定参照しない。
