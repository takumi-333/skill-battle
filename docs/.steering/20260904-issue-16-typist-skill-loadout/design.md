# 設計

1. `match_prototype.gd` にスキル候補ID・表示名・課題定義をまとめ、打鍵士のスキル2選択をロードアウトから解決する。
2. `character_skill_selection` は全キャラクター共通のスキル欄として維持し、対戦開始時に選択値をプレイヤー辞書へコピーする。未実装候補は既存の標準効果へフォールバックする。
3. スキル2の開始時に、プレイヤーのロードアウトIDから課題ワードと発動効果を決める。三叉震槌は既存の衝撃波・周囲波動処理を使用し、鍵片追弾IIは鍵片追弾の弾生成処理を共通化して発射間隔だけ差し替える。
4. 弾辞書にキーキャップ表示用テクスチャと入力文字を保持し、描画時にキーキャップを先に描画して文字を重ねる。スペースは視認可能な記号で表示する。
5. ネットワーク同期では既存の弾辞書をそのまま同期し、受信側も同じ辞書から描画する。
