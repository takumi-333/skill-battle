# 要求内容

## 機能要件

- 打鍵士の三叉震槌で使用するワード候補を仕様書の最新版へ合わせる。
- 打鍵士スキル2候補「鍵片追弾II」を追加し、キャラクター画面で選択できるようにする。
- キャラクター画面で選択したスキルセットを、対戦開始時のプレイヤー設定へ反映する。
- 鍵片追弾系スキルは `assets/ui/skill_effects/typist_key_cap.png` を弾の見た目に使い、入力済み文字を弾ごとに表示する。
- 鍵片追弾IIは鍵片追弾と異なる発射間隔・クールダウンを持つ。
- 既存の三叉震槌の効果と、他キャラクターのスキル発動を壊さない。

## 受け入れ条件

- 三叉震槌の出題ワードが仕様書と一致する。
- 打鍵士のスキル2候補2を選択して保存し、対戦中のスキル2で鍵片追弾IIが発動する。
- 鍵片追弾系の弾にキーキャップ画像と対応する入力文字が描画される。
- Godotのヘッドレス起動でプロジェクト由来のエラーがない。
