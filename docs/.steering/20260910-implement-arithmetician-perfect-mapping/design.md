# 設計

## 対象登録

- 算術士のスキル2候補へ完全写像を追加し、選択状態から `arithmetic_perfect_mapping` をプレイヤーのスキルIDとして設定する。
- 算術問題候補・12秒の制限時間・10秒のクールダウンを既存のスキル課題／クールダウン機構に登録する。

## コピー処理

- スキルIDのコピー可否を一か所で判定し、スキル1〜3を候補にする。
- 成功時にシミュレーション側で候補から一つを決定し、その選択結果とスコアをイベント化する。表示側は受信したコピー発動イベントを既存スキルの演出・処理へ橋渡しする。
- コピー実行のコンテキストに `suppress_interference_points` を渡し、元スキルの固有妨害ポイント加算を抑止する。
- 既存スキルのパラメータ算出を再利用し、コピー時だけ発動者・対象・スコアを差し替える。

## 演出

- 成功時に短時間の青紫の座標平面／タイル選択演出を表示し、コピー元のスキル演出に遷移する。
- コピー中も算術士のキャラクタースプライトを維持する。

## 検証

- ヘッドレス起動でGDScriptとリソース参照のエラーを確認する。
- 可能な範囲でローカル・オンライン双方のイベント経路を確認する。
