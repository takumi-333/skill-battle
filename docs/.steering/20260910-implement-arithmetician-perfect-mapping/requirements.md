# 要求

## 目的

算術士のスキル2「完全写像（パーフェクト・マッピング）」を、`docs/specs/キャラ別スキル仕様書/算術士/スキル2候補一覧.md` に従って実装する。

## 機能要件

- 算術士がスキル2として完全写像を選択でき、指定された算術課題（制限時間12秒）を出題する。
- 正答時に相手の装備スキル1〜3からコピー可能なものをランダムに一つ選び、追加課題なしで一度だけ発動する。
- コピー効果は完全写像の解答スコア、算術士を発動者、現在の相手を対象として算出・実行する。
- 相手側のクールダウン、回数、チャージ、継続効果には影響しない。
- パッシブ、通常攻撃、完全写像自身、およびスキル固有の妨害ポイント獲得はコピーしない。
- コピー可能な技がない場合も完全写像のクールダウンを適用し、不発にする。
- スキルアイコンを `arithmetician_new.png` からスキル名に沿うファイル名へ変更して利用する。

## 非機能要件

- ローカル対戦とオンライン対戦で同じコピー対象・結果を同期する。
- 既存スキルの挙動を回帰させない。
