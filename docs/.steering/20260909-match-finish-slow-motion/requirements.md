# 要求内容

## 概要

どちらかの HP が 0 になり勝者が確定した直後、対戦画面を維持したまま数秒間だけ視覚演出をスローモーションで再生し、その後にリザルト画面へ遷移する。現時点では方針の合意のみを対象とし、実装は行わない。

## 機能要件

1. 対象トリガーは HP 0 による決着だけとする。時間切れと切断の扱いは、実装時に個別に決める。
2. 決着時点で HP、勝者、最終的な攻撃結果はサーバー権威で確定し、以後は移動・攻撃・課題入力を受け付けない。
3. ローカル対戦とオンライン対戦の両方で、対戦画面を保ったまま同じ決着演出期間を経由してからリザルトへ遷移する。
4. 決着演出中は、歩行スプライト、集中エフェクト、画面揺れ、被弾時の白点滅など、クライアントが表示する時間依存の演出を共通のスロー倍率で進める。
5. 最終被弾者の白点滅は、HP 0 の直前に見える長さを確保する。
6. 決着演出期間の終了後にのみ、既存のリザルト画面と再戦・ロビー復帰操作を有効にする。

## 初期調整値案

- 演出の実時間: 2.0 秒
- 視覚演出の時間倍率: 0.20

これらは定数として切り出し、プレイテストで調整できるようにする。数値は今回の認識合わせ用の仮置きであり、実装開始時に再確認する。

## スコープ外

- KO テキスト、勝者ポーズ、専用カメラ、追加エフェクト素材の制作
- BGM・SE のピッチ変更。音の演出をスロー化またはフェードするかは別途決定する。
- 時間切れ、引き分け、切断時の専用演出
- 勝敗判定、ダメージ、スキル性能の変更

## 受け入れ条件（実装時）

- [ ] HP 0 の直後にリザルトが表示されず、対戦画面で決着演出が再生される。
- [ ] 決着演出中に操作や課題入力で試合状態が変わらない。
- [ ] 最終被弾の白点滅を含むクライアント側の演出が、通常時より遅く進む。
- [ ] 演出終了後、両プレイヤーで同じ確定結果のリザルトが表示される。
- [ ] ローカルと Dedicated Server 経由のオンライン対戦で同じ遷移順になる。
