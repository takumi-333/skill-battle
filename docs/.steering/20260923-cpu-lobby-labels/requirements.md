# 要求内容

## 概要

CPU対戦画面の案内文と操作ボタンの表示を簡潔にする。

## 実装対象の機能

### CPU対戦画面の文言
- 「あなたが操作」を表示しない。
- 「あなたのキャラクター」を「あなた」と表示する。
- 「CPUのキャラクター」を「CPU」と表示する。
- CPUレベル表示から括弧内の強さ説明を外し、「CPU レベルX」と表示する。
- 開始ボタンを「対戦を開始」と表示する。

## 受け入れ条件

- [ ] CPU対戦ロビーに指定された5点の文言変更が反映される。
- [ ] Godotで画面シーンとスクリプトがエラーなく読み込まれる。

## スコープ外

- キャラクター選択やCPUレベル選択の動作変更。
- 他画面の文言変更。
