# 設計書

## 方針

固定ラベルはCPU対戦画面のシーンに定義し、CPUレベルのように実行時に更新される表示文字列は既存の更新処理で変更する。画面構成と選択動作は変えない。

## 変更対象

- `scenes/ui/cpu_battle_screen.tscn`: 見出し、操作ラベル、開始ボタンの初期文言を変更する。
- `scripts/match_prototype.gd`: CPUレベルラベルの実行時文字列から強さの括弧書きを除く。

## 確認

- Godotをヘッドレス起動してシーン・スクリプト読み込みを確認する。
- `git diff --check` で差分の空白エラーを確認する。
