# 要求内容

## 概要

3キャラの通常攻撃を、ニュートラルの人物スプライトに武器画像と軌跡粒子画像を重ねる演出として実装する。

## 実装対象の機能

### 1. 武器の扇状スイング

- 通常攻撃中、キャラクター別の武器画像を手元に重ねる。
- 柄端を基準に、攻撃方向の左から右へ扇状に回転させる。
- 人物本体は既存のニュートラルスプライトを表示し続ける。

### 2. 軌跡粒子

- 通常攻撃中、キャラクター別の粒子画像を武器の先端付近に複数回描画する。
- 粒子は短時間で薄く消え、武器の移動軌跡を補助する。

## 受け入れ条件

- [ ] 打鍵士・算術士・詠唱者でそれぞれ固有の武器と粒子が表示される。
- [ ] 通常攻撃中に人物本体の攻撃用フレームを使わない。
- [ ] 武器が攻撃方向に対して左から右へ扇状に回転して見える。
- [ ] 既存の命中判定、クールダウン、ネットワーク同期を変更しない。
- [ ] Godotのパーサチェックまたは起動確認が成功する。

## スコープ外

- GPUParticles2Dなどのシーンノード化
- 新しい攻撃判定・ダメージ仕様
- 武器・粒子画像の再生成や最終的な素材昇格
