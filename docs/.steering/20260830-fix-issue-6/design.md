# issue-6 UX改善 設計

## ナビゲーション

`match_prototype.gd` にホーム復帰処理を集約する。オンライン画面の戻るボタンは `return_to_home()` を呼び、`OfflineMultiplayerPeer` へ切り替えてネットワーク関連の状態を初期化する。練習・デバッグの試合画面にはHUDレイヤー上の戻るボタンを表示し、課題が実行中なら中止してからホームへ戻す。

## 操作ガイド

既存の `controls_label` を練習モード専用の右上ラベルとして再利用する。対戦HUDの既存方針を崩さないため、練習以外では非表示にする。

## レイアウト

メニュー系Panelを viewport 全体 `Rect2(0, 0, 1280, 720)` に配置し、外周の枠線をなくす。各画面の既存コンテンツは現在の座標を基本的に維持し、画面全面の背景とコンテンツ領域を分離する。オンライン接続・ロビー・結果パネルも全面化し、内部要素を既存の相対位置で配置する。

## 検証

- 追加した戻る処理、ネットワーク切断、練習ガイドの表示条件をコード検索で確認する。
- Godotヘッドレスでエディタ起動と短時間実行を行い、パース・実行エラーを確認する。
