## 実装後の振り返り

- 完了内容: ロビーとHUDに `DuelLayout` / `FfaLayout` を追加し、固定座標・サイズ・仮表示値をシーンへ保存した。
- 計画との差異: エディタ確認中に既存の `UIScreenManager` がプレースホルダーとなるエラーを検出したため、`@tool` 対応を追加した。レイアウト実装方針の変更はない。
- 検証結果: 2人/3人ロビーUIテスト、2人/3人HUDテスト、既存のスキルHUDテスト、通常ヘッドレス起動が成功した。ヘッドレスのエディタ起動ではUI管理スクリプトのエラーが解消した。
- 学んだこと: 人数差を同じControl群の座標上書きで表現すると、エディタでの調整結果が実行時に失われる。固定レイアウトを兄弟ルートとして保存し、動的データだけを同じ更新処理へ流す方が編集性とテスト性を両立できる。
- 次回への改善: プレイヤーカードの見た目を共通部品化する場合も、人数別インスタンスの位置とサイズは各レイアウト側へ保存する。
