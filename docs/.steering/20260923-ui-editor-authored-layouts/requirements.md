# 要求内容

## 目的

2人用・3人用で異なるロビーと対戦HUDの固定レイアウトを、Godotエディタ上で個別に表示・編集できるようにする。

## 要求

- 2人用ロビーと3人用ロビーを、実行時の座標変更ではなくシーンに保存された別レイアウトとして持つ。
- 2人用HUDと3人用HUDを、シーンに保存された別レイアウトとして持つ。
- 各レイアウトには、エディタ上で位置調整しやすい仮のプレイヤー名・HP・状態を表示する。
- 実行時は対戦人数に応じたレイアウトの表示切替と、名前・HP・Ready・キャラクター画像など動的データの更新だけを行う。
- 実行時にControlの位置・サイズを上書きしない。
- 既存の2人対戦と3人FFAのロビー/HUD機能を維持する。

## 完了条件

- Godotエディタで2人用・3人用レイアウトをそれぞれ選択して位置とサイズを編集できる。
- ロビー更新処理に位置・サイズの代入が残っていない。
- 2人用・3人用の表示切替と動的値更新を自動テストで確認できる。
- Godotのヘッドレス起動と関連テストがエラーなく完了する。
