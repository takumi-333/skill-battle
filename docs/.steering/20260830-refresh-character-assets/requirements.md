# 要求定義

## 目的

更新済みの `docs/specs/キャラクター設定.md` を唯一のデザイン上の正として、対戦ゲームに登場する3キャラクターの画像素材を刷新し、対戦画面で新しい8方向スプライトを正しい向き・アニメーション・色で表示できる状態にする。

## 対象

| 表示名 | アセットID | モチーフ | メイン / アクセント |
| --- | --- | --- | --- |
| 打鍵者 | `typist` | 強欲 | 深い緑 / 金 |
| 算術士 | `arithmetician` | 傲慢 | 紺 / 金 |
| 詠唱者 | `chanter` | 色欲 | 紫 / 金 |

## 機能要件

1. 各対象について、仕様の固定要素・年齢層・雰囲気・テーマカラーに一致する立ち絵を作成する。
   - ファイル名は `assets/characters/<id>_idle.png` とする。
   - 立ち絵は今回はゲーム画面で利用しない。
2. 各対象について、同じデザイン契約を満たす8方向の対戦用スプライトシートを作成する。
   - ファイル名は `assets/characters/<id>_pixel_8dir.png` とする。
   - 64×64pxセルを8列×5行に配した、透過RGBAの512×320px PNGとする。
   - 列順は 下 / 下左 / 左 / 上左 / 上 / 上右 / 右 / 下右、行順は 停止 / 歩行1 / 歩行2 / 歩行3 / 歩行4 とする。
3. 既存の同名画像は、新素材の検査が完了した時点で置き換える。古い素材を並存させない。
4. 対戦画面は表示用IDに対応する新スプライトを参照する。
   - `facing` を45度単位で列へ対応付ける。
   - 停止時は行0、移動時は行1〜4を8fpsでループする。
   - 描画色は `Color.WHITE` とし、プレイヤー色で画像を変調しない。
   - 能力・課題に使う内部IDは変更しない。

## 品質要件

- 立ち絵は、透過RGBA背景・全身・1人・右向き3/4立ち・正方形のアニメ調ファンタジーイラストとする。
- スプライトは本物の硬いピクセル輪郭で、背景・床・影・グロー・文字・罫線・透かしを含めない。
- 40セルすべてに人物が収まり、セル境界を越える装飾、孤立した切れ端、欠け、方向・歩行フレームの不足がない。
- 立ち絵とスプライトの髪型、衣装、小物、配色を一致させる。

## 制約・受入条件

- `docs/specs/キャラクター設定.md` にない目立つ武器などを追加しない。
- 打鍵者は黒髪・黒縁眼鏡・白シャツ・短い緑裏地コート・ルーンペンダントを維持する。
- 算術士は流れのある暗色の髪・博士帽・紺のローブ・金の幾何学的ルーン刺繍を維持する。
- 詠唱者は紫の大きなローブ・金または淡色の装飾・複数のアクセサリー・仕様どおりの露出表現を維持する。
- 各ファイルの存在、画像の寸法・RGBA、40セルの内容、およびGodot実行時のエラーがないことを確認する。
