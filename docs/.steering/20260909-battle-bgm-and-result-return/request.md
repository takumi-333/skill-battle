## docs/issues/issue-31.md

# 戦闘BGMの導入

対象のBGM: PeriTune_Rising_Tension.mp3

## やってほしいこと
まずBGMのファイル名を戦闘用BGMとして書き換える
そして適切な場所に配置して導入する

## 戦闘BGMと戦闘の連動の仕様
1. 戦闘のReady, Fightの後試合開始と同時に、この曲が流れ始める
2. 試合終了時には、音楽を停止する
3. 特に制限時間での試合終了時には、少しずつ音量を下げるフェードアウトにする
4. さらにスキルを発動する集中状態のときは、音がこもって小さく聞こえる演出にする
    これは集中していて周りの音が聞こえづらくなっているのを表現

## docs/issues/issue-32.md

# リザルト画面の挙動の修正

## ロビーへ戻るボタンを押したときの挙動

現行：
    オンライン対戦で片方がロビーへ戻るボタンを押すともう一方もロビー画面へ移動する
修正後：
    オンライン対戦で片方がロビーへ戻るボタンを押すともう一方はロビー画面へ戻らない
    ただし、
    - 再戦希望状態を解除され、再戦ボタンがdisabledとなる
    - つまりロビーへ戻る選択肢しか受け付けない状態にはなるが、リザルトは引き続き見れる
