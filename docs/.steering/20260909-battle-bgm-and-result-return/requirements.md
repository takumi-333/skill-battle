# 要求

## 戦闘BGM

- 提供された `PeriTune_Rising_Tension.mp3` を戦闘用の名前で `assets/audio/` に配置する。
- Ready 表示後、FIGHT と同時に再生を開始する。ローカル、従来のホスト対戦、専用サーバー対戦の各クライアントで重複再生しない。
- 通常の試合終了では停止し、制限時間切れでは短いフェードアウトで停止する。
- いずれかのプレイヤーが集中課題中なら、BGM の音量を下げ、ローパスフィルタでこもった音にする。集中終了後は通常へ復帰する。

## オンライン・リザルト

- オンライン対戦の一方が「ロビーへ戻る」を選んでも、もう一方の画面はリザルトを維持する。
- 残ったプレイヤーの再戦希望を解除し、再戦ボタンを無効化する。ロビーへ戻る操作は引き続き可能にする。
- 両者がロビーへ戻った時点でのみ、ルーム全体を通常のロビー状態へ戻す。
- 専用サーバーの判定を正とし、既存のホスト対戦にも同じ挙動を適用する。

## 検証

- セッション単体テストで片側ロビー復帰時の受信者別フェーズと再戦不可を検証する。
- Godot のヘッドレス起動と既存テストを実行する。
