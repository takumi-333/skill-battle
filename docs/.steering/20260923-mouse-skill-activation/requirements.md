# 要求内容

## 概要

対戦HUDの通常攻撃・3つのスキル枠を、既存の1〜4キーに加えてマウスクリックでも発動できる操作部品にする。発動可能な枠はホバーと押下に反応し、詠唱者がマウス主体で操作しても押せることを明確にする。

## 背景

詠唱者の課題はポインターで図形をなぞるため、スキル開始もマウスで完結できる必要がある。現在のスキル枠は表示専用でマウス入力を無視している。

## 実装対象の機能

### 1. 共通のスキル発動要求

- キー入力とHUDクリックを、スロット番号による共通の発動要求へ集約する。
- ローカル・ホストでは既存の発動関数を呼び、オンラインクライアントでは既存のネットワーク入力経路へ一度だけ要求を流す。
- 対戦中でない、観戦中、課題中の要求は無視する。サーバー権威の判定は維持する。

### 2. クリック可能なスキルHUD

- スキル菱形の固定レイアウトとアイコン表示を維持したまま、HUD枠が左クリックを受け付けるようにする。
- 発動可能なときだけホバー、押下、指カーソルの反応を出す。
- クールダウン、集中・行動阻害、課題中、観戦中は非活性にし、クリックを受け付けない。

## 受け入れ条件

### 共通のスキル発動要求

- [ ] 1〜4キーと対応するHUD枠のクリックが、同じ操作種別を要求する。
- [ ] オンラインクライアントのクリックは既存のDedicated Server向けイベントまたは従来の入力同期を通り、二重送信しない。
- [ ] 課題中のクリックが詠唱者のなぞり入力を妨げない。

### クリック可能なスキルHUD

- [ ] 発動可能な枠はホバーと押下で視覚的に反応し、指カーソルを表示する。
- [ ] 非活性の枠はホバー反応とクリック発動を行わない。
- [ ] 既存のクールダウンと封印表示が維持される。

## スコープ外

- キーバインド変更画面の追加
- スキルの効果、クールダウン、課題採点の変更
- マウスによる移動・照準操作の追加
