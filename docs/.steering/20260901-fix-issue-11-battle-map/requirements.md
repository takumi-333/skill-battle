# 要求事項

## 目的

issue-11 に対応し、より広い対戦マップとプレイヤー中心の視点、通常攻撃中の位置・向き固定を実現する。

## 要求

- 対戦マップを 3840×1740 px にする。
- P1 を `(300, 390)`、P2 を `(3580, 390)` から開始させる。
- 試合中は各クライアントの操作プレイヤーを画面中央に捉える。ローカル対戦では現在の操作対象を中央に捉える。
- 通常攻撃の開始から完了まで、攻撃者の位置と向きを固定する。
- 左上を向いた通常攻撃も、他の方向と同様に判定・エフェクトを出す。
- 既存の HUD とネットワーク同期を維持する。

## 受入条件

- P1/P2 が指定座標に出現し、広いマップ内を移動できる。
- 操作中のプレイヤーが常に画面中央に表示され、HUD は追従によって移動しない。
- 通常攻撃中に移動入力をしても位置・向きが変わらない。
- 左上向きの通常攻撃でヒット判定と攻撃エフェクトが発生する。
- Godot のスクリプトチェックでエラーが発生しない。
