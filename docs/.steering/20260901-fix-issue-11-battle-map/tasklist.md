### 実装結果

- アリーナを 3840×1740 px とし、P1/P2 の開始位置をそれぞれ `(300, 390)`、`(3580, 390)` に設定した。
- ワールド描画だけに座標オフセットを適用し、各クライアント（ローカル対戦では操作対象）のプレイヤーを画面中央に表示するようにした。HUD は `Control` のまま固定される。
- 通常攻撃開始時に `attack_facing` を記録し、攻撃中は移動・向き更新を止め、命中判定と攻撃エフェクトにも記録した向きを使うようにした。
- 左上を含む全方向で、開始時に正規化した向きを使用して通常攻撃の判定・エフェクトが一致する。
- Godot 4.7.2 の `--headless --editor --quit` と `--headless --quit-after 5` を実行し、スクリプトエラーなしを確認した。

### 残課題

- ヘッドレス環境では Windows の証明書ストアと Godot の `user://logs` への書き込みに関する環境由来の警告が出る。GUI での実機操作による視点と斜め攻撃エフェクトの見た目確認は未実施。
