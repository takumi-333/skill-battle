# 設計

## 方針

ワールド描画だけにオフセット変換を適用する。これにより、既存の `Control` ベース HUD をカメラ追従で動かさず、操作プレイヤーを画面中央へ表示する。

## 実装

- `ARENA` を原点基準の 3840×1740 に更新する。
- `MatchState` と試合開始時の P2 初期座標を 3580 に更新する。
- 操作プレイヤーのワールド座標から、ビューポートの半分を引いたカメラ原点を求め、マップ端でクランプする。
- `_draw()` のワールド描画範囲だけにその原点の逆変換を適用し、描画後に戻す。
- プレイヤー状態に `attack_facing` を保持する。攻撃開始時に `facing` を記録し、攻撃中は移動・向き更新を抑止する。
- 命中判定とエフェクト描画は `attack_facing` を優先して使用する。

## 互換性

カメラはローカル描画のみであり、ネットワーク同期するワールド座標は変更しない。追加する `attack_facing` は既存のプレイヤー状態辞書と同様に同期可能な値である。
