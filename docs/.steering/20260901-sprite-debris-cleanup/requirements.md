# 要求定義

## 目的

64×64pxへ正規化した個別スプライトに、キャラクター本体から離れた孤立画素や小さな連結成分が残った場合に、決定論的に除去し、採用前に残留ごみがないことを機械検査できるようにする。

## 機能要件

- alphaマスクの8近傍連結成分を検出する。
- 最大成分をキャラクター本体の基準成分とし、基準成分から設定距離を超える成分を不要片候補として扱う。
- 距離、最小成分面積、除去画素上限をasset specで設定できる。
- 除去した成分・画素数・距離をJSONレポートへ記録する。
- `--check-only`で画像を変更せず、離れた成分が残っていれば終了コード1にする。
- 通常モードでは除去後のRGBA画像を出力し、除去後にも離れた成分が残っていないことを最終確認する。
- `validate_sprite.py`の最終検査から、各セルの残留ごみを検出できる。
- 既存の背景除去、pixelization、組版、採用フローを壊さない。

## 非機能要件

- alphaは0/255の二値を維持する。
- 固定パレットのRGB値を変更しない。
- 文字・背景・影などの意味判定は行わず、距離と連結成分だけで判定する。
- 除去が設定上限を超える場合は、画像を採用せずエラーとする。

## 受入条件

- 離れたごみを含むfixtureが通常モードで除去される。
- 本体に近い杖・髪・衣装の分離成分は保持される。
- `--check-only`が残留ごみを非0で検出する。
- スプライトvalidatorのレポートにフレームごとのごみ検査結果が残る。
- ガイドとツール一覧に、組版前のcleanupと採用前のfinal checkが記載される。
