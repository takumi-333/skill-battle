# 要求事項

## 目的

issue-9に対応し、通常攻撃の円弧描画を職業ごとのスプライト演出へ置き換える。

## 要求

- 打鍵士の通常攻撃は、ハンマーによる打撃と金色・緑色の残光として表示する。
- 算術士の通常攻撃は、前方へ現れる積分記号の魔法としてフェードイン表示する。
- 詠唱者の通常攻撃は、紫と桃色を基調とする魔法の斬撃として表示する。
- 表示する効果範囲は、既存の通常攻撃扇形（射程74、正面±55度）と視覚的に対応させる。
- 命中判定、ダメージ、攻撃クールダウン、ネットワーク上の攻撃処理は変更しない。
- 従来の円弧は攻撃時に表示しない。
- 各エフェクトは、透明背景の64×64px PNGピクセルスプライト4フレームで構成する。
- 4フレームは、横4コマ（256×64px）のスプライトシートとしてゲームへ配置する。
- 打鍵士・詠唱者の軌跡は太い扇形で塗りつぶさず、細い振り下ろしの線と粒子で表現する。

## 受入条件

- 3職の通常攻撃で、それぞれ4コマの固有スプライトシートがアニメーション表示される。
- 各シートが256×64px、RGBA（透明背景）であり、4セルすべての前景が空でない。
- 算術士の積分記号は攻撃開始時に透明から表示される。
- 攻撃エフェクトは向きに追従し、正面の扇形攻撃範囲と大きく乖離しない。
- 通常攻撃の命中条件とダメージ量が従来どおりである。
- Godot起動時にスクリプトエラーが発生しない。
