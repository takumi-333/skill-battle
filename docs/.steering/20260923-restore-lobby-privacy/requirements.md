# 要求

- `duel`（1 vs 1）のロビーは、FFA を開いた後でも既存のカード・プレビュー・操作ボタンの位置へ戻す。
- 対戦ロビーでは、自分以外の参加済みプレイヤーのキャラクターをシークレット用の影画像で表示する。
- この秘匿表示は `duel` と `free_for_all` の両方に適用する。
- 自分の選択キャラクターと既存の Ready・開始操作は維持する。

# 受け入れ条件

- FFA ロビーを表示した後に duel ロビーを表示しても、duel の2カード配置がシーン定義どおりになる。
- 参加済みの相手の `visual_id` が何であっても、ロビーの相手プレビューは `SHADOW_IDLE_TEXTURE` である。
- Godot のUIテストで duel / FFA の配置と秘匿表示を確認できる。
