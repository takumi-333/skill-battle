# オンライン対戦操作・UI修正 要求仕様

## 操作

- オンライン対戦中の両プレイヤーの移動は矢印キーに統一する。
- 小技は通常の数字キー `1`、大技は通常の数字キー `2` に統一する。
- 通常攻撃は Space キーに統一する。
- NumPad、ASDW、Enter は通常攻撃・スキル開始の操作として使用しない。
- 課題入力中の Enter 送信や Esc 中止など、課題UI固有の操作は維持する。

## 対戦HUD

- 画面上部中央に試合時間を表示する。
- 各プレイヤーには、自分のHPと通常攻撃・小技・大技のクールダウンだけを表示する。
- 操作説明、相手の情報、試合中の画面下部ステータス文は表示しない。
- ホストと参加者で表示内容を変えない。

## 受け入れ条件

- ホスト・参加者の双方が同じキー操作で移動、通常攻撃、小技、大技を実行できる。
- 旧キー操作で意図しない通常攻撃・スキル開始が起きない。
- 両者の対戦HUDが残り時間、自分のHP、自分のクールダウンだけになる。
- GDScriptのパースエラーがない。
