# オンライン対戦操作・UI修正 設計

## 操作入力

`match_prototype.gd` の対戦中入力を共通化する。ホストのローカルプレイヤー1と参加者のローカルプレイヤー2は、いずれも矢印キーを読み取る。ホスト上のプレイヤー2は、参加者から受信した入力状態を使う。入力状態の `attack`、`small`、`big` も同じキー（Space、1、2）から生成する。

課題入力のテキスト送信は Enter を利用するため、対戦操作の通常攻撃とは分離して維持する。

## 対戦HUD

ローカルプレイヤーIDから表示対象のプレイヤー状態を選び、単一の自分用ラベルへHPと3種類のクールダウンを表示する。タイマーは中央に配置する。相手用ラベル、操作説明、ステータスラベルは対戦HUDでは非表示にする。

結果画面やロビー画面の既存UIは変更しない。試合中に不要な文言が再表示されないよう、`set_gameplay_hud_visible()`でもステータスと操作説明を表示対象から外す。

## 検証

- `rg` で旧対戦キー（ASDW、Q/E、Num0/Num9、Enter攻撃）が残っていないことを確認する。
- Godotヘッドレスのエディタ起動と短時間実行でパース・実行エラーを確認する。
- コード上でホストと参加者の入力経路が同じキー定義を使うことを確認する。
