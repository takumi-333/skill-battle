# 要求

## 対象

Dedicated Server を用いるオンライン対戦のロビー、リザルト、再戦遷移を対象とする。

## 機能要件

1. ロビー段階で片方の peer が切断したとき、残った peer の phase は `lobby` のままとする。
2. 切断 slot を `connected_slots` から除外し、クライアントのロビー表示から相手のシルエットと状態表示を消す。
3. 試合中の切断は従来どおり、残ったプレイヤーの勝利として `result` へ遷移する。
4. リザルトの「もう一度対戦」は各 peer の意思として記録し、2 人とも選択するまで試合を開始しない。
5. 片方が「ロビーへ戻る」を選んだら、直ちに両クライアントをロビーへ遷移させる。そのためリザルト画面は消え、相手側の再戦ボタンも操作できない。
6. 再戦の選択状況を snapshot に含め、リザルト画面で自分の選択済み状態と相手の待機状態を表示する。

## 非機能要件

- phase と画面遷移は Dedicated Server の snapshot を正とし、クライアントだけで試合開始を決定しない。
- 既存の試合中の切断処理、ロビーの Ready とゲーム開始の条件を壊さない。
- 既存の headless テストおよび Godot 起動確認を通す。
