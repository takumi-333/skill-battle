# 3キャラクター・ドット絵8方向スプライト実装 — 要求

## 目的

打鍵者の試験結果を採用し、打鍵者・算術士・詠唱者の全員を、斜め上見下ろしの2Dドット絵キャラクターへ統一する。8方向の停止・移動アニメーションを、実際の対戦画面の移動に反映する。

## 共通スプライト仕様

- 1セルは64×64px、8列×5行、合計512×320pxのRGBA透過PNGとする。
- 列は左から、下 / 下左 / 左 / 上左 / 上 / 上右 / 右 / 下右の8方向とする。
- 1行目は停止、2〜5行目は4フレームの歩行ループとする。
- 斜め上見下ろし（3/4トップダウン）のドット絵で、頭頂・肩・足元が見えるアクションRPG視点に統一する。
- 左右反転を使わず、すべての方向を個別に描く。
- 背景・地面・影・文字・罫線・ロゴ・透かしを含めない。

## キャラクター契約

### 打鍵者

- 既存の試験用素材を採用する。
- 短い黒髪、細い黒縁眼鏡、白シャツ、暗色パンツ、青いルーン刺繍の短い魔導士コート、革ベルト、護符、ルーンペンダントを固定要素にする。

### 算術士

- 成人男性。肩に届く少し長い髪、端正でスマートな体格。
- 深い青または紺のローブ、博士帽、金のアクセントを固定要素にする。
- ファンタジーの魔導学者として、ローブに幾何学・数式を連想するルーン刺繍や小さな魔法具を加える。

### 詠唱者

- 成人女性。華やかな魔法使いで、上品でゲーム内で読みやすい衣装にする。
- 紫基調のローブ、金または淡色の装飾、髪飾り・耳飾り・ネックレスなど複数のアクセサリーを固定要素にする。
- 豊かなバストラインは衣装のシルエットで自然に表し、過度な露出は避ける。

## ゲームへの反映

- 既存の大判アニメ調PNGを描画に使用せず、3人の64pxドット絵シートを使用する。
- 停止中は停止行、移動中は4フレームの歩行行を使用する。
- 現在の移動ベクトルを8方向の列へ対応させ、上下・左右・斜めで異なるセルを描画する。
- キャラクターの表示を、能力・課題ロジックの内部IDと独立させる。
- HP、集中、中断、攻撃範囲など既存ゲームプレイの仕組みは維持する。

## 受け入れ条件

- `assets/characters/` に、3キャラクター分の512×320px・RGBA・40セルのドット絵シートがある。
- ロビーで選択した3キャラクターが、対戦画面でそれぞれのドット絵として表示される。
- 停止・上下・左右・斜め移動で、正しい方向の停止または歩行フレームが描画される。
- 既存のスキル・課題・対戦ルールは変わらない。

## 範囲外

- 攻撃・被弾・スキル発動専用の追加アニメーション
- 追加キャラクターの作成
- スキル・課題の仕様変更
