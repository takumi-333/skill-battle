今の実装状況、現状の公開手順だけでは「友人がすぐ遊べる配布」までは完結していません。


しかし想定している遊ぶ流れはこうです。
1. 私が、ゲームサーバーを自分のPC上で起動する
2. 私がゲームクライアントを自分のPC上で起動する
3. 私の友人が、windows PCで、Godotやそのほかツールは入れずに、ゲームクライアントを起動して、私のサーバに接続（もし何か必要な情報があるなら渡す。トークンキーとかは）
4. 「オンライン対戦」で、どちらか片方がルームを作成、もう片方が一覧から参加する。

そこで上記が実現できるようにしてほしい。
おそらくクライアントの配布用 Windows ビルドを作成する工程を検討し、実装する必要があるのかと。
実運用なら Windows クライアントをエクスポートして配布する仕組みを追加するのが自然です。
