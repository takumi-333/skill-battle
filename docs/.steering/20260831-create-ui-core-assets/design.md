# 設計書

## 方針

生成画像は各アセットを個別の透過PNGとして出力し、プロジェクト内の `assets/ui/` に配置する。テキストをゲーム内で差し替えられるよう、ボタン素材には文字を含めない。

## アセット設計

| 管理名 | 出力ファイル | 基準サイズ | 設計 |
| --- | --- | --- | --- |
| `ui_logo_title` | `assets/ui/logo_title.png` | 横長（1024px角出力から余白込みで使用） | 「SKILL BATTLERS」を読み取れるロゴ。深夜のアーケード感、ダークネイビー、ネオンピンク、控えめなティールを用いる。 |
| `ui_button_primary` | `assets/ui/button_primary.png` | 400x80px | 文字なし。主操作用にネオンピンクを主強調とし、ラベルの可読領域を残す。 |
| `ui_button_secondary` | `assets/ui/button_secondary.png` | 160x56px | 文字なし。補助操作用にダークパープルとティールを基調とし、主ボタンより低い視覚優先度にする。 |

## 実装の順序

1. 既存の画面コンセプトと世界観を参照して、3画像を個別に生成する。
2. 生成物を確認し、透明背景・文字・余白・用途適合を検査する。
3. `assets/ui/` に配置し、UIアセット台帳へ実ファイル情報を反映する。

## 検証方針

- PNGの幅・高さ・アルファチャンネルを確認する。
- タイトルロゴの表示文字を目視確認する。
- `git diff --check` でMarkdownの形式エラーがないことを確認する。
