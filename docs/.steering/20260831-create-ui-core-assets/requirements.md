# 要求内容

## 概要

UIアセット台帳に定義されたタイトルロゴ、主ボタン、副ボタンを、ゲームで参照できるPNGアセットとして作成する。

## 背景

UI刷新に必要な基本アセットを先行して整備し、以後の画面実装で共通利用できる状態にする。

## 実装対象

### 1. タイトルロゴ

- `SKILL BATTLERS` のタイトルロゴを透過PNGで作成する。
- 1280x720のタイトル画面で横長に配置できる十分な解像度と余白を持たせる。

### 2. 主ボタン

- 主要アクションに使う横長のボタン背景を透過PNGで作成する。
- 台帳の規格（幅360～420px、高さ72～88px）に収まる基準サイズとする。

### 3. 副ボタン

- 戻る・補助操作に使う横長のボタン背景を透過PNGで作成する。
- 台帳の規格（幅120～180px、高さ48～56px）に収まる基準サイズとする。

## 受け入れ条件

- [ ] 3アセットが `assets/ui/` 配下に透過PNGとして配置されている。
- [ ] タイトルロゴに `SKILL BATTLERS` の文字が読み取れる。
- [ ] 主ボタンと副ボタンが文字なしの背景素材であり、既存フォントでラベルを重ねられる。
- [ ] 寸法・用途・配置先がUIアセット台帳に反映されている。
- [ ] 画像ファイルとして読み込めることを確認している。

## スコープ外

- Godot画面への組み込み・ボタン動作の変更
- ホバー、押下、無効など状態別画像の作成
- 他のUIアセットの作成
