# 要求

- ホームのデバッグ入口を廃止し、オンライン対戦、練習、キャラクター、ユーザー設定、チュートリアル、CPU対戦を表示する。
- チュートリアルには対戦開始から操作、通常攻撃、スキル1～3、課題の点数と効果、勝敗までを体験する導線を用意する。
- スキルの 1～4 キーと HUD クリック操作を説明し、実際の既存入力を使わせる。
- CPU対戦では自分と相手のキャラクターを選び、相手の強さを1～3で選べる。
- CPUは移動、通常攻撃、スキル課題を人間の対戦と同じ試合処理で実行し、課題には所要時間と成功率を持たせる。
- レベルが上がると反応、照準、課題の成功率と得点が上がる。
- 既存のオンライン対戦と練習の挙動を維持する。
