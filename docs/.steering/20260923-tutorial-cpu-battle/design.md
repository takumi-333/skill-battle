# 設計

固定UIは画面シーンに定義し `main.tscn` に配置する。ホームからチュートリアルの説明画面とCPU対戦の設定画面へ遷移する。旧デバッグ画面は導線と画面登録から取り除く。

CPU対戦は既存のローカル2人対戦を使用する。人間はslot 1、CPUはslot 2に固定し、CPUの移動方向を既存 `update_player` に渡す。CPUの通常攻撃とスキルは既存の実行関数を使い、スキル課題だけは別のタイマーで段階的に進める。課題中はCPUを集中状態にし、終了時に既存のスキル効果関数へ点数を渡す。タイマー、失敗率、点数は難易度で変える。

チュートリアルは同じローカル対戦に段階的なガイドを重ね、相手は弱いCPUにする。移動、通常攻撃、課題成功を検知し、全操作を体験したら自由対戦に移行する。既存のHUDアイコンとキー入力を使う。

画面表示は `apply_screen_state` と `UIScreenManager` に集約する。対戦結果からの再戦は同じ設定で再開する。
