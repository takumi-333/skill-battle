# 要求内容

## 概要

詠唱者の一筆書き課題で、キャンバス内から描き始めた軌跡をキャンバス外で離しても、必ず採点と課題終了処理を行う。

## 背景

現在はマウスアップ時にもキャンバス内判定を行うため、外側で離すと採点されず筆跡が残る。

## 受け入れ条件

- [ ] キャンバス内で開始し、キャンバス外で左マウスボタンを離した場合に採点が開始される。
- [ ] 成功・失敗の既存処理を経由し、筆跡が残らない。
- [ ] キャンバス外からの押下では筆跡や採点を開始しない。
- [ ] ローカル・クライアント・専用サーバー接続時の既存送信経路を維持する。

## スコープ外

- なぞり採点アルゴリズムおよび合格ラインの変更。
- タッチ入力仕様の追加。
