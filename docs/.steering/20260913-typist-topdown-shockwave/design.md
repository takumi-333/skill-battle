# 設計

## 素材

既存の左向き横視点素材を、左向きを基準にした真上視点の地面衝撃波へ差し替える。出力キャンバスは 64x64px とし、効果本体を中央に収めて、45度回転時にも透明余白内に収まるようにする。

## 描画

`match_prototype.gd` で新素材を `preload` する。三叉震槌が生成する5本のスキル弾に専用フラグを記録する。

描画時は弾の速度ベクトルの角度から左向き基準（PI）を差し引いた回転を計算し、`draw_set_transform` を使って同じテクスチャを5方向の弾として描画する。着弾後に広がる既存の円形衝撃波は従来の円弧描画を残す。

`draw_set_transform` の後に変換をリセットし、後続の描画へ影響させない。

## 当たり判定

`scripts/data/typist_hammer_shockwave_hitbox.gd` に、PNG の alpha が 0 より大きいピクセルを一度だけ抽出する共有ユーティリティを置く。各ピクセル中心を描画と同じ拡大率・回転・位置へ変換し、プレイヤーの楕円ヒットボックスまたは分身の円形ヒットボックスと重なるかを確認する。

三叉震槌が生成する5方向の弾だけに専用フラグを設定し、ローカル実装と専用サーバー実装はこの共有ユーティリティで円形弾半径判定を置き換える。着弾後に広がる既存の円形波動は従来の判定を維持する。

## 検証

- PNG が 64x64px、RGBA であり、透明背景を保持していることを確認する。
- GDScript の構文とネットワーク用シミュレーションテストを実行する。
- 透明ピクセルが外れ、不透明ピクセルが当たるユーティリティテストを実行する。
- Godot をヘッドレス起動して読み込みエラーがないことを確認する。
