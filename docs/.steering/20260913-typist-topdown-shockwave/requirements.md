# 要求

## 目的

打鍵士のスキル「三叉震槌」で使う衝撃波を、上下左右および斜め方向へ共用できる真上視点のスプライトとして表現する。

## 機能要件

- `assets/effects/typist_hammer_shockwave.png` を、透明背景・64x64px の真上視点の方向性衝撃波へ置き換える。
- スプライトの基準方向は左向きとし、回転して全8方向に使用できる余白を確保する。
- 三叉震槌の着弾後に5方向へ発射するスキル弾へ、このスプライトを割り当て、弾の進行方向へ回転して描画する。
- 5方向のスキル弾の当たり判定は、描画時と同じ位置・回転・拡大率で配置した PNG の不透明ピクセルだけを攻撃範囲とする。
- 相手と分身は、不透明ピクセルがそれぞれの当たり判定へ重なった場合だけ衝撃波の影響を受ける。
- ローカル対戦と専用サーバー対戦で同一の不透明ピクセル判定を使用する。
- 着弾後に広がる円形波動の描画・当たり判定は変更しない。
- 衝撃波のダメージ、ノックバック、発生間隔、寿命など既存のゲームロジックは変更しない。

## 非機能要件

- ピクセルアートの輪郭を保ち、透明背景を維持する。
- 回転時にスプライトが切れない。
- 既存の専用サーバー／クライアント同期で衝撃波を描画できる。
- 透明ピクセルが当たり判定にならない。
