# 要求

- 打鍵士スキル2「三叉震槌」の着地点から、ハンマーに隠れず波紋・亀裂が連続して見えるようにする。
- 三叉震槌のハンマーが着地して効果を発生させた瞬間に、0.2秒間の画面揺れを再生する。
- 練習・ローカル対戦・Dedicated online client の各経路で同じ演出契約を満たす。
- 既存の画面揺れ強度（スコアに応じて4〜12px）および波動命中時に揺らさない仕様を維持する。

# 受け入れ条件

- 着地後のハンマー画像の上にも、着地点を中心とした波紋と亀裂が視認できる。
- 着地より前には画面揺れが始まらず、着地時に一度だけ始まる。
- Dedicated snapshot を受け取るクライアントでも、同一の着地につき一度だけ揺れる。
- 関連する自動テストとGodot起動確認が通る。
