# 設計

## 波紋の描画

三叉震槌は波紋・亀裂を描いた後にハンマー画像を重ねていたため、波紋がハンマーの不透明部分で欠けていた。ハンマーを先に描画し、着地点の波紋・亀裂を後段で描画する。着地前は波紋のアルファが0のため、振り下ろし演出の見え方は変えない。

## 着地時の画面揺れ

ローカル処理では、開始時ではなく `update_trident_impacts` が未解放の三叉震槌を解放する時点で画面揺れを開始する。

Dedicated online client では画面揺れ状態をサーバー同期しない。スナップショット内の三叉震槌が `released: false` から `true` に遷移したことをクライアントで検出し、そのIDを一度だけ消費して画面揺れを開始する。複数の同時三叉震槌とスナップショットの繰り返し受信に対応するため、個別の安定IDを三叉震槌状態に持たせる。

## 検証

ネットワークシミュレーションで三叉震槌のIDと着地状態を検証し、UIテストでDedicated snapshotの着地遷移が一度だけ画面揺れを起こすことを検証する。Godotヘッドレステストとメインシーン起動も行う。
