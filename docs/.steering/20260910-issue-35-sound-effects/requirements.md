# 要件

- issue-35 の4つの音源を `assets/audio/` へ英語の役割名で配置する。
- `damaged` はダメージ確定ごとに、ローカル対戦・P2P・Dedicated Server の双方の画面で一度ずつ再生する。
- `game_hit_midheavy` は三叉震槌のハンマー着弾ごとに、双方の画面で一度ずつ再生する。
- `skill-miss` はタイピングミス、算術の回答ミス、詠唱者のなぞり失敗で赤色フラッシュ／横揺れを開始するのと同時に再生する。
- `writing-sound` は詠唱者がキャンバス内を左ボタン押下中に動かしたときだけ本人の画面で再生し、停止・ボタン解放・課題終了時には止める。
- 各キャラクターのベース仕様と該当個別スキル仕様に、再生条件と可聴範囲を記載する。
- 既存の音声機能とネットワーク同期を壊さず、ヘッドレステストおよび Godot 起動で確認する。
