# 設計

## 課題種別

`challenge_definition.challenge_type` を優先する共通ヘルパーを `match_prototype.gd` に追加する。ネットワーク受信側では課題定義がないため、受信した課題IDの意味を保持するフォールバックとして `typing`、`arithmetic`、`tracing` を識別する。各入力受付・表示切替・制限時間判定はこのヘルパーを利用する。

## 待機画面

相手側プレビューのテクスチャは接続状態ではなく、ローカル側に応じた相手枠へ常に `SHADOW_IDLE_TEXTURE` を設定する。接続状態は既存のステータスアイコンで表現する。

## クールダウン背景

スキルアイコンと同じ進行値・利用不可状態を背景用 `ShaderMaterial` にも渡す。背景はアイコンの拡大処理を行わず、マスク内の放射状進行に合わせて明度を変える。
