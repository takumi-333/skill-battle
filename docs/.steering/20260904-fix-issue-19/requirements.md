# 要求事項

## 対象

- オンライン待機画面の相手キャラクター枠に `shadow_idle.png` を表示する。
- スキルアイコンのクールダウン進行に応じて、前景アイコンと背景の暗さを連動させる。
- `big_typing_keycap_ii` をタイピング課題として入力判定・表示制御・ネットワーク処理する。
- 既存の小技、大技、スキル3、算術、トレースの挙動を維持する。

## 受け入れ条件

- 相手未接続・接続済みの待機画面で、相手枠に人影が表示される。
- クールダウン中に背景も暗くなり、クールダウン完了へ向けて明るくなる。
- 鍵片追弾の課題で文字入力が成功・ミスとして処理され、完了後に課題が閉じる。
- Godot のヘッドレス起動でエラーが発生しない。
