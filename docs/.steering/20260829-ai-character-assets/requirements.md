# AI生成キャラクターアセット適用 — 要求

## 目的

対戦画面で使用する打鍵者・算術士・詠唱者の表示を、AI生成した2Dキャラクター画像へ置き換える。現時点では能力・攻撃内容と見た目を結び付けない。

## 今回の到達点

- 3キャラクターそれぞれについて、待機用1フレームと移動用4フレームからなる全身のAI生成スプライトを用意する。
- 3画像を同じ見下ろし2D対戦画面で読み取れる統一画風・サイズ・向き・足元位置に揃える。
- 既存の `blade`、`arithmetic`、`chanter` という表示用アセットIDを、キャラクター名に対応する中立的なIDへ置き換える。
- ロビーと対戦画面で、打鍵者・算術士・詠唱者の各画像を表示する。

## キャラクター契約

### 共通

- 透過背景のPNG、1キャラクターのみ、文字・ロゴ・透かしなしとする。
- 見下ろしマップ上で区別できる簡潔なアニメ調の2Dゲーム用イラストにする。
- 右を向いた全身の立ち姿を基本にし、全キャラクターでキャンバスと足元の位置を統一する。
- 本タスクでは待機1フレームと、足運びが分かる4フレームのループ移動アニメーションを対象とする。攻撃ポーズ、被弾ポーズ、技エフェクトは含めない。

### 打鍵者

- 成人男性。短い黒髪、細い黒縁眼鏡、白いシャツ。
- 細身から標準体型で、真面目・親しみやすい雰囲気。過度にコミカルにしない。
- 白・黒・控えめな寒色を基調にし、小表示でも黒髪と眼鏡を判別できるようにする。

### 算術士

- 成人男性。肩に届く程度の長めの髪、スマートな体格。
- 深い青または紺の端正なローブと博士帽を固定要素にする。
- 紺・青・金を基調にし、学究的で落ち着いた印象にする。

### 詠唱者

- 成人女性。華やかな魔法使いとして、上品でゲーム内で読みやすい衣装にする。
- 紫基調のローブ、金または淡色の装飾、複数のアクセサリーを固定要素にする。
- 豊かなバストラインは衣装のシルエットで自然に表現し、過度な露出は避ける。

## 受け入れ条件

- `assets/characters/` に、3キャラクター分の待機用透過PNGと移動用スプライトシートが追加されている。
- 各移動用スプライトシートは、同じキャンバス・足元位置・右向きを保った4フレームで構成され、連続再生して自然にループする。
- 既存SVGと同等の表示領域で全身が収まり、待機・移動のどのフレームも足元がプレイヤー位置に揃って描画される。
- 対戦画面で3キャラクターの外見上の特徴を区別できる。
- キャラクターを選択・表示するコードに `blade`、`arithmetic`、`chanter` の表示アセット名が残らない。
- 既存のゲームプレイ、スキル種別、課題ロジックの変更は行わない。

## 今回の範囲外

- 攻撃ポーズ、被弾ポーズ、技エフェクト
- 自動画像検査・評価・再生成を行う実行基盤
- スキル、課題、攻撃表現の名称や仕様の確定・変更
