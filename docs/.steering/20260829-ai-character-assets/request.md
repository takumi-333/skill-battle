## キャラのイメージ

### 1. 打鍵者

- 成人男性。短く整えた黒髪と、細い黒縁眼鏡が特徴。
- 白いシャツを基本に、清潔感のあるシンプルな服装にする。必要なら袖を軽くまくる。
- 少しだけオタクっぽい、真面目で親しみやすい雰囲気。過度にコミカルにはしない。
- 細身から標準的な体格。立ち姿はやや控えめだが、表情は集中している。
- 配色は白・黒・控えめな寒色を基調とし、眼鏡と黒髪が小さな表示でも判別できるようにする。

### 2. 算術士

- 成人男性。肩に届く程度の、少し長めで流れのある髪型。
- 知的でスマートな印象。すらりとした体格で、姿勢は落ち着いている。
- 衣服の上から、仕立てのよいローブを羽織る。ローブは深い青または紺を基調にする。
- 博士帽を着用し、学究的なシルエットが一目で伝わるようにする。
- 配色は紺・青・金のアクセント。長めの髪、博士帽、端正なローブを外見上の固定要素とする。

### 3. 詠唱者

- 成人女性。魔法使いらしさを強く打ち出した、華やかな印象。
- 豊かなバストラインを持つが、ゲーム内で読みやすい上品な衣装デザインにする。
- 紫を基調としたローブを羽織る。袖や裾には金色または淡色の装飾を入れる。
- 髪飾り、耳飾り、ネックレス、指輪などのアクセサリーを複数身に着ける。
- 配色は紫・金・淡い差し色。ローブの大きなシルエットと多めの装飾品を外見上の固定要素とする。

# AI生成キャラクター素材の一貫性確保方針

## 目的

2D対戦ゲームで使用する3キャラクター（打鍵者 / 算術士 / 詠唱者）の画像をAI生成で用意する際、キャラクターデザインとゲーム素材としての仕様を一貫させる。

## 基本方針

- 基準絵を参照画像として渡すだけに依存せず、生成・検査・再生成を繰り返す仕組みを設ける。
- キャラクターごとに、髪型、衣装、配色、武器・小物、体格、輪郭線、右向き、足元の位置を固定した「キャラクター契約」を定義する。
- 共通の画風・キャンバスサイズ・透過背景・向き・足元位置を全素材で固定する。
- 本体アニメーションと技エフェクトは別素材として扱う。

## 素材生成フロー

1. 各キャラクターの基準絵（マスター画像）を1枚ずつ作成・採用する。
2. 基準絵とキャラクター契約を入力として、待機・移動・通常攻撃・スキル発動・被弾の各ポーズ／アニメーション素材を生成する。
3. 生成物を自動検査し、合否と不合格理由を出す。
4. 不合格理由を次回プロンプトに追加して再生成する。
5. 合格候補を人が確認し、ゲームに採用する。

## 自動検査の対象

- 画像仕様: 指定キャンバスサイズ、RGBA、透過背景、足元の基準Y座標。
- 構図: キャラクターが1人だけで、右向き、全身が収まり、不要な文字・背景・透かしがないこと。
- デザイン: 基準絵との視覚的な類似度、主要色、衣装、髪型、武器・小物が契約に沿うこと。
- 出力: 合否だけでなく、武器形状・服色・足元ずれなどの再生成に使える理由を記録すること。

## 人による最終確認

自動検査だけでは、動きの自然さ、攻撃の読みやすさ、キャラクターらしさ、フレーム間のちらつきは判定しきれない。そのため最終採用は人が行う。

## 初期実装の優先順位

1. 3キャラクターの基準絵とキャラクター契約を確定する。
2. 各キャラクターの代表ポーズ（待機・移動・通常攻撃）で生成と検査の流れを試作する。
3. 必要な自動検査を実装する。
4. 小技・大技・被弾・技エフェクトへ対象を広げる。

## 注意点

- AIが生成した連番画像はフレームごとに服や武器が変化し、ちらつく場合がある。
- 初期段階では、AIで基準絵と代表ポーズを作成し、採用した絵をもとに手作業または2Dリグで動かす方式も比較対象とする。
