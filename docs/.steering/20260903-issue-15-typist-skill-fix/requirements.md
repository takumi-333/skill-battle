# 要求内容

## 対象
打鍵者のタイピング課題と2種類のスキル発動処理を、`docs/specs/キャラ別仕様書/打鍵者.md`に合わせる。

## 要件
- 課題UIは打鍵者のスキル名を表示し、残り時間のテキストとESC案内を表示しない。
- タイピングはEnter送信ではなく、次の正解キーを1文字ずつ即時判定する。
- ミス時は入力済み文字を保持し、時間ペナルティ・赤色フラッシュ・横揺れを適用する。
- 正解完了時は残り時間から0〜100点を計算し、スコアによらず両スキルを発動する。失敗は時間切れ等のみとする。
- 集中中の移動速度は通常の50%とする。
- 鍵片追弾は入力文字を0.5秒間隔で発射し、ダメージ5+切り捨て(スコア×0.1)、弾速550、存続2秒、非貫通とする。
- 三叉震槌は正面・±60度・±90度の5方向へ発射し、ダメージ50+四捨五入(スコア×0.2)、弾速300、存続5秒、貫通とする。
