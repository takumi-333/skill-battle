# 設計

1. `match_prototype.gd`の定数と課題定義を打鍵者仕様の値へ更新する。
2. 課題表示更新を、スキル表示名・問題文・時間バー中心へ整理する。時間ラベルは空にする。
3. `_input`からタイピング文字を1文字単位で処理し、正解文字との比較、入力保持、ネットワークRPCを同じ処理へ集約する。
4. 残り時間を正規化した式でスコア化する共通関数を追加する。
5. 打鍵者の発射処理を仕様値へ修正し、三叉震槌の5方向発射とスコア条件の周囲波動を既存のゾーン機構で表現する。
6. Godotヘッドレスのエディタ読み込みと実行ログで確認する。

## 周囲波動の追加変更

- 波動は0.5秒間隔で3回発生し、速度150で拡大する。
- 持続時間は50点で1秒、75点で1.5秒、100点で3秒として線形補間する。
- 各波動は命中済みになるまで対象へ判定し、命中時にスコア比例のノックバックを適用する。
- 命中時は共通のカメラオフセットへ0.2秒の画面揺れを設定する。
