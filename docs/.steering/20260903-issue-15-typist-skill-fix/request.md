#　打鍵者スキル修正

@打鍵者.mdのように仕様を修正する

## 課題ウィンドウ仕様修正
- 残り時間はバーで表示するので、テキストはなくてよい。
- 同様にESCで中止の記述もいらない
- 上部はこれから発動するスキル名を表示（例：　鍵片追弾（けんぺんついだん））
- ミスしても入力欄はリセットされない。
- Enterを入力したときにミスか判定ではなく、タイピングの際に次に打つべきキーを打たなかったらミス判定
- スコアは0 ~ 100いずれでも発動する。
    - あくまで失敗条件は時間切れのみ

## スコア計算に仕様変更
すべてのスキルにおいて制限時間に対しての残り時間から計算して0 ~ 100点をつける

そしてスコアは、以下の方針で計算する
- 最初のほうはすごい速度でスコアが落ちていく（80点 ~）
- 途中は緩やかにスコアが落ちていく(50 ~ 70点)
- 最後のほうは急激にスコアが落ちていく（0点 ~ 40点）


計算式例
```
function calcScoreByTimeOnly(remainingTime, timeLimit, A = 0.85) {
  const r = Math.max(0, Math.min(1, remainingTime / timeLimit));
  const score = 100 * (r + (A / (2 * Math.PI)) * Math.sin(2 * Math.PI * r));
  return Math.round(Math.max(0, Math.min(100, score)));
}

```
