# 設計

## オーラ

オンライン状態スナップショットの `typing_zone_level` と `typing_zone_time` はすでに同期されるため、描画経路でローカル対戦限定となっている箇所を特定して解除する。表示は既存の緑色オーラのみとし、残り時間を含む文字列の描画を削除する。

## 貫通弾

サーバー権威シミュレーションの投射物に、対象へダメージ済みかを示す状態を持たせる。詠唱士の十六夜系の貫通弾は、その状態が未設定の場合だけ命中ダメージを適用する。ローカル側も同じ状態遷移にする。

## ブラックホール

既存の全域・距離比例処理を issue-37 の要件として確認し、最大値が220px/秒であることをテストする。視覚用半径はゲーム判定から独立させる。

## 完全写像

コピー候補の許可リストから黄金時間IDが除外されていることをテストで固定する。
