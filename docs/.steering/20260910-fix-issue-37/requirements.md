# 要求事項

## 打鍵士

- オンライン対戦で、黄金時間の効果中であるプレイヤーのオーラを両クライアントに表示する。
- オーラ上の残り時間テキストを表示しない。

## 詠唱士

- 十六夜系の貫通弾は、1発ごとに同じ相手へ1回だけダメージを与える。弾は消滅せず貫通を維持する。
- 月蝕・潮汐のブラックホールはマップ全域を吸引対象とし、0.1秒ごとの吸引量を距離に応じて弱める。
- 最大吸引速度は、100点時で220px/秒（22px/0.1秒）とし、プレイヤー移動速度280px/秒を下回る。

## 算術士

- 完全写像のコピー候補から黄金時間I・II・IIIを除外する。

## 共通

- ローカルとオンラインのルール差を作らない。
- 自動テストとGodot headless起動で検証する。
