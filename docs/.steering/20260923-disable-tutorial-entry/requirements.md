# 要求内容

## 概要

チュートリアル機能を一時的に利用不可にし、ホーム画面の入口を準備中と表示する。

## 背景

チュートリアル画面を現時点で利用者に公開しない。

## 実装対象の機能

### ホーム画面のチュートリアル入口
- ボタンを disabled にする。
- 準備中であることをボタン文言に表示する。
- ボタン操作からチュートリアル画面へ遷移しない。

### 画面遷移の抑止
- チュートリアル画面への遷移要求を受けても、画面を表示しない。

## 受け入れ条件

### チュートリアル入口
- [x] ホーム画面のチュートリアルボタンが無効状態で「準備中」と表示される。
- [x] ホーム画面からチュートリアル画面へ遷移できない。
- [x] 直接の画面遷移要求でもチュートリアル画面が表示されない。

## 成功指標

- チュートリアル画面が通常操作で表示されない。

## スコープ外

- チュートリアル実装や関連仕様の削除。
- チュートリアル対戦ロジックの削除。
