# 設計書

## アーキテクチャ概要

既存のシーン構成を保ったまま、ホームUIと画面遷移管理でチュートリアル入口を閉じる。

## コンポーネント設計

### ホーム画面

**責務**:
- チュートリアルが準備中であることを示す。
- チュートリアルボタンを無効状態で表示する。

**実装の要点**:
- `home_screen.tscn` のボタン文言と disabled 状態を設定する。
- 初期化処理でも disabled を維持し、クリックシグナルを接続しない。

### 画面遷移

**責務**:
- 直接の遷移要求でもチュートリアル画面を表示させない。

**実装の要点**:
- `show_tutorial_intro()` はホームへ戻す。
- `apply_screen_state()` で tutorial_intro を拒否してホームへ置き換える。

## 実装の順序

1. ホーム画面のボタンを準備中・disabledにする。
2. UI初期化と遷移処理でチュートリアル画面を抑止する。
3. ホーム画面仕様と作業記録を更新し、Godotで読み込み確認する。

## 将来の拡張性

再開する場合はホームボタンの有効化と遷移ガードを見直す。
