# 要求内容

## 概要

既存のプレイヤーホスト型 ENet 対戦を、Godot Dedicated Server と FastAPI ロビーによるサーバー管理型対戦へ移行する。

## 今回の受け入れ条件

- Dedicated Server が単一の UDP ポートで複数の独立した 2 人ルームを管理する。
- サーバーだけが入力を検証し、試合スナップショットを生成する。
- FastAPI/SQLite がルーム作成、一覧、参加予約、短命署名トークン、状態通知を提供する。
- 実行・配備・検証に必要な Linux/WSL2/OCI の手順と設定をリポジトリに残す。
- 既存のローカル練習・デバッグ対戦には変更を加えない。

## 制約

- 指定された ideas 文書はユーザーの未保存変更を含むため変更しない。
- 秘密値は環境変数から取得し、リポジトリに保存しない。
- 新規 UI は既存の固定シーン部品化方針に従う。
