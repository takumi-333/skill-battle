# 要件

- 詠唱者のなぞり音が意図した音と異なる原因を、実装と音源の両面から特定する。
- コードや音源の変更は行わず、再現条件と原因を報告する。

## 追加要件（再生制御の修正）

- `writing_sound.wav` はループさせない。
- 左ボタン押下中にキャンバス内でマウスを移動した時、音が再生されていなければ通常再生を先頭から1回開始する。
- 音が再生中である限り、後続のマウス移動では再生位置を戻さない。
- 音が最後まで再生された後、なぞりを続けていて次のマウス移動が来た時だけ、先頭から次の1回を再生する。
- 既存の90ms無操作判定は維持し、無操作になった場合・ボタン解放時・課題終了時は再生途中でも即時停止する。
