# 調査方針

- `writing_sound.wav` の長さ・サンプル形式・ループ点を確認する。
- ループ再生の設定と、マウス移動時の再生開始・停止の実装を照合する。
- 必要に応じて最小の再生確認を行い、音が歪んで聞こえる機構上の要因を切り分ける。

## 追加設計（再生制御の修正）

- `writing_sound_player` にはインポート済みの `WRITING_SOUND` をそのまま設定し、`AudioStreamWAV.loop_mode` を変更しない。
- 既存の `note_challenge_trace_motion()` の「未再生時のみ `play()`」を維持する。これにより、自然終了するまでは連続した1回の通常再生となり、終了後の次の入力イベントだけが再生を開始する。
- `stop_writing_sound()` と90msの無操作検出は変更せず、停止条件でのみ途中停止する。
