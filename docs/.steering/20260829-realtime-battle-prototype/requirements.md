# リアルタイム対戦試作 — 要求

## 目的

「得意な操作を使って戦う、見下ろし型2D対戦アクション」の対戦コアを、同一PCで検証可能な形で段階的に実装する。

## 現在の前提

- 同一PCの2人操作は、ネットワーク対戦前に手触りを確認するためのデバッグ手段とする。
- 画面は2Dの見下ろしマップとし、キャラクター・マップともに2Dデザインで表現する。
- 通常攻撃は飛び道具ではなく、近距離の斬撃とする。

## 今回の到達点

- 2人がマップ内を移動できる。
- 向いている方向の近距離斬撃が相手にのみ命中する。
- HP・制限時間・勝敗を確認できる。
- 丸の仮表示を、2Dキャラクターとマップの視覚的な土台へ置き換える。

## 現在の実装フェーズ

- 打鍵者が小技を開始すると集中状態になり、対戦画面を隠さないタイピング課題UIを表示する。
- 集中中は打鍵者の移動を低下させ、通常攻撃を使えなくする。
- 正しく入力すると、入力時間から算出したスコアに応じた前方弾を発射する。
- `Esc` による任意中止と制限時間切れを実装する。被ダメージによる中断は次のフェーズで扱う。

## 今回の範囲外

- オンライン同期、マッチング、育成・ビルド
- 固有課題（タイピング・計算・なぞり）の完成実装
- 最終アセット・音声・エフェクト
