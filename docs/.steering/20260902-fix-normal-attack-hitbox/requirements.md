# 要求事項

## 目的

通常攻撃で、武器が相手の身体に届いて見えるのに命中しない不整合を解消する。

## 要求

- 通常攻撃の命中判定は、対象プレイヤーの縦長楕円ヒットボックスと攻撃扇形が重なる場合に命中する。
- 内側の死角は設けず、攻撃者の近接位置も扇形内なら命中できる。
- 赤いデバッグ扇形は、実判定と同一の攻撃形状・原点・射程・角度を使用して表示する。
- 武器の先端は、攻撃方向中央にある時、攻撃扇形の外周と一致する。武器は現在より小さくする。
- オンライン時も、ホスト確定状態を使うデバッグ表示を有効にできる。

## 受入条件

- 相手の楕円ヒットボックスに扇形が接すれば通常攻撃が命中する。
- 密着時にも攻撃方向内の相手へ通常攻撃が命中する。
- 赤い外周と武器先端の距離が一致する。
- Godot起動時にスクリプトエラーがない。
