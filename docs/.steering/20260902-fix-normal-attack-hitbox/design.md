# 設計

## 方針

通常攻撃の形状を生成する関数へ集約し、命中判定とデバッグ描画が同じ戻り値を参照する。

## 実装

- `NormalAttackHitArea` を追加し、原点、向き、外側半径、半角を保持する。
- 対象の縦長楕円を、攻撃扇形に対して局所座標へ変換して交差判定する。楕円の近似支持半径を使い、中心点だけで判定しない。
- `try_attack()` とデバッグ描画は同じ `get_normal_attack_hit_area()` を使用する。
- 武器の柄尻基準点を攻撃原点へ合わせ、中央振り時の先端距離を扇形外側半径へ合わせる。素材ごとの透明余白に依存する従来の固定係数を、共通の描画幾何へ置き換える。
- デバッグ表示は全モードで描画し、オンラインのクライアントでは受信済みのホスト状態を表示する。

## 非対象

- ネットワークのラグ補償やロールバックは今回追加しない。命中の最終権威は従来通りホストとする。
