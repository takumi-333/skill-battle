# 設計

## スキル選択と課題

`chanter_big_1` を流月雨のIDとして追加する。キャラクター選択、ローカル試合、Dedicated Serverの選択状態でこのIDを保持する。スキル2開始時はこのIDを判定し、複合紋章用の専用challenge IDと目標ポリラインを設定する。

複合紋章は単一ポリラインとして、上端→右端→左端→下端→上端の外周と、中央の円を連続した評価経路へ組み立てる。既存の双方向Polyline採点を利用し、表示名・課題文も専用化する。

## サーバー権威の隕石状態

`meteor_impacts` をシミュレーション状態へ追加する。発動時に20個の状態を予約し、各状態に位置、予約からの遅延、2秒の落下時間、スコア、着弾済みフラグ、経過時間を保存する。

更新処理では、着弾時に相手との円形当たり判定を評価してダメージを1回だけ適用する。落下地点は相手の位置を中心に疑似乱数で決め、発動者の安全半径・ステージ境界を満たすまで再試行し、失敗時は安全な補正位置を使う。

## クライアント描画

`falling_meteor.png` を隕石本体に用いる。予告中は地面に黒い円影を描き、残り落下時間に応じて拡大する。着弾直前は上方から隕石を落下させ、着弾後は隕石を短時間残し、円弧と薄い塗りで波紋を0.75秒描く。

Dedicated Serverではスナップショットの `meteor_impacts` を描画用状態として使用し、ローカル対戦では同じ配列を直接描画する。

## 検証

ネットワークシミュレーションテストで、候補ID、20個の予約、0.65秒間隔、2秒後の着弾、自傷なし、ダメージ、状態の消滅を確認する。課題形状の構成もテストする。Godotテストとヘッドレス起動を実行する。
