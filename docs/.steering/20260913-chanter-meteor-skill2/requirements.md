# 要求事項

## 目的

詠唱士のスキル2候補として、相手の周囲へ巨大隕石を20個落下させる新スキル「流月雨（りゅうげつう）」を追加する。

## 機能要件

- スキル2候補に「流月雨（りゅうげつう）」を追加し、既存の「望月（もちづき）」は残す。
- 課題は、中央の円と、縦線・横線を共有する上下反対向きの三角形で構成された複合紋章とする。
- 45点以上で発動する。クールダウンは8秒とする。
- 相手の周囲80〜260pxから、安全に配置可能な地点を選び、発動者の周囲120px以内には配置しない。
- 2個ずつを0.65秒間隔で10回、合計20個の隕石を予約する。
- 各隕石は予約から2秒後に着弾する。隕石半径は48px、着弾ダメージ範囲は半径110pxとする。
- 着弾時、相手にだけ `4 + floor(スコア × 0.08)` のダメージを一度与える。発動者自身はダメージを受けない。
- 落下予告は黒い半透明の円影とし、着弾に近づくほど半径を48pxまで拡大する。
- 着弾後は0.75秒かけて半径20pxから150pxへ広がる波紋を表示する。
- ローカル対戦とDedicated Server対戦で同じ結果・演出が再現される。

## 非機能要件

- 落下地点はサーバー側で決定し、スナップショット経由でクライアントに同期する。
- 既存の未コミット変更には触れない。
- 既存の詠唱士スキルおよびネットワーク同期テストを維持する。
