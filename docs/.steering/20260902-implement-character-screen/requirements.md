# 要求仕様

## 目的
ホーム画面から遷移できるキャラクター画面を実装し、3キャラクターの背景・立ち絵・スキルセット・保存操作を確認できるようにする。

## 必須要件
- ホームのキャラクターボタンからキャラクター画面へ遷移できる
- 打鍵者、算術士、詠唱者を画面内で切り替えられる
- キャラクターごとに `assets/ui/character_room/*_background.png` を背景として表示する
- キャラクターごとに立ち絵を表示する
- 3つのスキル枠を横スクロール可能な候補一覧として表示し、候補を選択できる
- SAVEボタンをキャラクター別素材で表示し、選択中のスキル構成を保存する
- ホームへ戻れる
- 既存の対戦・練習画面の遷移と挙動を壊さない

## スコープ外
- 新規スキルアイコンの制作
- スキル効果の対戦・練習ロジックへの接続（既存データ構造が未整備のため、今回の保存状態を次回表示に反映するところまで）
- 5キャラクター対応（現行の選択・立ち絵データがある3キャラクターを対象）
