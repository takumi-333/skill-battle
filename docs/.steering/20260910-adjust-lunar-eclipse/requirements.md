# 要求内容

## 概要

月蝕のブラックホール吸引とレーザー演出を仕様変更する。ブラックホールは判定領域ではなく吸引の中心として扱い、溜め時間とレーザー持続時間を延長する。

## 実装対象の機能

### 1. 吸引ルール

- ブラックホール自体の接触・ダメージ判定は持たせない。
- 吸引範囲内の相手を、ブラックホール中心まで引き寄せる。

### 2. レーザー時間と長さ

- ブラックホールの出現およびレーザー核の溜め時間を1秒から2秒へ変更する。
- レーザー射出時間を1.5秒から2.5秒へ変更する。
- レーザーはブラックホール中心を終点にせず、発射地点から発射方向のマップ端まで伸ばす。
- `assets/ui/skill_effects/chanter_beam.png` を横向きにしてレーザー本体へ使用する。

## 受け入れ条件

- [x] ブラックホール中心に到達するまで相手が吸引され、ブラックホール自体による別判定がない。
- [x] ブラックホール半径とレーザー核が2秒かけて完成する。
- [x] レーザーが2秒後から2.5秒間、発射地点からマップ端まで表示される。
- [x] ローカル対戦とサーバー権威オンライン対戦の挙動が一致する。
- [x] 変更内容を自動テストとGodot起動で検証する。

## スコープ外

- 月蝕のダメージ式、吸引間隔、最大半径、クールダウンの変更。
- ブラックホール・レーザー以外のスキル演出変更。
