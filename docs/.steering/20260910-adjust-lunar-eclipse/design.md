# 設計書

## アーキテクチャ概要

既存の月蝕状態を維持し、時間定数・吸引終端・レーザー描画だけを更新する。判定値は `MatchSimulation` と `MatchPrototype` で共有された仕様に合わせ、オンライン表示は `lunar_eclipses` スナップショットを利用する。

## コンポーネント設計

### MatchSimulation

- ブラックホールは中心位置と吸引半径だけを状態として持つ。
- 吸引処理は対象を中心へ `move_toward` し、32pxで停止する。
- レーザー命中線分は発射地点からマップ境界まで計算する。

### MatchPrototype

- 溜め中は `chanter_beam.png` を横向きの長い矩形として描画する。
- 2秒経過後は同じテクスチャを横向きに拡大してマップ端まで描画する。
- ブラックホール描画は吸引中心の視覚表現のみとし、個別のダメージ判定は追加しない。

## テスト戦略

- 2秒未満ではレーザー射出状態にならないことを確認する。
- 2秒後から4.5秒までレーザー状態が存在し、4.5秒で終了することを確認する。
- 吸引対象が中心近くまで移動すること、中心32px以内で停止することを確認する。
- 既存のサーバーシミュレーションテストとGodotヘッドレス起動を実行する。

## 実装の順序

1. 時間・吸引・レーザー終点のルールを更新する。
2. レーザーテクスチャを横向き描画へ置き換える。
3. テストとドキュメントを更新し、Godotで検証する。
