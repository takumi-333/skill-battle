# 設計書

## アーキテクチャ概要

通常攻撃の数値は、Dedicated Server の `MatchSimulation` とローカル／デバッグ対戦の `match_prototype.gd` にそれぞれ存在するため、両方を同じ値へ更新する。キャラクター基礎ダメージはキャラクター選択時に設定される配列を更新する。

```text
キャラクター選択
  → normal_damage を設定（2 / 1 / 1）
  → 通常攻撃時に既存バフを加算・乗算
  → ダメージを適用

基本クールダウン（3秒）
  → 算術士のみ 3 ÷ 妨害ポイント係数
```

## コンポーネント設計

### `scripts/network/match_simulation.gd`

**責務**:

- オンライン対戦の権威サーバーでダメージとクールダウンを決定する。

**実装の要点**:

- `configure_loadout` の基礎ダメージ配列を `[2, 1, 1]` にする。
- `NORMAL_COOLDOWN` を `3.0` にする。
- 算術士の既存のバフ計算式は変えない。

### `scripts/match_prototype.gd`

**責務**:

- ローカル／デバッグ対戦でオンライン対戦と同等の通常攻撃値を使う。

**実装の要点**:

- 基本クールダウン定数を `3.0` にする。
- キャラクター別の `normal_damage` 初期化を `[2, 1, 1]` にする。

### キャラクター仕様書

**責務**:

- 確定したキャラクター別の通常攻撃値を記録する。

**実装の要点**:

- 3キャラクターの基礎ダメージと3秒のクールダウンを明記する。

## テスト戦略

- 静的検索で旧ダメージ値・旧基本クールダウンが対象の設定箇所に残らないことを確認する。
- Godot の headless 起動でスクリプトの構文・読み込みエラーを確認する。

## 実装の順序

1. Dedicated Server の通常攻撃設定を変更する。
2. ローカル／デバッグ対戦の同等設定を変更する。
3. キャラクター仕様書を更新する。
4. 静的確認と Godot 実行確認を行う。
