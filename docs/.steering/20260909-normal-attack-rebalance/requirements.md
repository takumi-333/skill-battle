# 要求内容

## 概要

通常攻撃の基礎ダメージを打鍵士2、算術士1、詠唱者1へ下げ、基本クールダウンを全キャラクターで3秒へ変更する。

## 背景

通常攻撃を弱化し、スキルと集中状態を中心にした対戦バランスへ寄せる。

## 実装対象の機能

### 通常攻撃の基礎値調整

- Dedicated Server の対戦シミュレーションで、各キャラクターの基礎通常攻撃ダメージを指定値にする。
- ローカル／デバッグ対戦も同じ設定値を使い、対戦経路で結果が分かれないようにする。
- 算術士の既存の係数・加算バフは、変更後の基礎ダメージに対して従来どおり適用する。

### 基本クールダウン調整

- 基本クールダウンを3秒にする。
- 算術士の妨害ポイントによる短縮は、3秒を基準に従来どおり適用する。

## 受け入れ条件

### 通常攻撃の基礎値調整

- [ ] 打鍵士の基礎通常攻撃ダメージが2である。
- [ ] 算術士の基礎通常攻撃ダメージが1である。
- [ ] 詠唱者の基礎通常攻撃ダメージが1である。
- [ ] Dedicated Server とローカル／デバッグ対戦で同じ基礎ダメージになる。

### 基本クールダウン調整

- [ ] 全キャラクターの基本通常攻撃クールダウンが3秒である。
- [ ] 算術士のクールダウン短縮式は3秒を基準に維持される。

## スコープ外

- HP、通常攻撃の範囲・角度・発生時間の変更
- 算術士の係数、通常攻撃バフ、デコイ、その他のスキルの再調整
- 攻撃演出・UIデザインの変更
