# issue-3 修正設計

## UI構成

`match_prototype.gd` の動的UIを拡張する。キャラクター選択画面のテキストプレビューを、キャラ名ラベルと立ち絵用 `TextureRect` に置き換える。練習画面は1体、デバッグ画面はP1/P2の2体を横並びにし、名前を立ち絵の上部へ配置する。

## 自キャラ表示

対戦フィールドの描画時に、オンラインモードかつプレイヤーIDが `local_player_id` の場合だけ、キャラクター上部へ「あなた」を描画する。待機画面の情報ラベルにも同じ識別を使う。

## 待機状態アイコン

`assets/ui/` に imagegen で生成したチェック・ローディングの専用画像を置き、待機画面の各プレイヤー欄に `TextureRect` を追加する。アイコンは名前ラベルの右端付近に配置し、状態に応じて表示・非表示を更新する。入室待ちは `texture = null` とする。

## 表示名

対戦HUDのクールダウン表示は「通常」「スキル1」「スキル2」とし、内部の `small` / `big` 識別子は変更しない。

## 検証

- `godot --headless --editor --quit` でスクリプトとシーンの読み込みを確認する。
- `godot --headless --quit-after 3` で起動時エラーを確認する。
- UI表示要件と旧ラベルの残存を `rg` で確認する。
