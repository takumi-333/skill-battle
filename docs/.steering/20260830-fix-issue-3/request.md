## 練習画面でのキャラクター選択
練習画面のキャラクター選択は、画像１の通り文字とxxxxで切り替えみたいな形になっているが、
以下で構成してほしい。
練習するキャラクターという文字もいらない

- 戻るボタン
- 立ち絵とその立ち絵の上部にキャラの名前
- 左右の切り替えボタン
- このキャラクターで練習

デバッグ機能のキャラクター選択も同様に立ち絵を表示してほしい。
