# issue-3 修正要求仕様

## 1. スキル名称

- 小技の表示名を「スキル1」にする。
- 大技の表示名を「スキル2」にする。

## 2. 自キャラ識別

- オンライン対戦中、ローカルプレイヤーのキャラクターの上に「あなた」を表示する。
- 相手側には「あなた」を表示しない。
- 練習・デバッグなどローカル画面では、自キャラ識別ラベルを表示しない。

## 3. キャラクター選択

- 練習画面から「練習するキャラクター」などの説明文をなくす。
- 練習画面は、戻るボタン、キャラ名付き立ち絵、左右切り替えボタン、開始ボタンで構成する。
- デバッグ画面もP1/P2それぞれのキャラ名付き立ち絵と左右切り替えで構成する。

## 4. オンライン待機画面

- 立ち絵と準備状態の文字を重ねない。
- 「あなた」「対戦相手」の右隣に準備状態アイコンを表示する。
- 準備完了はチェックアイコン、準備中はローディングアイコン、入室待ちはアイコンなしとする。
- アイコンはプロジェクト内の画像資産として保存し、Godotから参照する。

## 5. 受け入れ条件

- GDScriptのパースエラーがない。
- 練習・デバッグの両選択画面で立ち絵、名前、操作ボタンが確認できる。
- オンライン待機画面で状態アイコンが名前の右側に表示され、立ち絵と重ならない。
