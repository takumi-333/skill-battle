# 要求内容

## 概要

Dedicated Server 対戦で、タイピングミス時の課題ウィンドウ演出を復元し、両プレイヤーが互いに独立して課題スキルを開始・進行できるようにする。

## 背景

サーバー権威化により、ミス判定は正しく行われる一方でクライアント演出に伝わらず、課題状態が1件に固定されたため相手の集中中にスキル開始が拒否される。

## 実装対象の機能

### 1. プレイヤーごとの進行中課題

- サーバーは slot ごとに最大1件の課題を管理する。
- 自分が集中中でなければ、相手の課題中でもスキルを開始できる。
- 入力、時間更新、成功・中止・中断、スナップショットを各課題へ正しく適用する。

### 2. オンラインのタイピングミス演出

- サーバーが確定したミスを snapshot の世代番号でクライアントへ通知する。
- 課題所有者のクライアントは、ミスごとに0.22秒の赤点滅と横揺れを再生する。

## 受け入れ条件

### プレイヤーごとの進行中課題

- [ ] P1 が課題中に P2 のスキル開始が受理され、両者が `focused` になる。
- [ ] 両課題が別々に入力・完了・中断でき、片方の終了で他方を消さない。
- [ ] 各クライアントは自分の課題だけを ChallengeLayer に表示する。

### オンラインのタイピングミス演出

- [ ] タイピングミスによりサーバーの時間ペナルティとミス世代番号が更新される。
- [ ] 受信クライアントは新しいミス世代番号を一度だけ演出へ反映する。

## スコープ外

- 2人を超える対戦人数への拡張。
- 課題ウィンドウの固定レイアウト変更。
- 演出音・色・時間の再調整。
