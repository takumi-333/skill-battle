# 要求

- 視覚妨害を受けているプレイヤーの頭上に、デコイと同系統の青いノイズを表示する。
- この頭上ノイズは、本人・相手のどちらの画面でも見える。
- 算術士の現在の強化倍率を示す `f(x) = ax` 表記を、算術士が敵側の場合にも敵HPバーの下へ表示する。
- 表記は既存の自分側HPバー下の倍率表示と同じルール（倍率1.0は `f(x) = x`、それ以外は小数1桁）を使う。

# 受け入れ条件

- 視覚妨害の有効時間中だけ、対象キャラクターの頭周囲に青いノイズが描画される。
- ローカル・リモートのどちらが対象でも頭上ノイズが描画される。
- 敵が算術士のとき、敵HPバーの下に現在の倍率が表示される。
- 非算術士の敵には倍率表示を出さない。
