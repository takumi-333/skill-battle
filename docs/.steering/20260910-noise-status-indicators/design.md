# 設計

- 試合中のワールド描画で、既存のデコイ用ノイズ表現を参照し、ノイズ状態フラグを持つプレイヤーの顔へ同系統の青・青紫のモザイク状ノイズを描画する。
- 描画は所有者・観戦者を区別しないため、同期済みのプレイヤー状態から対象を判定する。
- HUDは既存のローカル側倍率ラベルを維持し、敵側HPバー直下に専用ラベルを追加して敵キャラクターと倍率から可視状態と文言を更新する。
- ノイズ状態の同期値と倍率値は既存の対戦状態を利用し、対戦ロジックやダメージ判定は変更しない。
