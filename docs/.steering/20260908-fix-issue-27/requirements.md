# 要求事項

## 対象

- 対戦中のHUDとフィールド上のプレイヤー表示。

## 受け入れ条件

- 頭上にはHPバーを描画せず、ローカル操作プレイヤーには `あなた`、相手には同期済みの表示名（未設定時は既存のフォールバック名）だけを表示する。
- HUD上部にローカル操作プレイヤーのHPバーと `HP 現在値 / 100` を左寄せで表示する。
- HUD上部に相手のHPバーだけを、右端のタイマーより左側に表示する。
- 残り時間は右上端で `MM:SS` 形式となり、補助文言を含まない。
- 右下のスキルアイコンクラスターのシーン上の配置とサイズを変更しない。
- 固定HUD部品は `hud.tscn` に置き、`MatchPrototype` は値とテキストを更新する。
- Godotのヘッドレス起動でシーンおよびスクリプトエラーが発生しない。
