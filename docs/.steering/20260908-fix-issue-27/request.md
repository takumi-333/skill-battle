# 対戦画面UIの変更

現在の対戦画面を、以下の方針で変更する。

![対戦画面UIの改善イメージ](issue-27/battle-ui-improvement.png)

## HP表示

- HPバーはキャラクターの頭上には表示しない。
- 画面最上部に、自分用と相手用のHPバーをそれぞれ配置する。
- 自分（画面左側）のHPバーは左上に配置し、`HP 100 / 100` のように現在値と最大値を表示する。
- 相手（画面右側）のHPバーは右上のタイマー左側に配置し、数値・`HP`ラベルは表示せず、バーのみとする。

## 残り時間

- 残り時間は画面右上端に配置する。
- 表記は `xx:xx` 形式とする（例: `01:13`）。
- 「残り」や「秒」などの補助文言は表示しない。

## キャラクター名

- キャラクターの頭上には名前だけを表示する。
- 自分の名前は `あなた` と表示する。
- 相手の名前は対戦相手の名前を表示する。改善イメージでは `たろう` を例として表示している。

## スキルアイコン

- 右下のスキルアイコンクラスターは、現在の位置・おおよそのサイズを維持する。
