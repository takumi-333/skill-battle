# 設計

## HUD

`scenes/ui/hud.tscn` に自分用・相手用の独立した `ProgressBar` を固定ノードとして定義する。自分用の数値ラベルはバーの右側、相手用バーはタイマーの左側に置く。タイマーは右端に右揃えで配置する。色は既存の自分用ミント色を維持し、相手用には区別できる赤系のフィルを使用する。

`create_hud()` ではシーンで定義した位置・サイズを上書きせず、値の範囲と見た目だけを初期化する。`update_hud()` はローカル操作プレイヤーとその相手を特定し、それぞれのHPバーと自分用ラベルを更新する。時間は残秒を分・秒へ変換してゼロ埋めする。

## フィールド上の名前

`draw_player()` ではHPバー描画を削除する。HUDと同じローカル操作プレイヤー判定を使用し、本人には `あなた`、相手にはプレイヤーデータの表示名（未設定時は既存のキャラクター名、さらに未設定ならプレイヤー番号）を描画する。集中ゲージは既存のスキル状態表示のため維持する。

## 影響範囲

HUD固定ノードと `match_prototype.gd` のHUD更新・プレイヤー描画だけを変更する。スキルアイコンのノード、位置、サイズ、クールダウン処理には変更を加えない。
