# 実装方針

## キャラクター画面

`update_character_screen()` で候補ごとの実装状態を判定し、未実装候補には `*_lock.png` を設定する。ボタンの `disabled` と `focus_mode` を更新し、未実装候補の背景を暗くする専用StyleBoxを適用する。既存のシグナル接続は維持するが、`open_skill_detail()` と `set_skill_from_detail()` の両方で未実装候補を拒否し、状態経路を二重に防御する。

候補名は実装済みスキルの仕様上の標準名へ整理する。アイコン選択も候補インデックス単位に明示し、未実装候補はロックアイコンを返す。現在の選択が未実装にならないよう、キャラクター切り替え時と更新時に選択値を実装済み候補へ補正する。

## 対戦HUD

`create_skill_hud()` のプレビュー配列に通常攻撃用のプレースホルダーを設定し、打鍵士の通常攻撃にスキル演出アイコンが出ないようにする。通常攻撃アイコンの作成までは既存の共通プレースホルダーを使用する。
