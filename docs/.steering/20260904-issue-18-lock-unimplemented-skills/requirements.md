# 要求事項

## 機能要件

- 未実装スキルの候補はキャラクター画面で暗い背景とキャラクター別ロックアイコンを表示する。
- 未実装スキルの候補は押下・フォーカス・ロードアウト反映の対象外にする。
- 実装済み候補だけを選択でき、既存の確認モーダル経由のセット動作を維持する。
- 打鍵士のスキル1候補は実装済み1件と未実装4件に整理する。
- 打鍵士のスキル2候補は実装済み2件と未実装3件に整理する。
- 算術士と詠唱士のスキル1・2は標準候補名とし、スキル3は全候補を未実装とする。
- 対戦HUDの打鍵士通常攻撃は未作成状態を表すプレースホルダーアイコンにする。

## 非機能要件

- 固定レイアウトは `character_screen.tscn` に置き、実行時は表示状態・画像・テキストのみ更新する。
- 既存のキャラクター切り替え、確認モーダル、保存、対戦開始を壊さない。
- Godotヘッドレス起動でエラーがない。
