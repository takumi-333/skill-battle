# 要求内容

## 対象

`docs/ideas/ui_concepts/` に理想画像がある以下の画面を、準備済みのUIアセットを用いて改修する。

- タイトル
- ホーム
- オンライン接続
- オンライン待機・キャラクター選択
- 練習キャラクター選択
- デバッグ対戦セットアップ

## 受け入れ条件

- [ ] 各対象画面が、暗い地下アーケード背景、ネオンフレーム、上部ロゴの共通意匠を持つ。
- [ ] 既存の画面遷移、接続、キャラクター選択、準備完了、練習・デバッグ開始の動作を維持する。
- [ ] 対戦中の画面、HUD、課題UI、リザルト画面は変更しない。
- [ ] 画面ごとに対応する準備済みUIアセットを利用する。

## スコープ外

- 理想画像がない画面の新規改修
- 対戦画面の改修
- 通信・試合ロジックの仕様変更
