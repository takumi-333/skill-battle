# 設計

## スキル選択と課題

打鍵士の候補インデックスを既存のロードアウト送受信とプレイヤー初期化に反映し、各スロットで選んだ黄金時間のレベルを `small_skill_id`、`big_skill_id`、`skill3_id` として識別する。課題定義をレベル別に作成し、開始時に選択済み ID から候補語と制限時間を決定する。

## ゾーン状態

プレイヤー状態にゾーンの残り時間とレベルを持たせる。発動成功時にスコアで持続時間を決定し、毎フレーム減算する。通常攻撃の開始判定と HUD の通常攻撃アイコンはこの状態を参照して使用不可にする。

## 入力時効果

ゾーン発動中に正しく入力した文字を受け取った時点で、サーバー権威側でキーキャップ弾を生成する。レベル II/III は弾の緩い追尾を有効にし、III は同じ入力から円形波動を生成する。クライアントはサーバー状態を描画するため、専用サーバーとローカルの処理を対応させる。

## 表示

既存のキーキャップ弾と HUD の仕組みを再利用する。ゾーン中はプレイヤー描画に緑色の残光を追加し、HUD にレベルと残り時間を表示する。

## 検証

Godot のヘッドレス起動で GDScript とリソースを検査する。可能なら専用サーバーのシミュレーションを起動し、ログを確認する。
