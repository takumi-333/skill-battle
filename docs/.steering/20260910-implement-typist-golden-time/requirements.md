# 要求

## 対象

打鍵士の各スキル枠に定義された以下を実装する。

- スキル1: 黄金時間
- スキル2: 黄金時間II
- スキル3: 黄金時間III

## 機能要件

- キャラクター画面で3技能すべてを選択でき、作成済みアイコンを表示する。
- それぞれの候補語、制限時間、クールダウン、スコア別の持続時間を仕様書どおりに適用する。
- 発動中は通常攻撃を使用不可にする。
- 発動中に正しく入力した文字ごとにキーキャップ弾を発射する。I は追尾なし、II/III は緩い追尾を行う。
- 発動中のチャレンジは通常の残り時間スコアの 1.25 倍（上限 100）とし、タイプミスのペナルティは 0.9 秒とする。
- III は正しい入力ごとに周囲へダメージ波動を発生させる。
- ローカル対戦と専用サーバー対戦で、効果・クールダウン・入力処理が一致する。
- アイコン資産は既存の `typist_typing_zone*.png` を使用し、画像の再生成や変更はしない。

## 非機能要件

- 既存の打鍵士スキル、他キャラクターのスキル、および既存の未コミット変更を壊さない。
- Godot のヘッドレス起動で構文・リソース読み込みエラーがないことを確認する。
