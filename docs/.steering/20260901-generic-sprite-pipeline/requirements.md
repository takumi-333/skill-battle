# 汎用スプライト制作パイプライン — 要求

## 目的

現行の「8方向・停止／歩行・人物の足元揃え」に固定された制作ツールとガイドを、キャラクターの移動・攻撃、飛び道具、攻撃エフェクトなどへ再利用できる汎用パイプラインへ移行する。AI生成は引き続き個別フレーム単位、組版・検査・レビューは決定論的な処理とする。

## 要求

- 制作企画（意図・参照・禁止事項）を、機械可読のアセット仕様・アニメーション仕様・品質プロファイルから分離する。
- アニメーション仕様は任意数のclip、任意長のフレーム列、ループ、フレーム時間、イベント、任意のvariantを表せる。
- 出力レイアウトは等間隔グリッドと明示座標atlasを扱える。方向・停止・歩行は必須概念にしない。
- `character`、`weapon_attack`、`projectile`、`effect`の品質プロファイルを定義する。人物専用の足元・身体寸法・孤立成分検査をエフェクトへ強制しない。
- 組版、検査、プレビュー、採用ツールを新形式へ対応させる。既存のasset spec / motion spec / `--motion` 呼び出しは互換維持する。
- 既存の8方向移動は、新形式の一利用例として文書化する。攻撃・エフェクトの具体例も同じ仕様で示す。
- ガイド、フロー、ツール一覧、キャラクターアセット制作ガイド、アートディレクションを新しい責務境界に整合させる。
- 新形式と既存形式の正常系・主要な異常系を自動テストする。

## 非対象

- 実ゲーム用の攻撃・エフェクト画像の生成、採用、ゲームロジックへの追加。
- 既存の8方向移動素材またはGodotの現在の表示挙動の変更。
- AIによる外見品質・演技・権利上の自動判定。

## 受け入れ条件

- 16フレームの無方向エフェクトを、個別フレームから組版、検査、ブラウザプレビューできる。
- 8方向歩行の既存テストとCLIが引き続き通る。
- プレビューはclipと、存在する場合だけvariantを選択して再生できる。
- エフェクトには分離粒子があっても、character専用cleanup検査によって不合格にならない。
- 制作時に使う企画書・asset spec・animation spec・品質プロファイルの役割と作成順がガイドに明記される。
