# 設計

## 方針

`scripts/match_prototype.gd`の手動判定を、描画表現と分離したプレイヤー用楕円ヒットボックスへ置き換える。

## 実装

- `PLAYER_RADIUS`を、楕円の横半径・縦半径とスプライトの足元からの中心オフセットを表す定数へ分解する。
- プレイヤー間距離による押し出し処理と、その呼び出しを削除する。
- プレイヤー位置を楕円中心へ変換し、点が楕円内にあるかを判定するヘルパーを追加する。
- 移動先が相手の楕円ヒットボックスと重なる場合は移動を止め、相手を押し出さずに通過もできないようにする。
- 通常攻撃は楕円中心までの距離を使って対象を選び、飛び道具は楕円の外周までの近似距離で命中判定する。設置技も同じ楕円中心を参照する。
- `draw_player()`から通常時の色付き円を削除し、集中・被弾・攻撃のフィードバックは残す。

## 互換性

ネットワーク同期されるプレイヤーデータの形式は変更せず、ホスト側の判定とローカル表示のみを変更する。
