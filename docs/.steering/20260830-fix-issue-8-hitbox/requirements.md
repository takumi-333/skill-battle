# 要求事項

## 目的

issue-8に対応し、プレイヤーの見た目に近い当たり判定と、プレイヤー同士が押し合わない移動を実現する。

## 要求

- P1/P2の赤丸・青丸の表示を削除する。
- プレイヤーの攻撃・飛び道具・設置技の命中判定を、スプライトの身体に近い縦長の楕円として扱う。
- プレイヤー同士が接触しても、相手を押し出したり移動を阻害したりしない。
- 既存のアリーナ境界、HP、集中・被弾表示、攻撃処理は維持する。

## 受入条件

- 対戦画面にP1/P2の赤・青の円形マーカーが表示されない。
- 通常攻撃と飛び道具の命中判定が、プレイヤー位置を中心とした円形ではなく、キャラクターの身体に近い楕円で判定される。
- プレイヤー同士が重なって移動でき、接触時に自動的な押し出しが発生しない。
- Godot起動時にスクリプトエラーが発生しない。
