# 要求事項

## 機能要件

- キャラクター画面のスキルアイコンを押しても、その場ではロードアウトを変更しない。
- 押下したスキルの確認ウィンドウを、画面の大部分を覆うモーダルとして表示する。
- モーダル表示中は背面を暗くし、説明ウィンドウを最前面にする。
- モーダルにはスキルアイコン、スキル名、詳細説明、「閉じる」、「スキルをセット」ボタンを表示する。
- 説明ウィンドウと2つのボタンは、現在選択中のキャラクター用のフレーム・ボタン素材を使用する。
- 「閉じる」はロードアウトを変更せずモーダルを閉じる。
- 「スキルをセット」は対象スロットへスキルを反映してモーダルを閉じる。
- スキルアイコン押下時は通常のUIクリック音を再生しない。

## 非機能要件

- 固定レイアウトは `character_screen.tscn` に定義し、実行時は表示内容とテーマ素材だけ更新する。
- 既存のキャラクター選択、保存、画面遷移を壊さない。
- Godotヘッドレス起動でスクリプト・シーンのエラーがない。
