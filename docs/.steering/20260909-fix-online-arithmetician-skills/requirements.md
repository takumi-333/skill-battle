# 要求

## 目的

Dedicated Server を使うオンライン対戦で、算術士のスキル1「無限級数」とスキル2「最適解への収束」が算術士のスキル仕様に従うようにする。

## 対象

- サーバー権威の `MatchSimulation` における算術士スキルの課題生成と成功時効果。
- スキル効果を検証するネットワークシミュレーションテスト。

## 受け入れ条件

- スキル1はスコア帯ごとのデコイ数、効果時間、配置半径、移動速度1.1倍、通常攻撃力1.5倍を満たす。
- スキル1は2秒、スキル2は15秒のクールダウンを持つ。
- スキル1発動時は、発動者と半径1000px以内の相手に青い瞬間フラッシュを同期して表示する。
- スキル2はスコアに応じた10〜20秒の効果時間、移動速度1.25倍、通常攻撃力+10、透明化時間を満たす。
- 透明化中は2.5秒ごとに約0.2秒だけ相手にも表示され、通常攻撃中は相手にも表示される。
- 再発動時に既存のデコイが消える。
- デコイは発動者の移動・向きに追従し、サーバー状態としてスナップショットに保持される。
- 既存のオンライン課題送信・採点の権威分離を損なわず、関連テストが通る。

## 非対象

- クライアント専用の旧来ネットワーク経路の再設計。
- 仕様に記載されていない透明化の点滅演出の新規実装。
