# 設計

オンライン対戦の正は `scripts/network/match_simulation.gd` であるため、同ファイルの算術士スキル処理を仕様値へ合わせる。クライアントの `match_prototype.gd` はオンライン時にサーバースナップショットを表示するだけで、ゲーム効果の正を持たせない。

スキル1はスコアからデコイ数・持続時間・配置半径を専用関数で決める。デコイ数は仕様の各スコア帯をそのまま式にし、ランダムな8方向オフセットと半径内のランダム配置を用いる。発動時に既存デコイを全消去し、効果中の移動倍率と通常攻撃加算値を設定する。ノイズの5〜10秒間隔もサーバーで進行させる。

スキル1の瞬間フラッシュは、寿命を持つ表示エンティティとしてサーバー状態・スナップショット・reliableな表示イベントに載せる。これにより、即時表示と欠落後の状態復旧を両立する。スキル2は効果時間をスコア0〜100から10〜20秒に補間し、透明化時間・移動倍率・攻撃力加算を同じ時間だけ設定する。サーバーは透明化の2.5秒周期を状態として進め、クライアントは既存の描画分岐で約0.2秒の露出を表示する。算術士固有のクールダウンは課題終了時にサーバーが設定する。

テストはサーバーシミュレーションを直接操作して、両スキルの課題種別、主要なスコア境界、効果値、デコイ再発動、デコイ追従を検証する。
