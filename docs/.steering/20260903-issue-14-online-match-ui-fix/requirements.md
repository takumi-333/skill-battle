# 要求内容

## 概要

オンライン対戦の待機画面を、各プレイヤーが自分のキャラクターと準備状態だけを操作・表示できる構成へ修正する。

## 実装対象

- キャラクター選択の左右ボタンに対応する枠を正しい位置へ配置する。
- 自分のキャラクター名だけを左右ボタンの間に表示する。
- 相手側は名前と選択操作を表示せず、接続済みの場合は `shadow_idle` を表示する。
- 準備完了ボタンを1つにし、現在の接続側プレイヤーの準備状態だけを切り替える。
- ホストにだけゲーム開始ボタンを表示し、両者の準備完了時だけ押せるようにする。
- クライアントの準備完了操作がホストへ同期され、ホストの開始操作で両クライアントが試合へ進むようにする。

## 受け入れ条件

- クライアントが待機画面で準備完了を押すと、ホスト側の相手準備状態が更新される。
- 相手のキャラクター名と左右ボタンが待機画面に表示されない。
- 接続済みの相手欄に影キャラクターの立ち絵が表示される。
- ゲーム開始ボタンはホストだけに表示され、両者未準備では無効になる。
- Godot起動時にパースエラー・ノード参照エラーがない。
