# 設計

- `result_screen.tscn` に、`menu_background.png` を全面背景として置き、その前面に暗い半透明の `ColorRect` を置く。背景は入力を受けない。
- 既存の3キャラクター立ち絵を外部リソースとして定義し、`WinnerPortrait` と `OpponentPortrait` の `TextureRect` を固定配置する。`MatchPrototype` は選択済みの `visual_id` から対応する既存立ち絵を設定する。
- 勝者の立ち絵を左、相手を右に配置する。引き分けはP1を左、P2を右のまま扱い、勝利章は非表示にする。
- RESULTロゴ、試合時間、名前、成績パネル、ボタンはシーンに固定ノードとして定義する。ゲーム状態で変わる文言・数値・立ち絵・勝利章表示だけをスクリプトで更新する。
- HPと平均点はプレイヤーごとの独立したLabelにして、空白文字による位置合わせを廃止する。
- `ResultText` はオンライン再戦待機文専用とし、下部右端に控えめに置く。
