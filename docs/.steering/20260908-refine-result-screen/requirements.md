# 要件

- リザルト画面を、ユーザー提示の完成イメージに近い「キャラクター立ち絵が主役」の構成へ更新する。
- 背景は左右の色分割ではなく、暗い地下ストリート背景へ暗影を重ね、ロゴ・立ち絵・金装飾を前景として際立たせる。
- 上半分には、試合で選択された両プレイヤーの既存立ち絵を表示する。勝者側には既存の勝利章を重ねる。
- 試合時間は、改行しない `試合時間 02:38` 形式の日本語・太い金文字で表示する。
- 勝敗プレイヤー名を立ち絵の近くへ大きく表示し、従来の勝者／敗者カードとその補助文言は表示しない。
- 下部はひとつの成績パネルにまとめ、各プレイヤーの残HPを `現在値 / 100`、平均スキル点を左右に表示する。
- 再戦ボタンの表示名は `再戦`、ロビー復帰は `ロビーへ戻る` とする。既存の再戦・復帰処理は保持する。
- オンラインの再戦待機状態は結果の主表示を妨げない位置・サイズで表示する。
- 新規のキャラクター画像は生成せず、既存の `assets/characters/portraits/` と既存UI素材を使用する。
