# 要求仕様

## 目的

ホーム画面からユーザー名を設定できるようにし、その名前をオンライン待機画面とリザルト画面でプレイヤー名として表示する。

## 要求

### 1. 設定導線

- ホーム画面の右側メニューに、既存のキャラクター・デバッグ項目の上へユーザー設定ボタンを追加する。
- ボタンは人物アイコンのみを表示し、アイコンは `assets/ui/icon_user_settings.png` を用いる。
- ボタンを押しても画面遷移はせず、ホーム画面上にモーダルウィンドウを表示する。

### 2. ユーザー設定ウィンドウ

- 背景を暗くするモーダルとして表示し、背面のホーム画面は操作できない。
- ウィンドウには「ユーザー設定」の見出し、ユーザー名を入力する欄、保存ボタン、右上の閉じるボタンを置く。
- 右上の閉じるボタンは `assets/ui/icon_close.png` を利用する。
- 空白のみの名前は保存しない。入力は 20 文字までに制限する。
- 名前は `user://settings.cfg` に永続化し、次回起動時に復元する。

### 3. 表示とオンライン同期

- 設定名をオンライン待機画面の自分・相手のカード表示に使う。
- 設定名をリザルト画面の勝敗および両プレイヤーの表示に使う。
- 専用サーバー対戦では、ロードアウト送信に名前を含め、サーバー検証後に両クライアントへ同期する。
- 既存のキャラクター名は、ユーザー名が未設定の場合の初期値としてのみ使用する。

### 4. 表示の役割分離

- ロビーの自分の枠は `あなた　<キャラクター名>` と表示する。自分のユーザー名はここに表示しない。
- ロビーの対戦相手枠は、入室前は空欄にする。入室後に名前同期が完了した場合のみ、対戦相手のユーザー名だけを表示する。
- リザルト画面はキャラクター名ではなくプレイヤー名を表示する。名前が存在しないローカル対戦の仮想プレイヤーには `プレイヤーN` を表示する。

## 完了条件

- [ ] 設定ボタンからモーダルを開閉でき、保存内容が再起動後も復元される。
- [ ] 空白名・20文字を超える名前を保存できない。
- [ ] 待機画面と結果画面に保存したユーザー名が表示される。
- [ ] 専用サーバー対戦で両者の名前が相手側にも表示される。
- [ ] Godot のヘッドレステストとプロジェクト起動でエラーが出ない。
