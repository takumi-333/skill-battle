# ユーザ名の導入

## ホーム画面の右上にユーザ設定ボタンの配置
- 練習、キャラクター、デバッグボタンを少し下に下げてその上にユーザ設定ボタンを導入する
- ユーザ設定ボタンは、人間のアイコンを表示した一般的な見た目
    - このアイコンは画像生成する
- ボタンを押すと画面遷移ではなく、その場にウィンドウを表示（枠はオンライン対戦ボタンと同じ）
    - 背景は暗くし、ボタンは押せない状態にする
    - ウィンドウ右上に×ボタンを配置し、そこから閉じる
        - この×ボタンの×のUIは`assets\ui\icon_close.png`を利用する
- その中ではユーザ名だけいじれるような感じ

## ユーザ名の適用
上記で設定した名前は、待機画面やリザルトで表示される名前になる
待機画面では、対戦相手が入室すると、その名前が表示される
リザルト画面では、その名前が参照され表示される（今はキャラクター名となっているがそれだと被ったら、わからなくなるため）
