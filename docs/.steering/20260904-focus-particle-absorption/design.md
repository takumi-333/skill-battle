# 設計方針

- 対象は現在の対戦プロトタイプ `scripts/match_prototype.gd` とする。
- 既存の `draw_arc` による集中円を削除し、キャラクター描画前に `draw_focus_particles` を呼ぶ。
- パーティクルはローカルの視覚演出として、集中経過時間と粒子インデックスから再現可能な疑似ランダム位置を算出する。
- 各粒子は周囲約100〜180pxの位置から発生し、約1.2〜2.0秒でキャラクターのヒットボックス中心へ移動して消える。
- テクスチャは `assets/effects/focus_particles/` の8×8px PNGを2倍の16×16pxで描画する。
- キャラクター別の色違いを混ぜ、移動・拡大・透明度変化はコード側で行う。
- 円形の輪郭線や固定リングは描画しない。
