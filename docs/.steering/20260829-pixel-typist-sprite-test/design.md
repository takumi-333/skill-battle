# 打鍵者ドット絵8方向スプライト試験 — 設計

## 方針

打鍵者の外見を1つのキャラクター契約として固定し、同じシート内に8方向・停止・歩行の全フレームを収める。左右反転に依存せず、8方向をそれぞれ描く。今回はアセット生成と検査だけを行い、Godotの既存表示は変更しない。

## スプライトレイアウト

最終アセットは `assets/characters/typist_pixel_8dir_test.png` とする。64×64pxセルを8列×5行に並べた512×320pxのRGBA PNGとする。

各セルは透明な余白を含め、足元の接地点をセル下端から8px付近に揃える。上下方向のキャラクターは、顔ではなく頭頂・髪・肩・足の向きで方向を読み取れるようにする。

## 生成手順

1. 64pxセルの設計を読み取れる、低解像度のドット絵調・斜め上見下ろしスプライトシートを生成する。
2. 生成画像の方向順、5行構成、人物の一貫性、各歩行ループを確認する。
3. 必要に応じて、誤っている方向・行・固定要素だけを指定して再生成する。
4. 採用候補を最近傍補間で512×320pxへ正規化し、RGBA透過を確認してプロジェクトへ配置する。

AI生成で40セルの細部を完全に固定できない場合は、止め絵と歩行シートを分離して生成し、同じセル配置に合成する。この場合も、最終出力は上記の単一シートに統一する。

## 生成プロンプトの固定要素

- 真のピクセルアート。滑らかなベクター線、アニメ調の立ち絵、アンチエイリアス、ぼかしを使わない。
- 斜め上見下ろしのアクションRPG用スプライト。キャラクターが地面に立つ角度で、頭頂・肩・足元が見える。
- 成人男性、短い黒髪、細い黒縁眼鏡、白シャツ、暗色パンツ。青い裏地とルーン刺繍の短い魔導士コート、革ベルト、腰の護符、青く淡く光るルーンペンダントを固定要素にする。
- 背景・地面・影・文字・罫線・セル枠・ロゴを入れず、完全な透明背景にする。
- 各セルで頭身、配色、髪型、眼鏡、衣装、縮尺、足元Y座標を固定する。

## 検査

次を自動または目視で確認する。

- 出力寸法が512×320px、RGBAであること。
- 64×64pxのグリッドに沿い、8列×5行の40セルがあること。
- 全方向に黒髪・眼鏡・白シャツがあり、左右の衣装・ポーズに不自然な鏡写しがないこと。
- 各列の歩行1〜4が、接地・中間・逆接地・中間の歩行ループとして読めること。
- 足元位置とキャラクター縮尺がセル間で大きくずれていないこと。
