# 要求内容

## 概要

オンライン対戦のルーム参加導線と待機画面を、意図した状態表示・シーン編集可能なUI配置へ修正する。

## 機能要件

- 「ルームを作成」の既存動作は維持する。
- 「ルームに参加」を押すと、公開ルーム一覧をモーダルウィンドウで表示する。
  - モーダル外側は薄暗くする。
  - 枠は既存の `panel_frame.png` を利用する。
  - 各ルーム行の右側に入室ボタンを配置し、そのルームへ参加できる。
  - 一覧の更新と閉じる操作を提供する。
- 待機画面の相手欄の影キャラクターは、相手が接続済みの場合だけ表示する。
- 添付画面で確認されたロビーUIの配置ずれを修正する。
- ホームへ戻るボタンとキャラクター選択の左右ボタンには、対応する枠をシーン上で表示する。

## 非機能要件

- 固定UIの配置・サイズ・階層は `.tscn` に定義し、実行時は状態と可変個数のルーム行のみ更新する。
- 背景テクスチャは入力を妨げず、ボタンより背面に表示する。
- 既存の専用サーバー経由のルーム作成・参加処理を再利用する。

## 受け入れ条件

- 参加ボタンからモーダルを開き、公開ルームの各行から入室処理を開始できる。
- 相手未接続時には影キャラクターが表示されず、接続後のスナップショットでは表示される。
- ロビーの各フレームが対応ボタンの背面に整列し、ホームへ戻る枠も見える。
- Godotのシーン読み込み・ヘッドレス実行にエラーがない。
