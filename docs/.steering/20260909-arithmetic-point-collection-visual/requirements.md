# 要求内容

## 概要

算術士のデコイが相手の攻撃で破壊されたとき、妨害ポイントの獲得を可視化する。発生地点の数値が一定時間留まり、算術士へ飛んで吸収された時点でポイントを得る。

## 背景

デコイ破壊による妨害ポイントの蓄積がプレイヤーに伝わりにくい。獲得の発生源・量・到達時の強化を一連の演出として示す。

## 実装対象の機能

### 1. 妨害ポイント回収状態

- デコイを所有者以外の攻撃が破壊したとき、破壊位置・所有者・獲得量を持つ回収状態を生成する。
- 今回のデコイ由来の獲得量は `0.1` とする。
- 発生から1秒待機し、その後に所有者へ飛行する。
- 所有者に到達した時点でのみ、妨害ポイント係数を加算する。

### 2. 回収演出

- 発生地点に小さな `+0.1` を表示する。
- 待機後は現在の算術士位置を追って飛行し、到達時に消える。
- 同時発生は同時に飛行し、時差発生は各状態の発生から1秒後に個別に飛行する。
- ローカル対戦と専用サーバー対戦の両方で、両プレイヤーが同じ演出を確認できる。

## 受け入れ条件

### 回収状態

- [ ] 相手の攻撃で破壊されたデコイごとに `0.1` の回収状態が作られる。
- [ ] 係数は破壊時ではなく、待機・飛行後に所有者へ到達した時点で増える。
- [ ] 同時・時差の発生で各回収状態の待機時間が独立している。

### 表示と同期

- [ ] 数値が破壊地点で待機してから所有者へ飛行する。
- [ ] 専用サーバーのスナップショットと補間に回収状態が含まれる。
- [ ] リセット・試合終了後に演出や未回収状態が残らない。

## スコープ外

- デコイ以外の妨害ポイント獲得手段の追加。
- 音声・効果音の追加。
- ポイント量ごとの個別デザイン。
