# 要件

## 目的

オンライン対戦で多数の弾が存在する場合に、クライアントのスナップショット補間で発生する二重ループの照合コストを削減する。

## 対象

- `MatchProtocol.interpolate_visual_state()` が行うエンティティ補間
- 特に `presentation_id`、`projectile_id`、`impact_id` を持つ投射物・演出配列

## 完了条件

- 各エンティティ配列の前回状態をIDで一度だけ索引化し、各入力要素を定数時間で参照できる。
- IDを持つエンティティは従来どおり同一IDの前回状態との間で補間される。
- IDを持たない、または対応する前回状態がないエンティティは従来と同じフォールバック動作を維持する。
- ネットワークのワイヤ形式、サーバー権威の判定、弾数、描画仕様は変更しない。
- 既存テストと、この変更を検証するテストが通る。

## 非対象

- 弾幕の通信量、弾数、描画方式、なぞり入力の変更
- スキル効果・ダメージ・同期頻度の変更
