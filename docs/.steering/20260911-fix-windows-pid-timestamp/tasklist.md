### 学んだこと

- PowerShell 7 の `ConvertFrom-Json` は ISO 8601 文字列を `DateTime` に変換するため、JSON の日時値と文字列の直接比較は安全な同値判定にならない。
- PID の所有確認では、日時の表示形式ではなく UTC ticks のような型に依存しない値で比較する必要がある。

### 次回への改善提案

- PID 記録を利用する PowerShell スクリプトを追加する場合は、文字列の直接比較を避け、この正規化方式と同等の回帰テストを含める。
