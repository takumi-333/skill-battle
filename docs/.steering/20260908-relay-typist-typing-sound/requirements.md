# 要求

## 目的

オンライン対戦で打鍵士がタイピングした際、入力者本人だけでなく対戦相手にも打鍵音を再生する。

## 要件

1. ホスト／クライアント対戦では、どちらが打鍵士でも相手に打鍵音が届く。
2. Dedicated Server 対戦では、サーバーが受理したタイピング入力に対応して、入力者以外の同一ルーム参加者だけが打鍵音を再生する。
3. 入力者のローカル再生を維持し、二重に音を鳴らさない。
4. 既存のクライアント／サーバー RPC 契約とネットワークテストを維持する。

## 完了条件

- [ ] 受理済みのタイピング入力の音が相手へ中継される。
- [ ] 入力者と相手の双方で一打ごとに一度だけ鳴る。
- [ ] Godot のネットワークテストとヘッドレス起動が成功する。
