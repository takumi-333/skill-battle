# キャラクター実行用アセットの分離 — 要求

## 目的

キャラクター選択に使う待機立ち絵と、戦闘表示に使うスプライトシートを別ディレクトリにして管理しやすくする。

## 要求

- 待機立ち絵を `assets/characters/portraits/` へ配置する。
- 8方向スプライトシートを `assets/characters/sprites/` へ配置する。
- Godotで読み込む全ての参照を新しい `res://` パスへ更新する。
- 既存ファイルに対応する `.import` メタデータも、移動先と整合するよう維持する。
- Godotのheadless起動で、移動後にリソース・スクリプト読込エラーがないことを確認する。
