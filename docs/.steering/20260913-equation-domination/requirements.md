# 要求内容

## 概要

算術士スキル3候補2「方程式支配（エクエーション・ドミニオン）」を、ローカル対戦とDedicated Server対戦の両方で実装する。発動成功時に相手へ強制算術課題を出し、失敗時にスキル中止・5秒の攻撃封鎖・移動速度低下・妨害ポイント獲得を適用する。

## 実装対象

- 算術士のスキル3候補2を選択・ロードアウトへ反映できるようにする。
- 発動者の算術課題成功後、相手へ8秒の強制計算課題を表示する。
- 強制課題中は、対象が移動と強制課題への数値入力・送信以外の操作を行えないようにする。
- 相手が自分の課題中の場合は、その課題を一時停止して強制課題を前面表示する。正解時には一時停止していた課題を再開し、失敗時には中止する。
- 強制課題を時間切れまたは中止で失敗した場合、対象の通常攻撃・スキル1〜3・新しい課題開始を5秒間封鎖し、移動速度を75%にする。発動者は妨害ポイントを0.5得る。
- 封鎖中は、スキルダイヤの上に×字鎖UIを表示し、対象キャラクターの頭上には鎖マークを表示する。
- `assets/head-lock.png` と `assets/skill-lock.png` を用途が分かる名前と適切なアセットディレクトリへ移す。

## 追加スコープ: スキルアイコン

- ユーザー提供の方程式支配アイコンを透明PNGとして `assets/ui/skill_icons/arithmetician_equation_domination.png` に配置する。
- 算術士のスキル3候補2をキャラクター画面で表示する際、このアイコンを使用する。

## 追加スコープ: 封鎖オーバーレイのシーン編集

- スキルダイヤを覆う鎖オーバーレイを、実行時生成ではなく各サイズのスキルダイヤシーンに配置する。
- Godotエディタ上で、各サイズのオーバーレイの画像・位置・サイズ・アンカー・重なり順を調整できるようにする。

## 受け入れ条件

- 算術士の候補2を選択して対戦を開始し、スキル3から方程式支配を発動できる。
- 相手は強制課題中に移動と解答入力以外のゲームプレイ操作を行えない。
- 相手の正解時には封鎖や妨害ポイントが発生せず、元課題があれば残り時間を保って再開する。
- 相手の時間切れまたは中止時には、5秒の攻撃・スキル封鎖、移動速度75%、算術士への0.5ポイント加算が発生する。
- 封鎖対象の頭上と右下の使用不能スキル枠に、それぞれ対応する画像が表示される。
- ローカル対戦とDedicated Server対戦で、課題・封鎖・ポイントの判定結果が同期する。

## スコープ外

- 強制課題へ誤答以外の固有演出・追加音声を加えること。
- 同時に複数の強制課題を重ねること。
- すでに確定している飛翔体や持続効果を失敗時に取り消すこと。
