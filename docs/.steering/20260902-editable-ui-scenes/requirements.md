# 要求内容

## 概要

実行時に `scripts/match_prototype.gd` が生成しているゲームUIを、Godotエディタで選択・配置・サイズ変更できるシーンノードへ移行する。

## 背景

現行の `scenes/main.tscn` はルートの `Node2D` だけを持ち、HUDや各メニューはスクリプトから生成される。このため、Godotの標準UI編集機能で画面要素を調整できない。

## 実装対象

- `CanvasLayer` と `Control` を用いたUIルートを `main.tscn` に定義する。
- 画面を覆うHUD、ロビー、接続、リザルト、ナビゲーション、課題UIの親ノードをエディタ編集可能にする。
- 既存スクリプトはシーン上のノードを取得して状態・表示・イベントを更新し、試合フィールドの `_draw()` は維持する。

## 受け入れ条件

- [ ] Godotエディタで `main.tscn` を開くと、UI用の `CanvasLayer` と各画面の `Control` がシーンツリーに表示される。
- [ ] UIの親領域はInspectorから位置、サイズ、アンカー、可視性を編集できる。
- [ ] タイトル、ホーム、ロビー、接続、試合HUD、リザルトの既存遷移が動作する。
- [ ] UI調整専用の実行時機能に依存しない。

## スコープ外

- 対戦フィールド、プレイヤー、エフェクトの `_draw()` 描画をControl化すること。
- UIの意匠・操作仕様の変更。
