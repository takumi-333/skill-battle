# 要求

## 対象

ローカル練習・デバッグ対戦と Dedicated Server を用いるオンライン対戦の、対戦フィールド、試合時間、開始演出を対象とする。

## 機能要件

1. 対戦フィールドを従来の 2520 x 1160 px から約 2/3 の 1680 x 774 px へ縮小し、プレイヤー開始位置と移動制限を新しい範囲に合わせる。
2. 試合時間はローカル・Dedicated Server とも 90 秒とする。
3. 両プレイヤーが対戦画面へ遷移後、`READY` を表示してから `FIGHT` を表示する。
4. `READY` 中は移動・通常攻撃・スキル入力を受け付けず、`FIGHT` 表示と同時に試合の計時と操作を開始する。
5. オンライン対戦では開始状態と残り時間を Dedicated Server の snapshot を正として両クライアントへ同期する。

## 受け入れ条件

- [ ] ローカル・オンラインの両方で、プレイヤーが新しいフィールド範囲を越えて移動できない。
- [ ] 試合開始時に `READY`、続いて `FIGHT` が表示され、`FIGHT` 前の入力ではプレイヤー状態が変化しない。
- [ ] `FIGHT` と同時に 90 秒タイマーが開始し、終了判定まで正しく減少する。
- [ ] Dedicated Server の開始待機中にイベント・移動入力がゲーム状態へ反映されない。
- [ ] 関連テストと Godot headless 起動確認が成功する。

## スコープ外

- 開始合図の音声・追加アニメーション素材の制作
- マップ地形やカメラ方式の再設計
- 試合ルール・ダメージ値の調整
