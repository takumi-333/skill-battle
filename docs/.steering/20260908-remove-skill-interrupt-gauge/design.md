# 設計

## 方針

中断ゲージは独立したゲーム状態ではなく、被弾時に課題を失敗させるためだけに使われている。関連する状態、初期化、同期、描画、データ定義をすべて削除し、被弾処理はHPと被弾表示だけを更新する。

## 変更箇所

1. `MatchState`、`MatchProtocol`、`SkillDefinition` から中断ゲージのデータを削除する。
2. `MatchSimulation` と `MatchPrototype` の課題開始・終了・リセット処理から中断ゲージの初期化と解除を削除する。
3. 両方の被弾処理から、集中中の相手を中断する分岐を削除する。
4. `MatchPrototype` の中断ゲージ補間・フィールド上のゲージ描画を削除する。
5. 確定仕様とキャラクター別仕様書、UIアセット台帳を新ルールに更新する。

## 互換性

Dedicated Server とクライアントは同じリポジトリの通信契約を更新する。中断ゲージキーを同期しないため、更新後のクライアントと更新前のサーバーの混在は対象外とする。
