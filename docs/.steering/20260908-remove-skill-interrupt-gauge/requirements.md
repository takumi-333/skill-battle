# 要求

## 目的

スキル発動中の中断ゲージを廃止し、ダメージを受けても課題およびスキル発動を妨害できないようにする。

## 機能要件

- ローカル対戦と Dedicated Server 対戦のどちらでも、集中中にダメージを受けても課題を中断しない。
- プレイヤー状態、同期スナップショット、スキル定義、HUD描画から中断ゲージの状態・処理・表示を削除する。
- 既存の任意中止、時間切れ、誤答による失敗は維持する。

## ドキュメント要件

- 初期対戦仕様、オンライン対戦アーキテクチャ、UIアセット台帳から中断ゲージの仕様を削除する。
- 各キャラクター別スキル仕様書から中断ゲージの記述を削除する。
- `docs/ideas/` は未確定の検討メモのため変更しない。

## 検証要件

- ネットワークシミュレーションのテストを実行する。
- Godotをheadlessで起動し、スクリプト読み込みエラーがないことを確認する。
- リポジトリの実装対象と確定仕様に中断ゲージの参照が残らないことを検索で確認する。
