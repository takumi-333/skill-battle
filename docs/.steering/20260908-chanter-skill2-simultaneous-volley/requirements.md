# 要件

- 更新済みの詠唱士スキル2仕様書に従い、クールダウンを6秒へ変更する。
- 各周は16回の発射タイミングで構成する。各タイミングで、真上始点の時計回り弾と、真下始点の反時計回り弾を同時に各1発射出する。
- 周回数はスコア30以下で1周、50以下で2周、75以下で3周、76以上で4周とする。各周は32発のため、最大128発となる。
- 弾の方向固定・発射時点の発動者位置・ダメージ・渦巻き課題は前回仕様を維持する。
- ローカル対戦とサーバー権威シミュレーション、仕様書、自動テストを同じ仕様へ更新する。

## 補足

- アイコンイメージにある「8方向」は画像の表現であり、効果本文の16方向射撃を変更するものではない。
