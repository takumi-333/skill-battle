# 要件

## 目的

オンライン対戦における詠唱士スキル3「十六夜」の多数弾を、弾ごとの継続スナップショット同期から、1回の発動プレゼンテーションによるクライアント側の視覚再生へ切り替える。

## 要求

- 直前に追加したID索引による補間最適化と、そのテストを巻き戻す。
- 十六夜のダメージ、弾数、発射方向、発射間隔、サーバー上の当たり判定は従来どおりサーバー権威で維持する。
- 専用サーバーは十六夜について、弾ごとのプレゼンテーションと継続スナップショットへの弾状態の格納を行わない。
- 専用クライアントは1回の発動プレゼンテーションから、同等の弾幕をローカル視覚専用として生成・更新・描画する。
- サーバー側の同時弾数上限で一部の弾が生成されなかった場合も、実際に生成された弾数をイベントに含め、クライアントの見た目と一致させる。
- 通常のスキル弾と、他の演出の同期方式は変更しない。
- 重複受信、試合切替、寿命切れの視覚弾を安全に扱う。

## 完了条件

- 十六夜の高スコア時も、専用サーバーのスナップショットに当該弾が含まれない。
- 1発動につきコンパクトなプレゼンテーションが1件生成される。
- クライアントがプレゼンテーションから、実際に生成された弾数と同数・同方向・同間隔の視覚弾を生成する。
- サーバー権威の十六夜判定に関する既存テスト、および追加テストが通る。

## 非対象

- それ以外のスキル弾のイベント化
- 十六夜の描画方式・弾数・ダメージ・ネットワークのtick/スナップショット頻度の変更
