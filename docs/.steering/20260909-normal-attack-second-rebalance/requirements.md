# 要求内容

## 概要

通常攻撃の基礎ダメージを打鍵士3、算術士1、詠唱者2へ変更し、全キャラクターの基本クールダウンを5秒へ変更する。

## 実装対象

- Dedicated Server の通常攻撃基礎ダメージと基本クールダウン
- ローカル／デバッグ対戦の同等設定
- 3キャラクターの仕様書にある通常攻撃値

## 受け入れ条件

- [ ] 打鍵士、算術士、詠唱者の基礎通常攻撃ダメージが順に3、1、2である。
- [ ] 全キャラクターの基本通常攻撃クールダウンが5秒である。
- [ ] Dedicated Server とローカル／デバッグ対戦が同じ設定値を使う。
- [ ] 算術士の既存の係数・加算バフは変更しない。

## スコープ外

- 通常攻撃の範囲、命中判定、演出、攻撃時間、HPの変更
- 算術士の係数・加算バフ・デコイの調整
