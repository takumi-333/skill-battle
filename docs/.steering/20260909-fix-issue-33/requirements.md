# 要求内容

## 概要

通常対戦では通常攻撃のデバッグ用当たり判定を表示しない。オンラインルームでは退出した参加者の枠を解放し、空き枠数を正しく公開する。

## 受け入れ条件

- [x] デバッグ対戦以外で通常攻撃の赤い当たり判定枠が描画されない。
- [x] デバッグ対戦では従来どおり当たり判定を確認できる。
- [x] 参加者が退出したルームは `1/2` として一覧に反映され、別の参加者が入室できる。
- [x] 既存のルーム作成・参加・対戦開始フローを損なわない。

## スコープ外

- 攻撃判定の形状・ダメージ計算の変更。
- ルーム定員やマッチメイキング方式の変更。
