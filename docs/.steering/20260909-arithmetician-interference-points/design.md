# 設計

## 状態管理

サーバー権威の `MatchSimulation` の player state に `arithmetic_interference_multiplier` を持たせる。ローカル対戦の `match_prototype.gd` にも同じ状態と判定を実装し、両モードで仕様を一致させる。

## デコイ破壊

デコイを円形の攻撃対象として扱い、通常攻撃、弾、範囲・設置攻撃の各命中処理で先に照合する。命中したデコイは配列から除去し、所有者が算術士なら係数を 0.1 増加する。時間切れ除去では増加させない。

## 強化計算

通常攻撃のクールダウンとダメージ、移動速度の計算直前に係数を参照する。スキル2の既存バフは、ポイントによる補正と積み上げる。

## 表示

HUD の自分の HP バー直下に専用ラベルを追加し、算術士のときだけ係数式を表示する。デコイ名は `draw_decoy` に視点情報を渡して描画する。
