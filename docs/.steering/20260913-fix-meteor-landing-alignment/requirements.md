# 要求事項

## 目的

流月雨の予告影、隕石の着弾位置、ダメージ範囲を同じ地上の着弾点に一致させる。

## 機能要件

- 黒い予告影の中心は、隕石画像の下部中央が接地する位置（`meteor_impacts.position`）とする。
- 落下中と着弾直後の隕石画像は、下部中央が予告影の中心に重なるよう描画する。
- 着弾時だけ、予告影の最終半径と同じ48pxの円をダメージ範囲とする。
- 隕石の描画範囲そのものに継続的な当たり判定を設けない。
- ローカル対戦とDedicated Server対戦で同じ着弾判定を使う。

## 検証要件

- サーバーシミュレーションで、着弾点から影半径内の相手だけがダメージを受け、範囲外では受けないことを確認する。
- Godotの関連テスト、ヘッドレス起動、差分の空白検査を実行する。
