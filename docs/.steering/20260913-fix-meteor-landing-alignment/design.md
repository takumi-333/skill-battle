# 設計

`meteor_impacts.position` を唯一の地上着弾アンカーとして扱う。影と波紋は従来どおりこの座標を中心に描画し、隕石テクスチャは描画矩形の下辺中央がこの座標と一致するよう上方へオフセットする。

ダメージ半径は予告影の最終半径 `METEOR_RADIUS` を参照する。ローカル用 `match_prototype.gd` とサーバー権威の `match_simulation.gd` の両方で同じ値に統一し、着弾フラグが初めて立つ時点だけ相手の当たり判定を評価する。

既存の隕石テクスチャの縦横比は保持し、落下アニメーションの開始高度のみ現行のままとする。これによりテクスチャ下部が地面へ到達する見た目と、同期された影・判定が一致する。
