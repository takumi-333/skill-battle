# 設計

- `magic_zones` の各要素に、生成後の経過時間、予告時間、光柱の伸長時間、ダメージ間隔・タイマーを保持する。
- 描画は既存のワールド `_draw()` 内でテクスチャを直接描画する。魔方陣はアルファを予告時間に合わせて補間し、光柱はワールド上端から魔方陣へ向けた矩形へ段階的に描画する。
- 光柱の横幅・縦幅は、予告直後の2フレームずつで1/3、2/3、最大へ進め、残存時間中は最大値から0へ縮小・フェードする。判定はテクスチャの透明領域ではなく、既存どおり中心半径80pxの円で行う。
- ローカル実装と `MatchSimulation` のゾーン状態を同じ値・判定周期にする。表示専用値もスナップショットの補間対象に含める。
- なぞり失敗時は `end_active_challenge()` の前に既存ミス演出値を設定し、短時間のフィードバック後に閉じる。サーバー権威経路ではクライアントが送信前に同じ評価で演出し、権威判定は従来どおりサーバーに任せる。
