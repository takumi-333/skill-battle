# 詠唱士スキル仕様変更

## スキルの挙動変更
スキル発動ミスしたとき（スコアが一定以下）だった際に、
スキルウィンドウを赤くし、揺らすことで失敗したことを演出
（演出自体は打鍵士・算術士のものを参照）

## スキル1: 既存のもの
以下のように仕様と実装を修正

### スキル名
月柱（げっちゅう）・昇華

### 演出の変更
- 相手の足元にただの円ではなく魔方陣を出現させるようにする
    （これを使うassets\ui\skill_effects\chanter_area.png）

- 魔方陣は今の円と同様、相手の足元に出現する
- 魔方陣は暗い状態からだんだん明るくなるような形で出現
    - 相手の足元に危険信号としての役割がある
    - 0.5秒かけて完全に表れる
- 魔方陣が現れきったら光の柱を魔方陣の上に出現させる（これを使うassets\ui\skill_effects\chanter_beam.png）
- 光の柱は太くなりながら一瞬で画面最上部まで伸びる
（そしてだんだんと細くなっていき、魔方陣とともに消える）
- ダメージ判定自体は魔方陣の中のみ

### 時間経過によるスキルの挙動
| 経過時間 | 挙動 |
| ---: | --- |
| 0.0秒 | 相手の現在位置にエリア1を生成 |
| 0.0〜0.5秒 | エリア1の魔方陣を暗い状態から徐々に明るく表示する予告状態 |
| 0.5秒から2フレーム間 | エリア1の光の柱を、魔方陣の直径の1/3の太さ・画面上部までの高さの1/3で出現させる。この時点から、光の柱の範囲内に継続ダメージ判定を発生させる |
| 続く2フレーム間 | エリア1の光の柱を、魔方陣の直径の2/3の太さ・画面上部までの高さの2/3まで伸ばす。継続ダメージ判定を維持する |
| その後〜2.0秒 | エリア1の光の柱を魔方陣相当の太さ・画面最上部まで伸ばした状態にし、徐々に細く、薄くして消滅させる。光の柱が表示されている間は継続ダメージ判定を維持する。魔方陣は明滅させず、表示した明るさを保って光の柱とともに消滅させる |
