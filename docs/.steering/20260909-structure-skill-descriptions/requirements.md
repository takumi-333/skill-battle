# 要件

## 目的

各キャラクターのスキル仕様書に、キャラクター画面で表示するための簡潔で構造化された説明文を正本として追加する。ゲーム内のスキル詳細ウィンドウは、この正本と同じ内容を表示する。

## 表示構造

- 打鍵士・算術士は「クールタイム」「制限時間」「スキル説明」の順で表示する。
- 詠唱者は時間制限がないため、「クールタイム」と「スキル説明」のみを表示する。
- 算術士は各スキルの説明とは別に、妨害ポイントの獲得条件と強化内容を説明する常設欄をキャラクター画面に設ける。
- 未実装スキルの既存の準備中表示は維持する。

## 内容

- 実装済みスキルの説明文は、現行のゲーム内効果・課題・クールタイムと一致させる。
- 算術士「無限級数」の説明から、発動時の移動速度・通常攻撃強化には触れない。分身、相手への妨害、妨害ポイントの獲得を説明する。
- 算術士「最適解への収束」の説明は、透明化による接近・離脱の用途を説明する。

## 完了条件

- 3キャラクターの実装済みスキルすべてに「説明文」章がある。
- キャラクター画面で、各スキルにキャラクター別の構造化説明が表示される。
- 算術士選択時だけ妨害ポイント説明欄が表示される。
- Godot の headless 起動でスクリプトエラーがない。
