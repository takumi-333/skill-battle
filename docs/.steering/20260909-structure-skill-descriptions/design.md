# 設計

## 仕様書

各 `スキルN候補一覧.md` の個別スキルに `### 説明文` 章を追加する。説明文はゲーム画面で改行表示できる本文だけを記録し、クールタイムと制限時間は既存の `### 効果`・`### 課題` の値を正本とする。

算術士の妨害ポイントはキャラクター共通の仕組みなので、`算術士/ベース.md` の固有スキル仕様に、画面用の説明文を追加する。

## UI

固定レイアウトは `scenes/ui/character_screen.tscn` に追加する。スキル詳細パネルには、スキル情報の表示を担う既存の `SkillDescription` Label を使用する。

`match_prototype.gd` の `skill_description()` を、キャラクター・スキル・候補ごとに構造化文字列を返す形に更新する。値はゲーム実装のクールタイム・制限時間と同期させる。

算術士の妨害ポイント説明欄はキャラクター画面本体に Label として配置し、`update_character_screen()` で算術士を選択中の場合のみ表示する。他キャラクターでは非表示にする。

## 検証

テキストと仕様の一致を検索で確認し、Godot を headless で起動して構文・シーン読み込みエラーを確認する。
