# 仕様の修正

## スキルをセットした後に、保存する機能

現在、スキルをセットした後、再起動するとすべて初期化されているが、
スキルをセットしたのは保存しておきたい。
これはデバッグ時も、windowsなどビルド版作成後もそのようにしたい。

## オンライン対戦での集中状態時のBGM

オンライン対戦で集中状態に入るとBGM音が小さくなるが、
これは集中状態に入っている人だけがBGM小さくなり、
入っていない人のBGMは小さくなってはいけない

## オンライン対戦試合終了時の挙動の改修

どちらかが敗北等で試合が終わるときにスキルウィンドウが開いていると
リザルト画面でも開いたままになる。
対戦画面のその状態が続くわけない。
