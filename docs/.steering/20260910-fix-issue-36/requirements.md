# 要件

- キャラクター画面で明示的に SAVE したスキル構成を、次回起動時に復元する。
- 保存先は Godot の `user://` とし、エディタ実行および Windows エクスポート版で書込み・読込みできるようにする。
- 読込み値はキャラクター別・3スロット別に検証し、欠損・不正値・未実装候補は安全な実装済み初期候補へ戻す。
- オンライン対戦では、集中状態による BGM の減衰／ローパスを、そのクライアントを操作するプレイヤーが集中している場合にだけ適用する。
- ローカル／デバッグの音量仕様は既存の挙動を維持する。
- 試合が `finish` または `result` へ移った時点で、課題（スキル）オーバーレイ、入力フォーカス、描画中のなぞり状態を確実に終了する。
- P2P と Dedicated Server の双方で、試合終了からリザルトへの遷移時に課題 UI が残らないことを回帰テストで確認する。

## 今回の事前調査

- 保存ボタンの `save_character_skills()` は現在、画面上の表示更新と Dedicated Server への送信だけを行い、永続ストレージへ書き込んでいない。
- BGM 判定 `is_battle_focus_active()` は `players` の全員を走査しているため、受信した相手の `focused` 状態でもローカルの `BattleBGM` バスを減衰させる。
- 画面遷移時の課題 UI 非表示処理は `UIScreenManager.show_screen()` と `_on_screen_changed()` に既に存在する。実際の再現条件をテストで固定し、終了経路で必ず共通の終了処理を通ることを確認する。
