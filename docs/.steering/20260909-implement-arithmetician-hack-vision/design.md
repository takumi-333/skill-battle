# 設計

- 算術士のスキル3候補0を `arithmetic_hack_vision` としてロードアウトへ登録し、既存の候補ロック判定を解除する。
- サーバー権威の `MatchSimulation` に専用の追尾弾と対象プレイヤーの `hack_vision_time` を追加する。弾はダメージを与えず、命中時だけ残り時間を設定する。
- ローカル対戦側も同じ課題・クールダウン・追尾弾・状態時間を実装する。
- 固定UIは `scenes/ui/hack_vision_overlay.tscn` に置き、課題レイヤーより前面の `CanvasLayer` へ配置する。HUDはさらに前面の専用 `CanvasLayer` へ移し、HPバーとスキルアイコンをノイズから保護する。シェーダーで下層画面をブロック単位で再サンプルし、画面中心からの距離に比例して青いノイズ、走査線、ピクセル化を強める。
- 表示側は受信状態の操作プレイヤーだけにオーバーレイを表示する。カメラが操作キャラクターを中央に保つため、画面中心を「自キャラから近い場所」として扱う。
- テストは選択可否、課題の問題・制限時間、追尾弾、命中後の時間、スナップショット状態を検証する。
