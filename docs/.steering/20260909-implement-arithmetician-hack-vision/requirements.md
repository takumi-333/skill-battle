# 要求

算術士のスキル3「視覚妨害（ハックビジョン）」を実装する。

- 算術課題は候補一覧にある問題から出題し、制限時間は15秒とする。
- 正解時、相手を必中で追尾する妨害弾を発射する。命中すると相手にノイズ状態を付与する。
- ノイズ状態の時間はスコア × 0.9秒とする。
- ノイズは画面周辺ほど強く、画面中央（操作中の自キャラ付近）は見やすく保つ。
- ノイズ領域では青系のデジタルノイズと、粗いピクセル化による解像度低下を表示する。
- 効果は課題ウィンドウを含む相手画面の前面に表示する。ただしHUDのHPバーとスキルアイコンは効果より前面に置き、常に読めるようにする。
- ローカル対戦と専用サーバー対戦で同じルール・選択状態を扱い、自動テストで保護する。
