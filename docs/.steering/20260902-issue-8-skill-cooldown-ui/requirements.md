# issue-8 対戦中HUD要求

- 左上のキャラクター名・相手情報・秒数形式のクールダウン文字列を廃止する。
- 自分のHPだけをHPバーと数値で表示する。
- `skill_diamond_small_ready.png`、`skill_diamond_medium_ready.png`、`skill_diamond_large_ready.png` をHUDの枠として使用する。
- 通常攻撃は小、スキル1は中、スキル2と未実装スキル3は大の枠で表示する。
- スキル3は未実装のため常に使用不可表示にする。
- 使用可能時は中央のアイコンを明るくし、クールダウン中は中央を暗くしたうえで回復率に応じて12時方向から時計回りに明るい領域を増やす。
- 枠画像の下部プレートには、実際のキー操作（Space、1、2、3）を後から差し替えられる動的ラベルとして表示する。
- アイコンは現段階では共通の仮プレースホルダーを使い、後から個別素材へ差し替え可能にする。
