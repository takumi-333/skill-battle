# issue-8 HUD設計

`scripts/match_prototype.gd` にHUD専用の `SkillDiamondWidget` を追加する。ウィジェットはready枠テクスチャを描画し、透明な中央領域へ仮アイコンを描く。クールダウン率は中央のひし形を暗いポリゴンで覆い、回復率分の扇形ポリゴンを12時から時計回りに重ねて表現する。

HUDは `CanvasLayer` 上に自分側だけを作る。通常攻撃・スキル1・スキル2・スキル3を左下に横並びで配置し、サイズ差を保つ。既存の `attack_cooldown`、`small_cooldown`、`big_cooldown` を毎フレームウィジェットへ渡すため、ゲームルールやネットワーク同期形式は変更しない。

HP表示は左上にHPバーと数値を置き、既存のプレイヤー頭上HPバーはゲーム内情報として残す。アイコンは固有アセットを増やさず、ウィジェット内の共通ルーンを仮表示する。
