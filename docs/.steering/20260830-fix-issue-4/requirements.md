# issue-4 修正要件

## 目的

デバッグ対戦で一人がP1・P2の両キャラクターを検証できるようにし、操作対象と表示情報を個別に扱えるようにする。

## 要件

1. デバッグ対戦開始前または対戦中に、ユーザーが操作対象をP1またはP2から選択できる。
2. 選択したキャラクターだけがキーボード入力で移動・攻撃・スキル発動を行う。
3. 選択していないキャラクターは、デバッグ対戦の相手キャラクターとして通常どおり画面に残り、入力によって同時操作されない。
4. デバッグ対戦のUIにP1・P2両方のキャラクター情報を表示する。
5. デバッグ以外の練習対戦・オンライン対戦の操作および表示仕様は変更しない。
6. 既存のキャラクター選択、対戦開始、スキルクールダウン表示と競合しない。

## 受け入れ条件

- デバッグ画面で操作対象をP1/P2から選択できる。
- P1操作を選んだ場合、P1だけが入力に反応し、P2へ攻撃・スキルを試せる。
- P2操作を選んだ場合、P2だけが入力に反応し、P1へ攻撃・スキルを試せる。
- デバッグ画面にP1・P2双方のキャラクター名、HP、スキル状態などのステータスが表示される。
- Godotのヘッドレス起動およびエディタ読み込みでエラーが発生しない。
