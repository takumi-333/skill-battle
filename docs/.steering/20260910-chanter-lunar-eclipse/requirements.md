# 要求内容

## 概要

詠唱者のスキル3候補「月蝕:潮汐」を、ローカル対戦とサーバー権威のオンライン対戦で同一のルールで使用可能にする。既存の星形なぞり課題を用い、専用アイコンとブラックホール・レーザー演出を表示する。

## 背景

仕様書に定義済みの月蝕を詠唱者のスキル3として選択・発動できるようにし、スキル3の既存候補（十六夜）と選択肢を切り替えられる必要がある。

## 実装対象の機能

### 1. 月蝕のゲームルール

- 星形を45点以上でなぞったとき、発動時の位置と向きを固定し、2.5秒の詠唱中は行動不能にする。
- 300px前方（ステージ内に収める）にブラックホールを出現させ、スコアに応じた半径・吸引力で相手を引き寄せる。
- 発動1.0秒後から固定方向に1.5秒間、幅120pxのレーザーを放ち、最大3回のダメージを与える。

### 2. 選択・表示・同期

- 詠唱者のスキル3候補として十六夜と月蝕を選択でき、選択内容をローカル・オンラインで同期する。
- `chanter_new.png` を月蝕を表す名前へ改名し、月蝕のスキルアイコンとして表示する。
- ブラックホール、レーザー核、レーザーをローカル表示とスナップショット表示で描画する。

## 受け入れ条件

### 月蝕のゲームルール

- [ ] 星形なぞりが45点未満なら発動せず、45点以上で月蝕が開始する。
- [ ] 発動位置・向きが固定され、2.5秒間は移動・向き変更・通常攻撃・他スキルを行えない。
- [ ] ブラックホールが仕様の位置・成長半径・吸引間隔・最小距離・ステージ内補正に従う。
- [ ] レーザーが発動1.0秒、1.5秒、2.0秒にだけ仕様のダメージを与える。

### 選択・表示・同期

- [ ] 詠唱者のスキル3候補として月蝕を選択でき、ローカル対戦とオンライン対戦で同じ結果になる。
- [ ] 改名後のアイコンが月蝕の選択枠とHUDに表示される。
- [ ] ブラックホールとレーザーが双方の画面に表示される。

## 成功指標

- ルールの境界値、行動不能、命中回数、同期内容を自動テストで検証する。
- Godotのヘッドレス起動と既存ネットワークテストがエラーなく完了する。

## スコープ外

- 月蝕以外の未実装スキル候補の実装。
- スキル仕様そのものの数値・課題内容の変更。
