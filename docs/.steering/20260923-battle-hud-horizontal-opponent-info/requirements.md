# 要求内容

## 概要

3人対戦HUDの各相手情報を、HPバー直下で名前と算術倍率が横並びになるよう配置する。両方をHPバーと同じ幅に収め、長い表示でも重ならないようにする。

## 受け入れ条件

- [ ] 相手名と `f(x) = ax` が縦ではなく横に並ぶ。
- [ ] 名前欄と倍率欄は同じ行にあり、互いに重ならない。
- [ ] 2つの欄全体がHPバーと同じ横幅内に収まる。
- [ ] 相手名が長くても倍率表示と重ならない。
