# 要求内容

## 概要

ゲーム画面の個別UI部品を `.tscn` に定義し、Godotの2Dビュー、Inspector、アンカー、Containerを使って通常のUI編集ができる構成に変更する。

## 受け入れ条件

- タイトル、ホーム、オンライン接続、ロビー、対戦HUD、課題、リザルトの個別Controlがローカルのシーンツリーに存在する。
- 画面遷移とボタン操作、対戦中の状態表示は既存の仕様を維持する。
- GDScriptは状態更新、可視性、入力・シグナル処理に限定され、レイアウト値を生成しない。

## スコープ外

- `_draw()` による対戦フィールド描画の変更。
- UIの意匠・ゲーム仕様の変更。
