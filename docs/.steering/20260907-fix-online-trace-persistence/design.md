# 設計

専用サーバーのスナップショットには、提出前の課題について空の `trace` が含まれる。クライアントが毎回その値を `challenge_trace_points` に代入すると、ローカルで描画中の未提出筆跡が失われる。

`_apply_dedicated_challenges_snapshot()` では、課題IDが変わった場合だけサーバー値で筆跡を初期化する。同じ課題IDのスナップショットではローカル筆跡を保持する。提出後はサーバーが課題を終了し、空の課題スナップショットで従来どおりUIを閉じる。

既存の専用サーバーUIテストに、同一IDの tracing 課題スナップショットを連続受信してもローカル筆跡が保持され、新規IDで初期化されるケースを追加する。
