# 要求

- 専用サーバーを使うオンライン対戦で、詠唱士のなぞり入力中に筆跡を画面に保持する。
- 筆跡はマウス解放時まで保持され、解放時にサーバーへ提出される。
- 新しいなぞり課題が開始されたときだけ、前の筆跡を初期化する。
- 既存のサーバー権威によるなぞり採点・不正入力検証は変更しない。
- 同じ課題IDのサーバースナップショット受信で、ローカルの未提出筆跡が消えないことを自動テストで保証する。

# 受け入れ条件

- オンライン対戦中、円または星を描き続けても描画済みの線が消えない。
- 十分な筆跡を解放時に提出すると、既存どおりスキルが発動する。
- 新しい課題に切り替わると筆跡は空から始まる。
