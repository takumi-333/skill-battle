# 要件

- 詠唱士スキル1候補2「宵月」を選択・使用可能にする。真上始点の時計回り16方向弾を、スコア別に1〜4周、発射時点の発動者位置から射出する。
- 宵月は3秒クールダウン、`3 + floor(スコア × 0.05)` ダメージ、約1.5周の渦巻き課題、候補1アイコンを用いる。
- 詠唱士スキル3候補1「十六夜」を選択・使用可能にする。候補2「月蝕:潮汐」は未実装・ロック状態を維持する。
- 十六夜は真上・真下始点の時計回り列と、右・左始点の反時計回り列を各発射時刻に同時に射出する。16時刻を1周とし、スコア別に1〜4周する。
- 十六夜は8秒クールダウン、宵月と同じダメージ式・発射位置・固定弾道、約3.5周の渦巻き課題、候補1アイコンを用いる。
