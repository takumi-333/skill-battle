# 設計

- スキル選択値をローカル・サーバー権威のプレイヤー状態へ保持し、既存候補の既定値を崩さずに宵月（スキル1候補2）と十六夜（スキル3候補1）を判別する。
- 専用の渦巻き生成関数へ周回数を渡し、宵月1.5周、望月2.5周、十六夜3.5周の点列をローカルとサーバーで一致させる。
- 宵月は16弾、十六夜は4方向列のため64弾を1周として予約する。各弾は既存の `fixed_direction` 状態を使い、発射直前の所有者位置から開始する。
- スキル3開始条件を打鍵士専用から詠唱士候補1にも拡張し、スキル3専用の8秒クールダウンと中断ゲージを適用する。
- 自動テストで候補の実装可否、課題の周回数、射撃数・開始方向・同時性、スコア帯、クールダウンを検証する。
