### 実装完了日

2026-09-11

### 計画と実績の差分

保存ボタンの背後への入力漏れに加え、既存の配布スクリプトが Godot の非同期 `savepack` 完了前、最長 5 秒で出力を確認して失敗することが判明した。実行ファイルのサイズが安定するまで最大 300 秒待つ実装を追加し、ZIP と SHA-256 の生成まで完了させた。

### 学んだこと

モーダルは視覚的な前面表示だけでなく、ルート・ディマー・パネルで `MOUSE_FILTER_STOP` を明示し、クリックの解放処理中には閉じない必要がある。ヘッドレス環境では表示スケールが実機と異なるため、重複座標の検証とモーダルの入力遮断・遅延クローズを分けてテストした。

### 次回への改善提案

ホーム画面の操作部品とモーダルの重なりを変更するときは、背面ボタンとの座標重複と入力遮断を回帰テストで確認する。Godot のエクスポート後は固定時間待機ではなく、成果物の安定確認を行う。
