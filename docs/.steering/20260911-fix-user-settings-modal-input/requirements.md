# 要求内容

## 概要

ユーザー設定モーダルの保存操作が背後のホーム画面のデバッグボタンにも届き、デバッグ画面へ遷移する不具合を修正する。修正後の Windows x64 クライアント配布 ZIP を作成する。

## 背景

保存ボタンとデバッグボタンの画面座標が重なっている。設定モーダルが表示されている間は、背後のホーム画面を一切操作できなければならない。

## 実装対象の機能

### 1. モーダル入力の遮断

- ユーザー設定モーダルと背景ディマーがマウス入力を停止する。
- 保存をクリックしても、同じクリックが背後のホーム画面へ渡らない。
- 保存に成功した場合だけモーダルを閉じ、ホーム画面に留まる。

### 2. 配布クライアントの再作成

- Godot の Windows Client プリセットで x86_64 の配布物を再ビルドする。
- ZIP と SHA-256 ファイルを `build/releases/` に生成する。
- Godot が出力ファイルを作り終えるまで待ってから、ZIP 作成を開始する。

## 受け入れ条件

### モーダル入力の遮断

- [ ] 保存ボタンの全領域（デバッグボタンと重なる部分を含む）をクリックしても、デバッグ画面へ遷移しない。
- [ ] 有効な名前、HTTPS URL、招待トークンを保存すると、モーダルだけが閉じて値が再表示できる。
- [ ] 無効な設定では、モーダルを閉じずに検証メッセージを表示する。

### 配布クライアントの再作成

- [ ] Godot のヘッドレス検証でパースエラーがない。
- [ ] Windows x64 の ZIP と SHA-256 ファイルが生成される。
- [ ] エクスポート完了前に `SkillBattle.exe` がないとしてビルドが失敗しない。

## スコープ外

- 招待トークンや URL の仕様変更
- デバッグ画面そのものの変更
- Windows ARM64 向けクライアントの追加
