# 要求内容

## 概要

対戦HUDで数値のHPを表示するのは自分だけにし、相手のHPはバーの残量で示す。2人対戦では相手名と相手の倍率を隠し、3人対戦では各相手のHPバー直下に名前と `f(x) = ax` の表示欄を配置する。

## 背景

相手のHPを正確な数値で把握できる必要はなく、ゲーム画面では残量バーから状態を読み取れるようにする。3人対戦では相手を識別するため、名前と算術士の倍率をHPバーの下にまとめる。

## 実装対象の機能

### 1. 自分のHP詳細
- 自分のHPバーとHP数値を維持する。
- 自分が算術士の場合の倍率表示を維持する。

### 2. 相手HPと人数別情報
- 相手のHP数値を表示せず、HPバーのみで残量を示す。
- 2人対戦では相手名および相手の倍率欄を表示しない。
- 3人対戦では各相手のHPバーの下に名前欄と倍率欄を配置する。
- 3人対戦の倍率欄は相手が算術士の場合に値を表示する。

## 受け入れ条件

### 2人対戦HUD
- [ ] 自分のHP数値が表示される。
- [ ] 相手のHP数値、名前、倍率が表示されない。
- [ ] 相手のHPバーは残量に応じて更新される。

### 3人対戦HUD
- [ ] 自分のHP数値が表示され、両相手のHP数値は表示されない。
- [ ] それぞれの相手のバー直下に名前欄と倍率欄がある。
- [ ] HPバーと下の情報欄が重ならず、相手ごとに識別できる。
- [ ] 名前と倍率がプレイヤー状態に応じて更新される。

## 成功指標

- 2人対戦では自分だけがHPの正確な数値を読める。
- 3人対戦では相手のHP残量、名前、算術倍率を意図した位置で確認できる。

## スコープ外

- HP計算、ネットワーク同期、勝敗判定の変更。
- 対戦フィールド上の名前表示やリザルト画面の変更。
