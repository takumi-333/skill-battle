# 設計

- 発射列は16発ずつ、既存の0.08秒間隔で予約する。各周では真上から時計回りに16発、続けて真下から反時計回りに16発を予約する。
- 各予約弾は作成時に固定した速度ベクトルを持つが、予約解除時に発動者の現在位置へ配置してから移動を開始する。これによりプレイヤー移動後も発射位置は発動者中心となり、弾道は予約時から変わらない。
- `MatchSimulation` と `match_prototype.gd` の投射物更新で共通の `fixed_direction` 状態を扱い、通常の打鍵士弾のターゲット追尾開始と区別する。
- `chanter_ball.png` はワールド描画で速度方向に回転したテクスチャとして描き、既存の単純な円形弾表示を置き換える。
- なぞり目標は中央から外側へ伸びる約2.5周の渦巻きとして、ローカルと権威シミュレーションで同じ点列を返す。
- テストは周回数、開始方向、固定方向、移動後の発射位置、ダメージ、渦巻き点列を検証する。
