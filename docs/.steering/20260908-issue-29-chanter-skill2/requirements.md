# 要件

- 詠唱士スキル2の名称を「望月（もちづき）」へ更新し、HUD アイコンに `chanter_evening_moon_stage_2.png` を用いる。
- 詠唱士スキル2の課題は、添付図を基にした中心から外へ約2.5周する渦巻き状の目標紋章にする。
- クールダウンは5秒、ダメージは `3 + floor(スコア × 0.05)` とする。
- 発動成功後、発動者を中心に16方向へ順番に弾を射出する。時計回りの列は真上から、反時計回りの列は真下から開始する。
- 繰り返し周回数は、スコア30以下で2周、50以下で3周、75以下で4周、76以上で5周とする。1周は時計回り列と反時計回り列を各1回含む。
- 弾は発射時点の発動者の位置から射出し、移動中の発動者にも追従して各弾の射出位置を決定する。一度発射した弾は方向を変更しない。
- 弾の視覚表現は `chanter_ball.png` を使う。ローカル対戦とオンライン対戦で同じゲーム結果になるよう、サーバー権威シミュレーションにも同一仕様を実装する。
- スキル2仕様書と自動テストを更新し、issue 解決後にそのままアーカイブできる状態にする。
