# タイトル画面修正 設計

## 方針

既存のタイトル画面を構成する`match_prototype.gd`へ、タイトル画面専用の経過時間と開始プロンプト参照を追加する。既存のロゴ描画領域と入力遷移は維持し、描画時のクリッピングとアルファ値で演出する。

## ロゴの左から右への表示

- タイトル画面へ入った時点でロゴ演出経過時間をリセットする。
- `_process(delta)`でタイトル画面中だけ経過時間を進める。
- `_draw()`では、現在の演出進行率からロゴの表示幅を計算する。
- ロゴ画像の元の矩形位置・高さは変更せず、表示幅だけを0から全幅まで増やす。
- `draw_set_clip_rect()`でロゴ矩形を左から順にクリップし、固定位置のまま左→右へ可視化する。
- 演出完了後は全幅を描画する。

## 開始プロンプトの点滅

- `title_prompt`をメンバー変数として保持する。
- タイトル画面中の経過時間から正弦波または周期関数でアルファ値を算出し、プロンプトの`modulate.a`へ反映する。
- タイトル画面以外ではアルファ値を通常表示へ戻す。

## 開始音

- 既存の`ui_click_player`と`UI_CLICK_SOUND`を利用する。
- タイトル画面の入力条件に一致したとき、ホーム画面へ遷移する直前に`play_ui_click()`を呼び出す。
- 既存のButton接続によるUIクリック音とは別に、キー入力・背景クリックにも同じ再生処理を適用する。

## 状態遷移

```text
タイトル画面表示
  ├─ ロゴ経過時間を0へリセット
  ├─ ロゴを左から右へ表示
  └─ プロンプトを点滅

Space / Enter / 左クリック
  ├─ 開始音を再生
  └─ ホーム画面へ遷移
```

## 検証方針

- Godotのプロジェクトチェックまたは実行でGDScriptエラーがないことを確認する。
- タイトル画面を目視し、ロゴ位置が動かず、左から右へ表示されることを確認する。
- プロンプトの明滅と、Space・Enter・左クリックそれぞれの開始音・画面遷移を確認する。
