# タイトル画面修正 要求仕様

## 目的

タイトル画面に視覚・聴覚的なフィードバックを追加し、ゲーム開始操作を分かりやすくする。

## 要求事項

### ロゴ演出

- タイトルロゴはタイトル画面表示時にアニメーションを開始する。
- ロゴの位置・サイズは現在のレイアウトを維持する。
- ロゴは左側から右側へ順番に表示されるようにする。
- 表示途中は、まだ表示されていない右側の領域が見えない状態にする。
- アニメーション完了後はロゴ全体を表示する。

### 開始プロンプト

- 「Press Space / Enter / Click to Start」の開始プロンプトを点滅させる。
- 点滅はタイトル画面表示中のみ動作する。
- 点滅によって入力操作や画面レイアウトを妨げない。

### 開始音

- Spaceキー、Enterキー、またはマウス左クリックでタイトル画面から遷移するとき、開始音を1回再生する。
- タイトル画面以外の入力では、開始音を再生しない。
- 既存のUIクリック音素材または同等の音声素材を利用する。

## 受け入れ条件

- ゲーム起動時、ロゴが固定位置のまま左から右へ順番に表示される。
- ロゴ演出完了後もロゴが消えずに表示される。
- 開始プロンプトがタイトル画面表示中に一定周期で明滅する。
- Space、Enter、左クリックの各操作でホーム画面へ遷移し、それぞれ開始音が鳴る。
- Godot実行時にスクリプトエラーが発生しない。
