# 要求

- Windows の開発用ランチャーと公開用ランチャーは、それぞれ専用の環境設定ファイルだけを参照する。
- 開発用の接続先は常にローカルホスト、Dedicated Server の待受とクライアントに返すポートは UDP 17000 とする。
- 公開用の playit.gg ホスト名・ポート・公開モード設定を開発用プロセスへ渡さない。
- 既存の `local.env` に公開用設定が混入している場合、開発用起動時にローカル専用設定へ移行し、公開用設定や秘密値を流用しない。
- `public.env` の内容は開発用起動によって変更しない。
- 開発用クライアント設定は従来どおりランチャーが生成し、手入力を要さない。
- デバッグビルドでは、保存済みの loopback HTTP Lobby 設定を最新のローカルクライアント設定で更新し、HTTPS 必須エラーや旧トークンによる失敗を起こさない。

## 完了条件

- 公開用設定を含む旧 `local.env` からの移行後、Lobby が `127.0.0.1:17000` を返す設定になる。
- 移行後の `local.env` と `public.env` は別の秘密値を持ち、以後のローカル起動ではローカル秘密値が維持される。
- PowerShell の自動テストで、移行・再起動時の安定性・公開設定非変更を確認する。
