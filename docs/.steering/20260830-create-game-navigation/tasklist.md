## 実装後の振り返り

### 実装完了日

2026-08-30

### 計画と実績の差分

タイトル・ホーム・練習・デバッグのメニューは設計どおり追加した。オンライン待機は既存のロビー状態とRPCを再利用し、左右の操作ボタンを追加した。Godot実行ファイルが環境にないため、起動確認は静的検査に置き換えた。

### 学んだこと

単一シーンの既存実装では、メニュー用の`screen`状態と試合用の`phase`状態を分離すると既存対戦ロジックを保ったまま導線を追加できる。画像生成アセットはプロジェクト内へコピーし、参照パスを固定する必要がある。

### 次回への改善提案

Godot実行環境を用意した上で、次回は2プロセスのオンライン待機と練習モードを実機確認し、UIの視認性もスクリーンショットで検証する。
