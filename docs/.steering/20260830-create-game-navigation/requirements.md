# 要求内容

## 概要

既存の対戦プロトタイプへ、タイトルからオンライン対戦・練習・デバッグを開始するまでの画面導線を追加する。オンライン対戦では現在のルーム作成・参加機能を維持し、待機画面で両プレイヤーがキャラクターを選択して準備完了後に試合を開始できるようにする。

## 背景

現在の機能は対戦開始用の導線が限定的で、プレイヤーが用途に応じた開始方法を選べない。タイトル・ホーム・各開始画面を設け、オンライン対戦、1人での練習、同一PCでのデバッグを分かりやすく選択できるようにする。

## 実装対象の機能

### 1. タイトル画面

- 「スキルバトラーズ」の仮タイトルロゴを表示する。ロゴは通常のテキスト表示ではなく、ゲームのタイトルとして視認性と迫力を持つ画像とする。
- 「Press Space to Start」相当の開始案内を表示する。
- スペース、Enter、または画面クリックでホーム画面へ遷移できるようにする。

### 2. ホーム画面

- 画面左半分に「オンライン対戦」ボタンを配置する。
- 画面右半分に「練習」「キャラクター」「デバッグ」の各ボタンを配置する。
- 「オンライン対戦」はオンライン対戦画面へ、「練習」は練習画面へ、「デバッグ」はデバッグ画面へ遷移する。
- 「キャラクター」は将来の育成画面用の入口として表示するが、本フェーズでは画面本体を実装対象外とする。

### 3. オンライン対戦画面

- 既存の「ルームを作成」「ルームに参加」の機能と操作を維持する。
- ルーム作成または参加に成功した場合、待機画面へ遷移する。

### 4. オンライン待機画面

- 打鍵者、算術士、詠唱者の3キャラクターの既存立ち絵を用いて、左右操作で選択中のキャラクターを切り替えられるようにする。
- ホストは画面左半分、参加者は画面右半分で自分のキャラクターを選択する。
- 相手が未入室の場合は相手側を空欄とし、入室後は相手の存在を人影などで視覚的に確認できるようにする。
- 各プレイヤーの準備状態を画面上部に「準備中」または「準備完了」として表示する。
- 両プレイヤーがキャラクターを選択して準備完了した時点で、既存のオンライン対戦を開始する。

### 5. 練習画面

- 3キャラクターから操作キャラクターを選択できるようにする。
- 選択後、対戦相手なしで選択キャラクターを自由に操作できる練習用のゲームを開始する。

### 6. デバッグ画面

- 待機画面に近い構成で、画面左側・右側それぞれのキャラクターを3キャラクターから独立して選択できるようにする。
- 選択した組み合わせで、既存の同一PC用デバッグ対戦を開始できるようにする。

## 受け入れ条件

### タイトル・ホーム画面

- [ ] 起動時に仮タイトルロゴと開始案内が表示される。
- [ ] スペース、Enter、クリックのいずれでもホーム画面へ遷移できる。
- [ ] ホーム画面でオンライン対戦、練習、キャラクター、デバッグの入口が画面の指定位置に表示される。

### オンライン対戦・待機画面

- [ ] 既存のルーム作成・参加が可能で、成功後に待機画面が表示される。
- [ ] ホストと参加者はそれぞれ指定された側でキャラクターを選択でき、相手の入室状況と準備状態を確認できる。
- [ ] 両者がキャラクターを選択して準備完了すると、選択内容を反映したオンライン対戦を開始できる。

### 練習・デバッグ画面

- [ ] 練習画面でキャラクターを選択し、相手なしの練習を開始できる。
- [ ] デバッグ画面で左右それぞれのキャラクターを選択し、同一PCデバッグ対戦を開始できる。

## 成功指標

- プレイヤーが起動後、用途に応じてオンライン対戦、練習、デバッグの開始方法を選択できる。
- オンライン対戦の両参加者が、試合開始前にキャラクター選択と相互の準備状況を確認できる。

## スコープ外

以下はこのフェーズでは実装しません:

- キャラクター画面における育成・成長・装備などの機能
- タイトルロゴの最終デザイン、タイトル画面の豪華な演出
- 自動マッチング、専用サーバー、再接続など、既存仕様にないオンライン機能
- 待機画面以外での新規キャラクター追加や対戦ルールの変更
