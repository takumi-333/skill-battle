## タイトル画面の作成
いつか豪華にする予定だが、いったんは
タイトル：「スキルバトラーズ」と
「Press Space to Start」みたいなのを表示して、スペース・エンター・クリック押してスタートみたいな感じにしたい。

一応スキルバトラーズのタイトルロゴ画像は仮で作成しておいて。
普通の文字だと迫力ないので

## ホーム画面の作成
ホーム画面は、

「オンライン対戦」が画面左半分のボタンとなっており、
「練習」、「キャラクター」、「デバッグ」が画面右半分にある感じ。

## オンライン対戦画面
今のルームを作成・ルームに参加ができるのと同じ感じでよい。
ルームを作成・参加すると「待機画面」へ

## 待機画面
キャラクター選択ができる（3キャラの立ち絵から表示される）
右左に立ち絵を切り替えながらキャラ選択できる感じ。
二人ともキャラ選択し、準備完了を押したら、ゲーム開始

- ルームを作成した場合
    画面左半分でキャラ選択ができる
    そして画面右半分は、人が入室していなければ空、人が入室したら人影があり、入室したのが確認できる。
    準備中か準備完了かは画面の上にそれぞれ表示される
- ルームに参加した場合
    画面右半分でキャラ選択ができる
    画面左半分はホストの人影。
    準備中か準備完了かは画面の上にそれぞれ表示される

## 練習画面
ここは相手なしで自由に自分のキャラの練習をできるところ
まずは、キャラを選んでそのまま練習って感じ。
