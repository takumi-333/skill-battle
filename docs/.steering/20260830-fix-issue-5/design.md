# 実装方針

- `match_prototype.gd` に課題モーダル用の暗幕、時間バー、なぞりキャンバスを生成する。
- なぞりの座標は画面座標ではなくモーダル内キャンバス座標で保存し、ネットワーク送信時も同じ座標系を使う。
- `_draw()` で正解点列と入力軌跡をキャンバスの位置へ描画する。正解図形のデータはスキル開始時に作る。
- 採点は、端点距離、入力点の線分距離、正解線を一定間隔に分割したサンプルの被覆率を合成し、既存の小技45点・大技70点の合格基準を維持する。
- 課題UIは既存の `ChallengeLayer` 配下に置き、ネットワーク状態では課題の表示内容だけを同期する。入力判定は従来どおりホストで行う。
