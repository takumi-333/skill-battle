# issue-5 改修要件

## なぞり課題

- 詠唱者の小技は右向きの直線、大技は星形の正解点列を表示する。
- 正解点列は `PackedVector2Array` として保持し、画像に依存しない。
- 始点を円、終点を矢印、正解線を半透明の太線で表示する。
- プレイヤーの入力軌跡を同じ描画領域へ重ねて表示する。
- 入力軌跡の始点・終点、線分からの距離、正解線上の通過率を組み合わせて採点する。

## 共通スキルモーダル

- モーダルを画面中央寄せ、画面中央より少し下へ拡大する。
- 表示中はモーダル外を暗くする。
- 見出しは「スキル1　発動！！」または「スキル2　発動！！」とする。
- 移動速度低下・通常攻撃不可の説明文は表示しない。
- 残り時間をモーダル上部の細いバーで表示し、時間切れで失敗する。
