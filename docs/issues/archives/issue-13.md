# 対戦中UIの改修

## 左上のテキスト全廃止
自分、算術士、HP100、通常0.0sとかはすべて廃止する。

## 新しく表示するUI
- HPの値は、自分のHPのみHPバーの横に数値を表示する

- スキルのクールタイムは次のように管理する。

この画像の６のいちのようにひし形の枠を用意する。そこに各スキルのひし形を適切に配置する。そしてひし形の中に各スキルのアイコンが表示されている、さらに使えるスキルは光っていて、使えないスキルは暗い（クールタイムを表すように時計のようにだんだん明るいエリアが増えていく）
- 通常スキル小さ目
- スキル1: 中くらい
- スキル2: 大
- スキル3: 大（未実装、まだ使えなくてよい）
![alt text](image-1.png)

スキルのクールタイムは
- ひし形の中のアイコンが完全に光っていたら、発動可能
- 利用後、真っ暗になり、ひし形の真ん中（アイコンの真ん中）を中心に時計回りにだんだん光のエリアが拡大されていく。
- 再度全体が明かるくなったら、発動可能

ひし形のアイコンは、
skill_diamond_xxx.pngを利用してね。

## 各スキル用のアイコンを作成する

まずアイコンを作る前にアイコンの規格を決めておく。（ひし形に当てはまるような大きさにする）
その後、いったん仮で１つだけアイコンを作成し、それを使いまわす（プレースホルダー）
