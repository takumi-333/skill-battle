# 攻撃エフェクトの改修


## エフェクトの改修
今は、円弧の図形で通常攻撃のエフェクトを表現している。

しかし、そこをスプライト素材を用いて、エフェクトを表現したい。
表現したいのは３パターン

- 打鍵士：ハンマーで殴ったような演出
    今の円弧と同じ軌跡を上から下にもしくは、右から左に振り下ろすイメージ
- 算術士：インテグラルの印で目の前の敵を押すイメージ
    フェードインで、インテグラルの印を出現させ、あたかも魔法を繰り出した感じを出すイメージ
- 詠唱者：紫の魔法の光で切り下ろすイメージ
    今の円弧と同じ軌跡を上から下にもしくは、右から左に振り下ろすイメージ


## 当たり判定
今の円弧と同じ当たり判定でよいと思う
ただし、円弧は見えない。
そして各エフェクトもその円弧と同じような範囲を攻撃している感じにする（エフェクトと当たり判定が乖離しないように）
