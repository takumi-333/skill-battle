# 未実装のスキルは選べないようにする

## キャラクター画面において未実装のスキルは選択できないように

未実装のスキルはアイコン背景を暗くして、選択できないようにする。
手前には各キャラのロックアイコンを使用する

## 打鍵士のスキルの設定ミス
スキル１の候補に
鍵片追弾がたくさんあるが、１つだけにするべき。
スキル２も３つ目以降はすべて未実装のアイコン鍵にする。

## 算術士のスキルの設定ミス
スキル１の名前は標準ではない
スキル２もそう
スキル３は１つも実装していない

## 詠唱士のスキルの設定ミス
スキル１、２の名前は標準じゃない
スキル３は１つも実装していない

## 対戦画面における打鍵士の通常攻撃のアイコンミス
通常攻撃のアイコンはまだ作成していない。今設定されているのはぶん回しのもの
