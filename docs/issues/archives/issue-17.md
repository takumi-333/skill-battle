# キャラクター画面のスキル確認・セットウィンドウの表示

## 現行
スキルのアイコンを押すと、セットされる

## 修正後
スキルのアイコンを押すと、そのスキルの説明ウィンドウが開かれる。そのウィンドウの下部にそのスキルをセットするかどうかのボタンがある。

あとスキルアイコンを押したときは通常のクリック音ではなく、

## 画面イメージ
- 画面全体の9割くらいを覆うでかいウィンドウ
- スキル説明ウィンドウは一番手前に出現
- 後ろは暗くする
- スキルのウィンドウの枠は各キャラの専用フレーム
- 「閉じる」ボタンと「スキルをセット」ボタンがある
    - 両方ともキャラの専用ボタン
- 画面左上にでかでかとスキルのアイコンがあり
- 右側にスキルの説明
    - スキルの名前
    - スキルの詳細な説明
