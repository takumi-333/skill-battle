# オンライン対戦待機画面の修正

## バグの修正
- ルームに入室した側が準備完了できなくて、ゲームが始まらない。

## 修正箇所
- キャラ選択の右左ボタンの枠がないので追加
- 左右ボタンの間にキャラ名を書く。（相手のところには左右ボタンも、キャラ名もない、相手のキャラ名がわかってはいけない）
- 相手のキャラ絵が入る部分には影キャラクターの立ち絵を入れる。（人が入っているのは一目でわかるが、キャラがわからない）
    - 立ち絵は、shadow_idle
- 準備完了ボタンは下に一つでよい（自分ののみ、もちろん押してもその人の準備が完了するだけ）
- ルームを開いた人にのみ、ゲーム開始ボタンを右下に配置。（両者が準備完了していないと押せない）
