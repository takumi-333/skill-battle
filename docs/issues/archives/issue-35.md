# 音の追加

以下の効果音を、適切なアセット用ディレクトリに分かりやすい名前で配置し、指定のタイミングで再生する。

## damaged

- キャラクターがダメージを受けたときに再生する。
- 両プレイヤーに聞こえる音とする。

## game_hit_midheavy

- 打鍵士のスキル2「三叉震槌（さんさしんつい）」で、ハンマーが地面に着弾したときに再生する。
- 両プレイヤーに聞こえる音とする

## skill-miss

- 各キャラクターのウィンドウを赤くするタイミングで再生する。
- 対象はタイピングミス、回答ミス、詠唱士の発動ミス。

## writing-sound

- 詠唱士のスキルで、マウス操作により軌跡を描いている間に再生する。
- マウスに動きがない間（離してはいないが止まっている間）は再生を止める
- 本人だけに聞こえる音とする。
