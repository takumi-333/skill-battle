# オンラインの画面遷移の仕様修正

## リザルト画面に行く問題
ロビーで相手が抜けた際に、リザルト画面に行くが、試合が始まっていないのにリザルトに行くのはおかしい。
ロビーで相手が抜けた場合は、ただ、相手がいなくなっただけにする。（もちろんシルエットも消える）

## リザルト画面で再戦ボタンを押した際の挙動の修正
現行：
    リザルト画面で再戦ボタンをどちらかが押すと強制マッチング開始になる
    ロビーへボタンをどちらかが押すと強制ロビー画面になる
変更後：
    両者が再戦ボタンを押さないと、マッチングは開始しない
    どちらかがロビーへ画面を押すと、もう片方の再戦ボタンは押せなくなる（押しても意味ないので）
