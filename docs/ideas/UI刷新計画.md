# 各画面のUI刷新計画

## 1. 各画面のイメージ画像を作成する
まず世界観のイメージは、
@docs\ideas\design_image.pngと@docs\specs\世界観・アートディレクション.mdを参照する

@docs\ideas\ui_conceptsに各画面の改修後イメージ画像を格納した。

## 2. このゲームの世界観に合ったフォントを作成する

改修後イメージの画像から
このゲームで統一して使うフォントを作成
作成できないならば、フリー素材を取得してくる。

## 3. 各画面を作成した画像のように各画面を刷新するための計画を立てる

改修後のイメージの画像から
あらかじめ準備が必要があるUIパーツを洗い出し（ボタンなど）
各画面に必要な画像素材などを生成・取得しておく。

## 4. 実装する

集めたパーツ、フォントと改修後のイメージから
実装を改修して画面を作成する。
