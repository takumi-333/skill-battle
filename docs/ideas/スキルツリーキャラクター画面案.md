# スキルツリー付きキャラクター画面案

> アイデア段階。実装仕様ではなく、今後の仕様検討用の画面イメージとして保存する。

## コンセプト

キャラクター画面では、1ページに1キャラクターだけを表示する。
選択中のキャラクターが暮らしている部屋のような背景と、そのキャラクター固有の雰囲気を持たせる。

## 画面構成

- キャラクター画面の上部または左右に、キャラクター一覧を開くための切り替えUIを配置する。
- キャラクター数が増える前提のため、全員分のポートレートを常時タブとして並べない。
- 一覧画面、スクロール可能なリスト、カテゴリ分けなど、人数が増えても扱える選択方式を検討する。
- 選択中のキャラクターだけを大きく表示する。
- キャラクターを切り替えると、背景、スキルツリー、装備中スキル、ステータス表示が選択キャラクター用に切り替わる。

## スキルツリー

- キャラクターを使用することでスキルポイントが蓄積される。
- スキルポイントを消費して、スキルやステータス強化を獲得する。
- スキルツリーには、アクティブスキル、パッシブスキル、ステータス強化、派生スキルなどを含める。
- 未解放、解放可能、解放済みの状態を視認しやすくする。
- ツリーの形状やノード表現はキャラクターごとに変え、個性を出す。

## スキルセット

- スキルは合計3つまでセットできる。
- スキルツリーで獲得したスキルを、セット枠へ割り当てる。
- セット中のスキル、未セットの獲得済みスキル、未獲得スキルを区別して表示する。

## キャラクターごとの背景イメージ

- 打鍵士: キーボード部品、鎖、ハンマーのある工房。重い金属感とネオンピンク。
- 詠唱者: 月明かりの観測室兼書庫。巻物、星座、魔法陣。紫と金を中心にする。
- 算術士: CRT、数式、グラフ用紙、ケーブルのある研究室。青、シアン、金を中心にする。
- 新キャラクター追加時も、そのキャラクターの「部屋」として背景を設計する。
