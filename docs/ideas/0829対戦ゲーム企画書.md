# スキル対戦ゲーム：企画アイデア書

## 1. コンセプト

プレイヤーごとの「得意な操作」を武器にして戦う、ドット調2D対戦アクションゲーム。
タイピング、エイム、リズム、計算などのミニゲーム的な操作を成功させることで、キャラクター固有の技を発動する。単なる操作の速さだけではなく、相手との距離、技の選択、入力を始めるタイミングといった対戦の読み合いで勝敗が決まる。

**ひとことで表すと**: 「自分の得意スキルで戦える、短時間の対戦アクションゲーム」。

## 2. 目指す体験

- 格闘ゲームに慣れていない人でも、「タイピングなら得意」のような入口から対戦に参加できる。
- 自分の得意な操作を選んだキャラクターで勝てたときに、強い自己表現と達成感を得られる。
- 相手の得意操作を見て、妨害・大技の狙いどころを考える読み合いを楽しめる。
- 1試合を短くし、負けてもすぐに再挑戦したくなるテンポを作る。

## 3. 想定ターゲット

### 第一ターゲット

- タイピングゲーム、音楽ゲーム、パズル、エイム練習ゲームを好む中高生〜若い大人。
- 対戦ゲームに興味はあるが、複雑なコマンド入力や多数の定石を覚えることには抵抗がある人。

### このゲームが提供する価値

- 対戦アクションが得意でなくても、別の得意分野を勝ち筋にできる。
- 同じ対戦でも、キャラクターごとに異なる「上達したいスキル」が見つかる。
- 観戦者にも「いま難しい入力で大技を狙っている」と状況が伝わりやすい。

## 4. 参入容易性の方針

最初の試合を、説明を読み込まずに始められるようにする。

- 1試合は60〜90秒を基本とする。
- 初期キャラクターは、必要な力を一言で説明する。
  - 打鍵士: 速く正確にタイプする力が必要だぞ
  - 算術士: 計算問題を素早く解く力が必要だぞ
  - 詠唱者: 印を素早く正確になぞる力が必要だぞ
- 初回は、固有技を2つ程度に絞る。
- 対戦前に5〜10秒の操作体験を用意する。
- リザルトでは勝敗に加えて、入力速度・正確性・命中率などの改善点を簡潔に表示する。

## 5. 対戦の基本ルール案

### 基本形式

- 基本モードは1対1。
- 主な対戦の場はオンライン対戦とする。気軽に遊ぶカジュアルマッチと、実力を競うランクマッチを想定する。
- 1つのマップに両者が配置され、開始と同時に移動・攻撃できる。
- 相手のHPを先に0にしたプレイヤーが勝利する。
- 将来的には多対多の対戦も検討するが、まずは1対1の面白さを成立させる。

### 共通操作と固有操作

すべてのキャラクターで、移動・通常攻撃・防御などの基本行動は共通にする。技の発動にだけキャラクター固有の操作を使う。

これにより、キャラクターごとの差別化を保ちつつ、対戦アクションとしての共通した読み合いを成立させる。

### 集中状態と課題中断

固有操作の課題を始めると、キャラクターは集中状態になる。集中状態はエフェクトで両者に明示し、移動速度を大きく下げる。通常攻撃はできない。

集中状態には課題中断用のゲージを設け、一定量のダメージを受けると課題が中断される。ゲージは両者に表示し、攻撃側が中断を狙えるか、集中側が課題を完遂できそうかを判断できるようにする。

### 技選択の駆け引き

- 短く簡単な入力: 威力は低いが、安全かつ素早く出せる。
- 長く難しい入力: 高威力または強い効果を持つが、入力中に隙ができる。
- 入力の失敗: 技が不発になる、隙が生まれる、ゲージを消費するなどのリスクを持たせる。

この「安全な小技」と「危険な大技」の選択を、ゲームの中心的な読み合いとする。

## 6. キャラクター案

| キャラクター | 必要なプレイヤースキル | 対戦上の個性 |
| --- | --- | --- |
| 打鍵士（タイピスト） | タイピングの速度・正確性 | 高火力・長射程。入力中の隙が大きい。 |
| 詠唱者（スペリスト） | 図形をなぞる速度・正確性 | 範囲攻撃や設置技で行動を制限する。 |
| 算術士 | 計算問題を解く速さ | 状況に応じた強化・妨害を選択する。 |
| 連打者 | 連打速度 | 近距離での継続火力に優れる。 |
| エンジニア | 簡易的なコード・ロジック構築 | 自動攻撃や罠を準備して戦う。 |
| リズマー | リズム感・タイミング | 安定した連続攻撃や防御・支援を行う。 |
| 狙撃者（エイマー） | クリックの速度・正確性 | 遠距離牽制と精密な大ダメージを狙う。 |

## 7. キャラクター育成とビルド

各キャラクターには個別のレベルを設ける。プレイヤーは、使いたいキャラクターを繰り返し遊ぶことでそのキャラクターのレベルを上げ、新しいスキルやスキルポイントを獲得する。

### 育成で得られる体験

- 「打鍵士を使い続けて強くなる」のように、キャラクターへの愛着と継続して遊ぶ目標を作る。
- スキルポイントの割り振りにより、同じキャラクターでも自分の得意操作や戦い方に合ったビルドを試せる。
- 例: 打鍵士なら、短い単語を使う連射型、長文の大技に特化する一撃型、入力失敗のリスクを抑える安定型。

### スキルリセットの方針

スキルポイントは、いつでも無償でリセット・再配分できるようにする。

- 間違った割り振りが、育成を始めたばかりのプレイヤーの不安や離脱につながらないようにする。
- 相手や気分に応じてビルドを変え、新しい戦い方を試す楽しさを作る。
- 育成は「一度選んだ能力を固定する仕組み」ではなく、「戦い方の選択肢を増やす仕組み」と位置付ける。

### オンライン対戦との両立

レベル差がそのまま勝敗を決めないよう、オンライン対戦では育成による強さの扱いを慎重に設計する。

- ランクマッチでは、全スキルを使用可能にする、または能力値を一定に補正する方式を検討する。
- カジュアルマッチでは、育成済みのビルドをそのまま試せるようにする。
- 育成の報酬は単純な基礎能力の上昇より、技・効果・立ち回りの選択肢を増やす形を優先する。

## 8. 最初の試作案

最初から全キャラクターを実装せず、対戦の核を検証する3キャラクターから始める。

1. **打鍵士**: 入力中のリスクと、高火力技を狙う魅力を検証する。
2. **算術士**: 問題を解く速さと、技の選択による戦術性を検証する。
3. **詠唱者**: 図形入力の正確さと、範囲攻撃・設置技の駆け引きを検証する。

エンジニアは魅力が大きい一方で、ルール設計と実装の負荷が高い。対戦の基礎が固まった後に、目玉キャラクターとして追加する。

## 9. 独自性

本企画の独自性は、ミニゲームを技のトリガーとして使うだけではない。プレイヤーの得意操作が、対戦中のリスクと報酬を伴う戦術の選択になる点にある。

例として、打鍵士が長い文章を入力して大技を狙っている間、相手は中断ゲージを削り切るために攻めるか、攻撃範囲から逃げるかを選ぶ。打鍵士側も、短い入力で小技を連発するか、中断される前に大技を通すかを選ぶ。

このように、**得意操作 × キャラクター性能 × 対戦の読み合い**を組み合わせることが、一般的なミニゲーム集や対戦アクションとの差別化になる。
