# スキル演出用スプライト画像の作成

基本はプロンプトを考え、画像はこちらで作成する。
すべてドット絵ではある


## 全員
集中状態のときに、周りから力を集めている演出を出すために
小さなパーティクルスプライトを各キャラ用に用意し、それを用いて演出する


## 打鍵士
スキル1用に、キャラクターのハンマーについているようなキーボードのキーキャップのスプライトを用意する。
それを放ち、立体的なキーキャップが飛んでいくようにする。キーキャップの上面は無地にし、入力したアルファベットはゲーム側で後から重ねて表示する。動きの軌跡や弾の発光は付けない。

## 詠唱士
スキル１用に地面に出現させる魔方陣を作成する
スキル１用に魔方陣上にビームのように伸ばしそこからダメージが発生したことを演出したい。それ用のビームスプライト

スキル２用に
魔法の玉。小さ目の玉にする予定それをたくさん飛ばす。

## 制作方針・共通条件

以下は現行仕様をもとにした制作候補であり、実装時には必要なものから採用する。複数フレームの画像アニメーションは原則作らず、移動、回転、拡大縮小、明滅、透明度変化はゲーム側で制御する。

- すべてゲーム画面用のドット絵。90年代ゲームのポップさと、深夜の地下ストリート風ダークファンタジーを組み合わせる。
- 背景、床、キャラクター本体、影、UI、説明文は含めない。透過PNGの孤立したスプライトにする。
- 暗い画面上で読めるよう、輪郭と発光部分のコントラストを高くする。ただし画面全体を白く塗るような過剰な発光は避ける。
- 素材は原則として1フレームの単体画像にする。エフェクトは `effect`、弾は `projectile` profileを想定する。
- 文字・数式・細かい記号は画像に焼き込まず、ゲーム側で重ねる。キーキャップ弾も上面は無地にし、入力したアルファベットをGodot側で上面へ表示する。
- 生成後に、余白のトリミング、二値alpha、ドットのにじみ・半透明の除去、色数の整理を行う。

## サイズの仮基準

移動キャラクターの基準が1フレーム64×64pxであるため、スキル演出もゲーム内表示で扱いやすいよう、以下のサイズを初期値とする。すべて1フレームの単体画像とし、sprite sheetにする場合も1列×1行とする。これはアイデア段階の仮基準であり、実際の表示倍率に合わせて後で調整する。

| 素材 | 生成する画像サイズ | ゲーム内の基準表示サイズ |
| --- | ---: | ---: |
| 集中パーティクル | 8×8px | 16×16px（2倍表示） |
| キーキャップ弾 | 24×24px | 24×24px |
| 直進衝撃波 | 64×32px | 128×64px（2倍表示） |
| 周囲波動 | 80×80px | 160×160px（2倍表示） |
| 魔法陣 | 80×80px | 160×160px（2倍表示） |
| ビーム | 32×360px | 64×720px（2倍表示、画面上端まで届く長さ） |
| 星辰弾 | 16×16px | 24×24px（1.5倍表示） |
| 命中フラッシュ | 80×80px | 160×160px（2倍表示） |
| デコイ残光 | 32×32px | 64×64px（2倍表示） |
| 収束マーカー | 32×32px | 64×64px（2倍表示） |

プロンプト中のサイズは「生成する画像サイズ」を指す。ゲーム側で拡大表示する素材は、必ずnearest-neighborで整数倍率に拡大し、ぼかしやアンチエイリアスを発生させない。生成サービスが正確なピクセル寸法を保証しない場合は、生成後にnearest-neighborで切り出し・縮小してから採用する。

## 全員：集中状態のパーティクル

キャラクターの周囲から力を集めていることが伝わる、小さな「ほぼ丸」のドットを用意する。凝った形や記号は使わず、各キャラクターのテーマカラーに合わせた色違いを数種類用意する。画像の生成はAIではなく、円・楕円・数ピクセルの欠けを組み合わせた簡単な機械生成で行う。

### 機械生成するバリエーション

- 小さい点：直径2〜3px程度。数を多く表示する基本粒子。
- 普通の点：直径4〜6px程度。集中演出の主な粒子。
- 大きい点：直径7〜10px程度。少数だけ混ぜるアクセント粒子。
- 形は完全な円ではなく、1〜2pxだけ欠けた円や少し縦長・横長の楕円を混ぜる。
- 各バリエーションは1フレームの単体画像とし、移動・拡大縮小・明滅・消滅はゲーム側で制御する。

### 色の指定

- 打鍵士：深緑、緑、金。金は少量だけ使う。
- 詠唱者：深紫、紫、淡い桃色、金。桃色と金はアクセントにする。
- 算術士：深い紺、青白、金。青白を主な発光色にする。

### 機械生成用メモ

```text
入力：幅16px、高さ16px、透明背景
形状：中心を少しずらした円または楕円、必要に応じて1〜2px欠けさせる
サイズ：直径2〜3px、4〜6px、7〜10pxの3種類
出力：nearest-neighbor、二値alpha、アンチエイリアスなし、各画像1フレーム
```

集中パーティクルはAI生成プロンプトの対象外とする。必要な画像は、色とサイズの組み合わせを機械的に増やせばよい。

## 打鍵士

### スキル1「鍵片追弾」：キーボードキーキャップ弾

正解した文字1つにつき1個生成される弾。立体的な四角いキーキャップの無地の上面に、入力したアルファベットをゲーム側で重ね、その形のまま移動する。動いている感を出す軌跡、残光、火花、押下・発射・消滅のアニメーションは作らない。斜め方向にも使えるよう、上面が見える斜め上からの視点で作り、移動方向への回転と文字表示はゲーム側で行う。

## 生成後の確認項目

- 透過背景になっているか。背景色が残っている画像は採用しない。
- 暗いゲーム画面へ置いたとき、1秒以内に「弾」「設置範囲」「命中」「集中粒子」の区別がつくか。
- キャラクター設定のテーマカラーから外れていないか。打鍵士は緑・金、詠唱者は紫・桃・金、算術士は紺・青白・金を基本とする。
- 発光の中心、弾の進行方向、魔法陣の中心など、ゲーム側で配置する基準点が明確か。
- キーキャップ弾の上面が見え、文字を載せられる平面が確保されているか。
- キーキャップ弾に軌跡、残光、速度線、余計な火花が入っていないか。
- キーキャップ弾の上面が無地で、Godot側の文字を重ねられる十分な平面が確保されているか。
