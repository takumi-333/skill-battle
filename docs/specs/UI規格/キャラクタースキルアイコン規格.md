# キャラクタースキルアイコン規格

## 目的と適用範囲

本規格は、キャラクターのスキルに使用するアイコン素材と、対戦中のスキルHUDにおける表示方法を定める。

キャラクター固有の色、モチーフ、シルエットは[キャラクター設定](../キャラクター設定.md)および[世界観・アートディレクション](../世界観・アートディレクション.md)に従う。

## 対戦HUDの構成

今後の対戦中スキル表示は、次のレイヤーを重ねて構成する。

1. キャラクターのメインテーマカラーを基調とした背景
2. アクセントカラー単色のスキルロゴ／アイコン
3. アイコンの表示領域を切り抜く穴マスク
4. キー入力バッジとキー表示
5. ひし形フレーム

背景は各キャラクターのメインテーマカラーを基調とし、単色または緩やかなグラデーションで表現する。下方向へ行くほど少し暗くなるグラデーションは推奨表現とする。スキルの内容を表すロゴ／アイコンは背景透明の画像として別に制作し、その上へ重ねて表示する。アイコン素材自体にひし形の枠、キー番号、クールタイム表示を描き込まない。

## フレーム素材

フレームは、サイズごとにready画像とhole mask画像を用意する。

| 種類 | ready画像 | 穴マスク |
| --- | --- | --- |
| small | `assets/ui/skill_diamond_frames/skill_diamond_small_ready.png` | `skill_diamond_small_hole_mask.png` |
| medium | `assets/ui/skill_diamond_frames/skill_diamond_medium_ready.png` | `skill_diamond_medium_hole_mask.png` |
| large | `assets/ui/skill_diamond_frames/skill_diamond_large_ready.png` | `skill_diamond_large_hole_mask.png` |

ready画像はひし形フレームとして最前面に表示する。穴マスクはアイコンの表示範囲を定義するためのもので、アイコン素材へ直接合成しない。

## アイコン素材の規格

- 背景レイヤーは各キャラクターのメインテーマカラーを基調とする。単色、またはメインテーマカラーから大きく外れない緩やかなグラデーションを使用する。
- 背景は上部より下部を少し暗くする表現を推奨する。これによりロゴの視認性とひし形フレームの輪郭を保つ。
- 背景への模様、風景、強い質感、強い影、過度な発光は使用しない。
- ロゴ／アイコンレイヤーは背景透明のPNG（RGBA）とする。
- ロゴ／アイコンは、small、medium、largeの各ウィジェット規格サイズに合わせた正方形素材として制作する。
- ロゴ／アイコンの色は、対象キャラクターのアクセントカラー1色のみとする。多色化、グラデーション、半透明の色分けは行わない。
- ロゴ／アイコンの主題は中央に配置し、ひし形の表示領域内で判別できる大きさにする。
- ロゴ／アイコンの重要な形状を四隅や外周へ広げない。smallサイズの穴マスクで切り抜かれても主題が欠けない構図にする。
- ロゴ／アイコンレイヤーに、背景、ひし形フレーム、キー番号、文字、クールタイム表現を含めない。
- 背景レイヤーとロゴ／アイコンレイヤーは分離して管理し、色を変更するためにロゴ画像を再制作しなくてよい構造にする。
- 現在の仮素材は `assets/ui/skill_icons/skill_placeholder_square.png` である。二層構成への移行までは仮素材を使用する。

個別スキルのアイコンを追加する場合は、キャラクターのメインテーマカラーを背景へ設定し、アクセントカラー単色のロゴ／アイコン画像を差し替える構造を維持する。

## 色の対応

色は[キャラクター設定](../キャラクター設定.md)に定めるテーマカラーを使用する。

| キャラクター | メインテーマカラー（背景） | アクセントカラー（ロゴ／アイコン） |
| --- | --- | --- |
| 打鍵士 | 深い緑 `#121F18` | 金 `#DAB06C` |
| 算術士 | 深い紺 `#1C213F` | 金 `#E6B072` |
| 詠唱者 | 深い紫 `#3F255D` | 金 `#F3B772` |

## ロゴ／アイコンの表現例

「人が走っている姿」を表す場合は、次のように制作する。

- 背景：対象キャラクターのメインテーマカラーを基調とし、下方向へ少し暗くなる正方形のグラデーション
- 前景：走っている人のシルエット／ロゴ
- 前景色：対象キャラクターのアクセントカラー1色
- 前景の背景：透明
- 表現：細部を描き込みすぎず、走っている姿だけで意味が伝わる単純なシルエット

この例では、写真風の人物、背景風景、複数色の衣装、文字や速度線を追加しない。必要な動きは、走る姿勢や体の傾きなどロゴの形状で表現する。
