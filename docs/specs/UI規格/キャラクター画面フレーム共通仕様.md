# キャラクター画面フレーム共通仕様

## 目的

キャラクター画面で使用するウィンドウ枠を、キャラクターが増えても同じデザイン体系で制作できるように定める。打鍵士用の枠を基準デザインとし、各キャラクターでは色と小さなモチーフだけを差し替える。

## 共通デザイン

- 細く、画面の情報を邪魔しないウィンドウ枠とする。
- 外周は単純な矩形を基本とし、軽いベベルと細い内側ラインだけで立体感を出す。
- 装飾は四隅の小さなアクセント、または短い区切り線に限定する。
- 大きな飾り、厚いフレーム、複雑な彫刻、過度な発光、宝石、鎖などは原則として使用しない。
- 中央のコンテンツ領域は完全に空け、文字・数値・アイコン・キャラクター画像を素材へ焼き込まない。
- 横方向・縦方向に伸縮して使用できる構造とし、9-sliceまたはタイル配置を前提にする。
- 角や端の装飾が中央領域へ張り出さないようにする。
- 小さい表示サイズでも枠の輪郭と選択状態が読めるよう、線幅と明暗差を優先する。

## 色と質感

- 作品共通の暗色をベースにし、金属または硬質素材の落ち着いた質感で統一する。
- 基本色は `世界観・アートディレクション.md` の共通パレットに合わせる。
- キャラクターごとの差分は、主にアクセントカラー1色と補助色1色で表現する。
- アクセントカラーは枠全体を塗りつぶさず、内側ライン、角の小片、選択時の強調に限定する。
- ネオンや発光は弱く抑え、背景やキャラクターより目立たせない。
- 文字の可読性を損なうノイズ、傷、粒子、強い影は枠の内側へ重ねない。

## キャラクター別の差し替え範囲

各キャラクターで変更してよいのは次の範囲に限る。

1. 主アクセントカラー
2. 補助色
3. 素材感（金属、塗装、石、革など）
4. 四隅または区切り線に入れる小さなモチーフ

枠の細さ、矩形構造、余白、装飾量、透明背景、ピクセル表現は全キャラクターで維持する。モチーフはキャラクターを連想できる程度に留め、枠の用途が変わるほど大きくしない。

## AI画像生成用の共通プロンプト

以下を基本文として使用し、`[ ]` の部分だけキャラクターごとに置き換える。生成時は現在のキャラクター画面または既存ウィンドウ画像を参照画像として渡す。

```text
Use the attached current character-screen window frame as the primary visual reference. Create a matching reusable window frame for the character [CHARACTER NAME].

Keep the same restrained thin-border design: a simple rectangular frame, narrow consistent border width, subtle bevel, one understated inner line, and very small corner or divider accents. Preserve the reference frame's proportions, pixel-art language, lighting direction, material quality, and overall visual identity. Reduce decoration rather than adding ornamentation. Do not use large corner pieces, bulky protrusions, complex engravings, gems, chains, excessive particles, or strong glow.

Adapt only the character-specific visual identity: primary accent color [PRIMARY COLOR], secondary color [SECONDARY COLOR], material [MATERIAL], and a small restrained motif [SMALL MOTIF]. The motif must remain subtle and must not extend far into the content area.

Design it as a practical UI window border for a character screen. Keep the center completely empty and transparent outside the frame. Make the border suitable for horizontal and vertical stretching, 9-slice or tile-based use, with clean corners and consistent thickness. It must remain readable at small resolution and must not compete with text, icons, or character artwork.

Pixel art, crisp hard edges, limited palette, dark fantasy arcade RPG style, 1990s game UI, isolated transparent asset, no anti-aliasing, no blur, no large external shadow, no letters, no words, no numbers, no symbols, no character, no background, no floor, no complete UI screen.
```

## 制作時の確認項目

- 既存のキャラクター画面と並べたとき、枠の太さと装飾量が揃っている。
- 枠の内側へ文字や画像を配置しても、読みやすさを損なわない。
- 横長・縦長・小型のウィンドウへ伸縮しても、角の形状が崩れない。
- キャラクター固有の色やモチーフを除けば、他キャラクターの枠と同じシリーズに見える。
- 透過背景で、文字・数値・UI状態を画像へ含めていない。
