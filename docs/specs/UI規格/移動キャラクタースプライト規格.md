# 移動キャラクタースプライト規格

## 目的と適用範囲

本規格は、フィールド上で移動するキャラクターの `idle` / `walk` 用sprite sheetの固定レイアウト、再生順、描画制約を定める。キャラクター固有の外見は[キャラクター設定](../キャラクター設定.md)に従い、全体の画風・配色は[世界観・アートディレクション](../世界観・アートディレクション.md)に従う。

汎用のasset spec / animation specのデータ契約は[スプライト制作仕様](../スプライト制作仕様.md)を正とする。

## sheet規格

| 項目 | 規格 |
| --- | --- |
| 画像形式 | 透過PNG、RGBA |
| sheetサイズ | `512 × 320 px` |
| レイアウト | 8列 × 5行のgrid。セル間の余白なし |
| 1フレーム | `64 × 64 px` |
| 総フレーム数 | 40フレーム（8方向 × 停止1フレーム + 歩行4フレーム） |
| 視点 | 斜め上見下ろしの3/4トップダウン。頭頂、肩、足元が見えること |
| 方向 | 左右反転は使わず、8方向を個別に描画すること |
| 禁止要素 | 背景、床、影、発光、罫線、文字、ラベル、透かし |

## grid配置

原点はsheet左上とし、`column` / `row` は0始まりで扱う。

| 行（`row`） | フェーズID | 内容 |
| --- | --- | --- |
| 0 | `idle` | 停止 |
| 1 | `walk_01` | 接地 |
| 2 | `walk_02` | 中間 |
| 3 | `walk_03` | 逆接地 |
| 4 | `walk_04` | 中間 |

| 列（`column`） | 方向ID | 向き |
| --- | --- | --- |
| 0 | `down` | 下 |
| 1 | `down_left` | 下左 |
| 2 | `left` | 左 |
| 3 | `up_left` | 上左 |
| 4 | `up` | 上 |
| 5 | `up_right` | 上右 |
| 6 | `right` | 右 |
| 7 | `down_right` | 下右 |

## 再生規則

- `idle` は各方向につき1フレームを表示する。
- `walk` は各方向で `walk_01 → walk_02 → walk_03 → walk_04` の順にループする。`walk_04` の次は `walk_01` とし、接地足、重心、足元の位置が連続して見えること。
- すべての方向で、髪、衣装、武器などのキャラクター識別要素と、足元を基準にした配置を一貫させる。
- 本ゲームの現行実装では、歩行は8 FPSで再生する。

## asset spec / animation specへの対応

この規格をv2仕様で記述する場合は、`profile: "character"`、`layout.type: "grid"`、`layout.cell_size: { "width": 64, "height": 64 }`、`layout.columns`、`layout.rows`に上記の方向IDとフェーズIDを順序どおり指定する。`idle` clipは8つの方向variantを持ち、`walk` clipは各variantに4フレームを上記の再生順で持つ。
