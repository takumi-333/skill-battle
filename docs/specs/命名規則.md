# 命名規則

## この資料について

本資料は、キャラクター「打鍵士」のスキル名を統一するための仕様である。スキル、スキル説明、演出名、関連するUI文言を作成・更新する際は、本資料に従う。

## 打鍵士の命名コンセプト

打鍵士の核となるモチーフは**欲望の採掘者**である。

- キー入力は、地中の鉱脈を掘り当て、資源を回収する行為として表現する。
- 大型ハンマーは、岩盤や鉱石を砕く採掘槌として扱う。
- 強欲は単なる金銭欲ではなく、時間・労力・成果を取りこぼさず回収する収集欲として表現する。
- 報酬、コイン、宝石、金属は、蓄積した価値や成果の視覚的な記号として使う。

スキル名は、**打鍵による作業感**、**採掘の力強さ**、**価値の回収**のうち、少なくとも二つを連想できるものとする。

## 使用する語彙

### 打鍵・操作

`打鍵`、`連打`、`鍵`、`キー`、`鍵盤`

### 採掘・破砕

`採掘`、`鉱脈`、`鉱山`、`鉱石`、`岩盤`、`砕き`、`爆砕`、`震槌`

### 蓄積・価値

`金`、`黄金`、`金脈`、`宝`、`鉱`、`利益`、`回収`、`貪欲`、`欲望`

語彙は、意味が重複しすぎないように組み合わせる。例として「黄金金脈」のような同義語の重ね方は避ける。

## 命名の構造

### 基本形

原則として、以下のいずれかの二語構成を用いる。

| 構造 | 用途 | 例 |
| --- | --- | --- |
| 価値・対象 + 打鍵 | 通常攻撃、素早い連続攻撃 | 金脈打鍵、黄金連打 |
| 欲望・対象 + 採掘 | 蓄積、強化、資源獲得 | 貪欲採掘 |
| 鍵・鉱物 + 破砕語 | 範囲攻撃、打撃攻撃 | 鍵山砕き、欲鉱爆砕 |
| 価値・欲望 + 回収語 | 蓄積物を消費する攻撃、フィニッシュ | 黄金回収、欲望清算 |

### 漢字表記

- 基本は二字から四字程度の漢語を使い、短く強く読める名前にする。
- 読みが難しい語を使う場合も、スキル一覧で意味を推測できる程度に留める。
- `キー`のような外来語は、キーボード要素を即座に伝える必要がある場合だけ使う。基本は`鍵`または`打鍵`を優先する。
- ハンマーそのものを示すときは、通常は`槌`を用いる。大技や強い衝撃を示す名称には`震槌`を用いてよい。

## スキル種別ごとの指針

| 種別 | 名称の方向性 | 例 |
| --- | --- | --- |
| 通常攻撃 | 打鍵・連打を含め、軽快で反復的にする | 金脈打鍵、黄金連打 |
| 小技 | 採掘・破砕・回収のうち一つを主題にする | 貪欲採掘、鍵山砕き |
| 大技 | 鉱脈、黄金、爆砕、震槌などを使い、蓄積した価値を一撃で解放する印象にする | 欲鉱爆砕、黄金震槌 |
| 強化・蓄積効果 | 回収量や執着が増す印象にする | 金脈発見、貪欲蓄積 |
| 状態異常・弱体効果 | 相手を岩盤・鉱滓・採掘対象として扱う | 岩盤拘束、鉱滓まみれ |

## 基準となる名称

以下を、打鍵士の命名トーンを判断する基準とする。

- 金脈打鍵
- 貪欲採掘
- 鍵山砕き
- 黄金連打
- 欲鉱爆砕

## 避ける表現

- タイピング、強欲、ハンマーのいずれとも結び付かない、抽象的な固有名詞だけの名称。
- 硬派な採掘・作業者の印象から外れる、魔法少女風・舞台芸術風の表現。
- 金銭だけを直接奪う印象が強く、打鍵士の「成果を回収する」強欲を矮小化する表現。
- 英単語や長いカタカナ語を連結した、読み取りに時間がかかる名称。

## 命名時の確認項目

- 名前だけで、打鍵・採掘・価値回収のうち二つ以上を想起できるか。
- スキルの効果・威力・役割が、語尾の印象と一致しているか。
- 既存の基準名と並べたとき、語調・漢字量・世界観に違和感がないか。
- UI上で読みやすく、短時間で意味を把握できるか。
