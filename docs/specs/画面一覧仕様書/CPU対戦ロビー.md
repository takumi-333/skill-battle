# CPU対戦ロビー

## 役割

- ホーム画面から開き、自分とCPUのキャラクター、CPUレベルを選んで対戦を始める画面
- 対戦中の動作は[CPU対戦](../対戦モード仕様書/CPU対戦.md)を参照する

## 画面構成

- 画面中央の枠内に、タイトル「CPU対戦」を表示する
- 枠内を左右に分け、左側に自分、右側にCPUのキャラクター選択欄を配置する。各欄ではキャラクター名の下に立ち絵を表示する。
- 自分とCPUのキャラクター選択ボタンを、それぞれの立ち絵の下に配置する。CPUレベル選択はCPU側の下部に配置する。
- 枠内の下部中央に対戦開始ボタン、画面左上にホームへ戻るボタンを配置する。

## UI要素と挙動

| 要素 | 表示・挙動 |
| --- | --- |
| 自分のキャラクター欄 | 見出しは「あなた」。選択中のキャラクター名と立ち絵を表示する。初期選択は打鍵士。 |
| 自分のキャラクター切り替えボタン | 「◀」「▶」を表示する。押すと自分のキャラクターを打鍵士・算術士・詠唱者の順で切り替え、名前と立ち絵を更新する。末端からは反対側へ循環する。 |
| CPUのキャラクター欄 | 見出しは「CPU」。選択中のキャラクター名と立ち絵を表示する。初期選択は算術士。 |
| CPUのキャラクター切り替えボタン | 「◀」「▶」を表示する。押すとCPUのキャラクターを打鍵士・算術士・詠唱者の順で切り替え、名前と立ち絵を更新する。末端からは反対側へ循環する。自分と同じキャラクターも選べる。 |
| CPUレベル表示 | 選択中のレベルを「CPU レベルX」と表示する。選べる値は1・2・3で、初期値は1。1が最も弱く、3が最も強い。 |
| CPUレベル切り替えボタン | 左の「◀」でレベルを1下げ、右の「▶」で1上げる。レベル1では左ボタンと背景枠、レベル3では右ボタンと背景枠を表示しない。レベル2では両方表示する。 |
| 対戦開始ボタン | 「対戦を開始」と表示する。押すと、選択した自分のキャラクターとCPUのキャラクター・レベルで対戦を開始する。 |
| ホームへ戻るボタン | 「ホームへ戻る」と表示する。押すとホーム画面へ戻る。 |
