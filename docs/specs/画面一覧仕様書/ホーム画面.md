# ホーム画面

## 役割

タイトル画面から進み、ゲームの各機能を選ぶ画面。

## 表示する入口

| 項目 | 遷移先・操作 |
| --- | --- |
| オンライン対戦 | オンライン対戦画面を開く |
| 練習 | 練習画面を開く |
| キャラクター | キャラクター画面を開く |
| ユーザー設定 | ユーザー設定を開く |
| チュートリアル | 準備中（選択不可） |
| CPU対戦 | [CPU対戦ロビー](CPU対戦ロビー.md)を開く |

デバッグ画面の入口は廃止する。

## 現行実装

ユーザー設定はホーム上に重なるウィンドウとして表示される。ユーザー名、Lobby HTTPS URL、招待アクセストークンを編集できる。オンライン対戦では、遷移先の画面で2人用・3人用ルームを選ぶ。
