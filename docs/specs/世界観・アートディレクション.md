# 世界観・アートディレクション

## 目的と適用範囲

本書は、本作におけるキャラクター、背景、UI、エフェクト、アイコンの共通ビジュアル方針を定める仕様である。個別キャラクターの設定は [キャラクター設定](キャラクター設定.md) を正とし、本書と矛盾する場合は、個別設定を優先する。

## コアコンセプト

**「90年代ゲームのポップさ × 深夜の少し退廃した地下世界」**

夜の地下ストリート、ゴシック、ストリート、ピクセル、控えめなネオンを組み合わせたダークファンタジーとする。目標は、かわいい・かっこいい・少し不穏が同居するダークポップであり、陰鬱さや恐怖だけに寄り過ぎないことを重視する。

## 共通ルール

- 画面と衣装は暗色を基調にし、重要な情報とキャラクターの識別点だけを鮮やかにする。
- ネオンは画面全体を塗る色ではなく、輪郭、選択状態、魔法、看板、金具などの強調に限る。
- ゴシックとストリートの要素は、チェーン、金具、ルーン、ステッカー、ベルト、ブーツ、擦れた質感などで表現する。
- 血、恐怖、過度な損壊ではなく、壊れかけたネオン、ノイズ、錆、傷、暗い路地で危うさを表現する。
- 文字、数字、ゲーム情報は常に読みやすさを優先し、質感やノイズを重ねすぎない。

## キャラクター・アニメーション

- 立ち絵とゲーム用ドット絵では、髪型、武器、衣装の大きな輪郭、テーマカラー、キャラクターシンボルを共通化する。
- 8方向スプライトは、武器・髪・帽子・ローブなどの識別点を全方向で維持し、左右反転に依存しない。
- 現行のゲーム用**移動キャラクター**スプライトは、背景、床、影、発光、文字、孤立した粒子を含めない。攻撃・集中・飛び道具・エフェクトは、[汎用スプライト制作ガイド](../guides/スプライト素材作成ガイドライン/README.md)で目的別のasset spec・animation spec・profileを先に定義する。演出上必要な発光や分離粒子は、effect / projectile profileで許容する。
- アニメーションは滑らかさを重視する。現行の移動シートは停止1行と歩行4フレーム行で構成し、歩行ループのつながりを明確にする。
