# CPU対戦

## 目的

他のプレイヤーとの接続なしで、人間に近い相手との対戦を楽しめるようにする。

## 対戦条件

- CPUの相手キャラクターとして、打鍵士・算術士・詠唱者の全員を選べる。
- CPUのレベルは1・2・3から選べる。1は弱く、3は強い。
- 選択画面については[CPU対戦ロビー](../画面一覧仕様書/CPU対戦ロビー.md)を参照する。

## CPUの行動原則

- CPUは移動し、相手との距離や向きを考慮して通常攻撃とスキルを使う。
- スキルには人間のプレイヤーと同様に発動までの時間がかかる。CPUだけが課題を即時に完了して発動することはない。
- 課題には失敗と得点の差を設ける。レベルが高いほど強い相手になる。

## 現行実装

CPUの課題は、解答時間・成功率・得点を持つモデルで表現している。CPUが問題文を実際にタイピング・計算・なぞり入力する処理ではない。

## 未確定事項

レベル別の具体的な反応時間、課題成績、戦術の目標値は、プレイ感を見て決める。
