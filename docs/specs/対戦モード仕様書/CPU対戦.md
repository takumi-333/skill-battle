# CPU対戦

## 目的

他のプレイヤーとの接続なしで、人間に近い相手との対戦を楽しめるようにする。

## 対戦条件

- CPUの相手キャラクターとして、打鍵士・算術士・詠唱者の全員を選べる。
- CPUのレベルは1・2・3から選べる。1は「弱い」、2は「標準」、3は「強い」。
- 選択画面については[CPU対戦ロビー](../画面一覧仕様書/CPU対戦ロビー.md)を参照する。

## CPUの行動原則

- CPUは移動し、相手との距離や向きを考慮して通常攻撃とスキルを使う。
- スキルには人間のプレイヤーと同様に発動までの時間がかかる。CPUだけが課題を即時に完了して発動することはない。
- 課題には失敗と得点の差を設ける。レベルが高いほど強い相手になる。

## レベル別の仕様

| 項目 | レベル1（弱い） | レベル2（標準） | レベル3（強い） |
| --- | ---: | ---: | ---: |
| 行動判断の間隔 | 0.9～1.1秒 | 0.55～0.75秒 | 0.3～0.5秒 |
| 攻撃・スキルを試みる間隔 | 3.2～4.2秒 | 2.3～3.3秒 | 1.6～2.6秒 |
| 相手との目標距離 | 125 px | 170 px | 200 px |
| 相手を向く方向のずれ | ±0.9ラジアン | ±0.6ラジアン | ±0.3ラジアン |
| 判断時に移動をやめる確率 | 32% | 0% | 0% |
| スキル課題にかかる時間 | 4.9～5.5秒 | 3.1～3.7秒 | 1.7～2.3秒 |
| スキル課題の成功率 | 55% | 78% | 94% |
| 成功時の得点 | 32～60点 | 55～79点 | 72～94点 |
| 強制計算課題にかかる時間 | 5.0秒 | 3.5秒 | 2.3秒 |
| 強制計算課題の成功率 | 40% | 70% | 90% |

- 試合開始直後は、全レベル共通で最初の行動判断まで0.8秒、最初の攻撃・スキルの試行まで2.0秒待つ。その後は表の間隔を使う。
- CPUは相手との距離が目標距離より遠ければ近づき、95 pxより遠く目標距離以内なら横移動し、95 px以内なら離れる。移動方向と向きは行動判断のたびに更新する。
- 攻撃・スキルの試行時、相手との距離が180 px未満なら65%の確率で通常攻撃を試みる。それ以外はスキル1～3からランダムに1つ選び、クールダウン中でなく課題中でもなければ課題を開始する。選んだスキルを使えず、距離が180 px未満なら通常攻撃を試みる。
- スキル課題中は移動を止める。表の時間が経過した後に成功判定を行い、成功した場合のみ表の範囲から得点を決めてスキルを発動する。失敗した場合も選んだスキルのクールダウンは発生する。
- 強制計算課題は、相手の「方程式支配」を受けた場合の処理を指す。表の時間が経過した後に成功判定を行い、失敗すると5秒間の行動制限を受ける。

## 課題の表現方法

CPUの課題は、解答時間・成功率・得点を持つモデルで表現する。CPUが問題文を実際にタイピング・計算・なぞり入力する処理ではない。表の時間・確率・得点は現行実装の設定値であり、プレイ感に応じて調整する場合はこの仕様書も更新する。

## 未確定事項

レベル間の強さのバランスは、プレイテストで確認する。
