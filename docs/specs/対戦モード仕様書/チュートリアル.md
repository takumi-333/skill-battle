# チュートリアル

## 目的

初めて遊ぶ人が、相手との対戦を一通り体験して基本操作を理解できるようにする。

## 必ず伝える内容

- 移動と通常攻撃の使い方。
- スキルは1・2・3・4キー、またはHUDのアイコンをクリックして発動できること。1は通常攻撃、2～4はスキル1～3に対応する。
- スキルの課題に取り組み、得点を得て発動すること。
- 得点が高いほど、発動したスキルの効果が強くなること。
- 対戦の勝敗とリザルトまでの流れ。

開始前の画面については[チュートリアル画面](../画面一覧仕様書/チュートリアル画面.md)を参照する。
