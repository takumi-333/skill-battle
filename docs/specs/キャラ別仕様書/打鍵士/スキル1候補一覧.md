# スキル1候補一覧

ここには打鍵士のスキル１に登録することができるスキル一覧である。

## 1. 鍵片追弾（けんぺんついだん）

### 概要
キーボードキーキャップ弾を相手に飛ばして攻撃する

### アイコンイメージ

キーボードキャップが1つ飛んでいくイメージ

### 課題

- 制限時間: 6秒
- ワード候補: `Track`、`Chase`、`Trace`、`Trail`、`Stalk`

### 効果

- クールタイム：2秒
- 正解入力した文字を、1文字につき1個のキーボードチップとして生成する。
- チップは0.5秒間隔で発射される。入力したスペースもチップとして扱う。
- 各チップは発射時点の打鍵士の位置から出現する。
- スコア79点以下では、発射時点での相手位置との方向を一度だけ計算し、発射後は追尾しない。
- ダメージ: `5 + floor(スコア × 0.1)`
- 弾速: 550
- 存続時間: 2秒
- 貫通: なし。相手に命中すると消滅する。

### 特殊効果

- スコア80点以上で、ゆるやかなホーミング機能を有効化する。
- 発射時の方向は通常どおり相手へ向ける。
- 発射後0.7秒間だけ、毎フレーム相手方向へ少しずつ回転する。
- ホーミング中の最大旋回速度は毎秒35度とする。
- 発射時の方向からの最大補正角度は35度とする。
- ホーミング時間終了後は、その時点の方向へ直進する。
- 相手へ瞬時に方向転換したり、相手の位置へワープしたりはしない。
