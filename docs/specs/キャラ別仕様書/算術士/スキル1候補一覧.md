# スキル1候補一覧

ここには算術士のスキル1に登録することができるスキル一覧である。

## 1. 無限級数（インフィニティ・フラクタル）

### 概要

高度な計算魔術により、自身の分身をたくさん発生させる

### アイコンイメージ

自分が真ん中にいて、その両サイドに２体の薄い人間がいある感じ

### 課題

- 制限時間: 7秒
- 問題候補:
  - `12 + 3 * 8`
  - `15 + 4 * 9`
  - `18 + 5 * 14`
  - `21 + 6 * 7`
  - `16 + 7 * 8`
  - `24 + 3 * 12`
  - `17 + 4 * 11`
  - `25 + 5 * 9`
  - `14 + 6 * 10`
  - `19 + 3 * 13`
  - `23 + 4 * 12`
  - `11 + 7 * 9`
  - `26 + 3 * 14`
  - `20 + 5 * 13`
  - `27 + 4 * 15`

### 効果

- クールダウン: 2秒
- デコイ数:
  - スコア 59以下：10体 + MAX(スコア - 50, 0)
  - スコア 60代：20 + スコア - 60
  - スコア 70代：30 + スコア - 70
  - スコア 80代：45 + スコア - 80
  - スコア 90以上： 70 + スコア - 90
- 効果時間: スコアに応じて20〜30秒
  - スコア 59以下：20秒
  - スコア 60 ~ 79: 30秒
  - スコア 80以上：40秒
- デコイは算術士を中心に半径20〜700pxの範囲からランダム配置し、点在させる。配置はマップ内に収める。
  - スコア 59以下：半径10 ~ 500px
  - スコア 60 ~ 79: 半径20 ~ 700px
  - スコア 80~: 半径20 ~ 1000px
- 各デコイは個体ごとに5 ~ 10秒間隔でランダムに少しノイズが入る。
- デコイは算術士と同じキャラクタースプライト・向きで描画する。
- デコイごとに発動時、算術士の向きに対する8方向のランダムなずれを割り当てる。その方向のずれを維持したまま、発動プレイヤーの移動キー入力に従って移動し、プレイヤーが向きを変えた場合はデコイの向きにも反映する。
- デコイが移動している間は、その向きに対応した歩行アニメーションを表示する。停止中は待機アニメーションを表示する。
- 発動者の画面ではデコイの見た目は薄く、相手の画面では通常と全く同じ見た目をしている
  - 相手は惑わされるが自分は惑わされない
- 効果中は移動速度1.1倍、通常攻撃力1.5倍。
- 再発動時は、すでに出ているデコイはすべて消える
- 発動時に自分及び半径 1000px以内にいる相手の画面が一瞬青く光る（テーマカラーの色）
