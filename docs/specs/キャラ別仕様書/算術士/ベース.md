# 算術士

## 基本設定

| 項目 | 設定値 |
| --- | --- |
| キャラクターID | `arithmetic` |
| 表示名 | 算術士 |
| 課題形式 | 算術問題 |
| 通常攻撃ダメージ | 10 |

## キャラクター説明

算術問題を解く能力で戦うファイター。

## 課題ウィンドウ

- 位置: `(55, 410)`
- サイズ: `300 × 290px`
- 表示内容: スキル名、問題、入力フォーム、残り時間
- 図形キャンバスは表示しない。
- 課題中はゲーム側の入力処理がキー入力を受け取り、入力フォームへ明示的なフォーカス操作をしなくても入力できる。
- 次の15問からスキルごとに1問をランダム出題する。

`22 + 4 * 16` / `4 + 8 * 9 + 12` / `16 + 17 + 18 + 19` / `164 + 255` / `18 + 5 * 14` / `7 + 6 * 8 + 15` / `21 + 22 + 23 + 24` / `176 + 248` / `32 + 7 * 11` / `9 + 5 * 12 + 18` / `14 + 16 + 18 + 20` / `187 + 326` / `25 + 6 * 13` / `8 + 9 * 7 + 14` / `15 + 17 + 19 + 21`

- 掛け算を先に計算し、その後に足し算を計算する。
- 解答は入力欄の内容で判定する。
- 解答ミスは即時失敗にせず、残り時間を1.8秒減らし、入力欄を空にする。ウィンドウは約0.22秒赤くなり、横に振動する。
- 時間切れ、中止、割り込みゲージ消失時は失敗する。失敗時はスキル効果を発生させず、クールタイムを適用する。

## 集中

- スキル1/2の中断ゲージ: 30 / 50
- 集中中の移動速度: 通常の35%
