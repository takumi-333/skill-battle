# スキル1候補一覧

ここには詠唱者のスキル1に登録することができるスキル一覧である。

## 1. 円環の降臨

### 課題

- 目標紋章: 円
- 円周上の任意の位置から一筆書きを開始できる。
- 開始位置・終了位置は指定しない。
- 円周の距離スコアとカバー率で判定する。
- 合格スコア: 45点以上

### 効果タイムライン

- クールダウン: 2秒

各エリアは生成時点の相手位置を取得し、その後は追従しない。各エリアのダメージ判定は1回とする。

| 経過時間 | 挙動 |
| ---: | --- |
| 0.0秒 | 相手の現在位置にエリア1を生成 |
| 0.0〜0.3秒 | エリア1の予告状態 |
| 0.3秒 | エリア1のダメージ判定。強く発光 |
| 0.3〜2.0秒 | エリア1を発光・明滅表示 |
| 1.5秒 | 相手の現在位置にエリア2を生成 |
| 1.5〜1.8秒 | エリア2の予告状態 |
| 1.8秒 | エリア2のダメージ判定。強く発光 |
| 1.8〜3.5秒 | エリア2を発光・明滅表示 |
| 3.0秒 | 相手の現在位置にエリア3を生成 |
| 3.0〜3.3秒 | エリア3の予告状態 |
| 3.3秒 | エリア3のダメージ判定。強く発光 |
| 3.3〜5.5秒 | エリア3を発光・明滅表示 |
| 5.5秒 | エリア3が消滅し、スキル終了 |

- 効果範囲: 半径80px相当
- ダメージ: `8 + round(スコア × 0.06)`
- ダメージ発生時に一瞬強く光り、その後は明暗を小さく揺らして危険状態を表現する。
