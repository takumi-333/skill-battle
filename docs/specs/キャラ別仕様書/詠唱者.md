# 詠唱者

## 基本設定

| 項目 | 設定値 |
| --- | --- |
| キャラクターID | `chanter` |
| 表示名 | 詠唱者 |
| 課題形式 | 紋章なぞり |
| 通常攻撃ダメージ | 11 |

## 課題ウィンドウ・共通入力

- 位置 `(250, 185)`、サイズ `780 × 400px`。打鍵者・算術士と異なり図形キャンバスを表示する。
- 発動までの制限時間は設けない。
- 前回の軌跡は課題開始時・終了時に消去する。
- マウスボタンを押している間だけ軌跡を記録し、ボタンを離した時点で一度だけ判定する。
- 始点・終点への到達では自動判定しない。目標紋章との距離・カバー率からスコアを算出する。
- 乖離が大きく合格スコアに届かない場合は効果を発生させず、失敗クールダウンを適用する。

## スキル1：円環の降臨

### 課題

- 目標紋章: 円
- 円周上の任意の位置から一筆書きを開始できる。
- 開始位置・終了位置は指定しない。
- 円周の距離スコアとカバー率で判定する。
- 合格スコア: 45点以上

### 効果タイムライン

各エリアは生成時点の相手位置を取得し、その後は追従しない。各エリアのダメージ判定は1回とする。

| 経過時間 | 挙動 |
| ---: | --- |
| 0.0秒 | 相手の現在位置にエリア1を生成 |
| 0.0〜0.3秒 | エリア1の予告状態 |
| 0.3秒 | エリア1のダメージ判定。強く発光 |
| 0.3〜2.0秒 | エリア1を発光・明滅表示 |
| 1.5秒 | 相手の現在位置にエリア2を生成 |
| 1.5〜1.8秒 | エリア2の予告状態 |
| 1.8秒 | エリア2のダメージ判定。強く発光 |
| 1.8〜3.5秒 | エリア2を発光・明滅表示 |
| 3.0秒 | 相手の現在位置にエリア3を生成 |
| 3.0〜3.3秒 | エリア3の予告状態 |
| 3.3秒 | エリア3のダメージ判定。強く発光 |
| 3.3〜5.5秒 | エリア3を発光・明滅表示 |
| 5.5秒 | エリア3が消滅し、スキル終了 |

- 効果範囲: 半径80px相当
- ダメージ: `8 + round(スコア × 0.06)`
- ダメージ発生時に一瞬強く光り、その後は明暗を小さく揺らして危険状態を表現する。

## スキル2：星辰弾幕

- 目標紋章: 星
- 制限時間なし。マウスボタンを離した時点で判定する。
- 自分を中心に16方向へ1発ずつ順番に射撃する。
- 16方向の射撃を3周繰り返す。
- 各弾は発射後に方向を変更しない。

## 集中・クールダウン

- スキル1/2の中断ゲージ: 30 / 50
- 集中中の移動速度: 通常の35%
- クールダウン: スキル1=2秒、スキル2=4秒
