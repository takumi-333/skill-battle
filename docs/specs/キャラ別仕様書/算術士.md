# 算術士

## 基本設定

| 項目 | 設定値 |
| --- | --- |
| キャラクターID | `arithmetic` |
| 表示名 | 算術士 |
| 課題形式 | 算術問題 |
| 通常攻撃ダメージ | 10 |

## 課題ウィンドウ・共通入力

- 位置 `(55, 410)`、サイズ `300 × 290px`。画面左下に配置する。
- 表示はスキル名、問題、入力フォーム、残り時間のみ。図形キャンバスは表示しない。
- 課題中は明示的なフォーカス操作なしでキー入力を入力フォームへ送る。
- 次の15問からスキルごとに1問をランダム出題する。

`22 + 4 * 16` / `4 + 8 * 9 + 12` / `16 + 17 + 18 + 19` / `164 + 255` / `18 + 5 * 14` / `7 + 6 * 8 + 15` / `21 + 22 + 23 + 24` / `176 + 248` / `32 + 7 * 11` / `9 + 5 * 12 + 18` / `14 + 16 + 18 + 20` / `187 + 326` / `25 + 6 * 13` / `8 + 9 * 7 + 14` / `15 + 17 + 19 + 21`

- 掛け算を先に計算し、その後に足し算を計算する。
- 解答ミスは即時失敗にせず、残り時間を1.8秒減らし、入力欄を空にする。ウィンドウは約0.22秒赤くなり、横に振動する。
- 時間切れ、中止、割り込みゲージ消失時は効果を発生させず、失敗クールダウンを適用する。

## スキル1：無限級数（インフィニティ・フラクタル）

- 制限時間: 7秒
- デコイ数: 30体
- 効果時間: スコアに応じて20〜30秒
- デコイは算術士を中心に半径60〜620pxの範囲からランダム配置し、算術士の近くとマップ全体に点在させる。配置はアリーナ内に収める。
- 各デコイは個体ごとに2〜3秒間隔でランダムに揺れ動く。
- デコイは算術士と同じキャラクタースプライト・向きで描画する。
- 発動者の画面では薄く、相手の画面では通常に近い濃さで表示する。
- 効果中は移動速度1.25倍、通常攻撃力+8。

## スキル2：最適解への収束

- 制限時間: 10秒
- 効果時間: スコアに応じて10〜20秒
- 効果中は移動速度1.25倍、通常攻撃力+10。
- 発動者の画面では薄く表示し、相手側では基本的に非表示にする。
- 透明化中は2.5秒ごとに約0.2秒だけ相手にも見える。
- 攻撃中は透明化せず、相手側にも表示する。

## 集中・クールダウン

- スキル1/2の中断ゲージ: 30 / 50
- 集中中の移動速度: 通常の35%
- クールダウン: スキル1=2秒、スキル2=4秒
