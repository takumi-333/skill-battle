# キャラ別スキル仕様書

## このディレクトリの役割

各キャラクターのスキルすべての仕様を管理する
ここを常に正本として参照する

## 仕様書の構成

- ベース.md
    各キャラクターのスキルのベースとなる部分の仕様書。スキルウィンドウの大きさや、スキルのスコア計算などについて記載されている
- スキル命名規則.md
    各キャラクターのスキルの命名規則について記載する。何をモチーフにしているかなどスキル名の一貫性を保つための仕様書。
- スキル1候補一覧.md
    そのキャラクターのスキル1にセットできるスキルすべてについて定義する
- スキル2候補一覧.md
    そのキャラクターのスキル2にセットできるスキルすべてについて定義する
- スキル3候補一覧.md
    そのキャラクターのスキル3にセットできるスキルすべてについて定義する
