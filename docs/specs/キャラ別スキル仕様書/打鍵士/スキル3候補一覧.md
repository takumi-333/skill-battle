# スキル3候補一覧

ここには打鍵士のスキル3に登録することができるスキル一覧である。

## スキル3: 黄金大旋槌（おうごんだいせんつい）

### 概要

ハンマーを思い切り周囲にぶん回し、相手を吹き飛ばす

### 説明文

クールタイム：3秒
制限時間：20秒

スキル説明
長いワードを打ち切ると、ハンマーを振り回しながら移動できる。高得点ほど持続時間とハンマーが大きくなり、60点以上では鍵片も射出する。

### アイコンイメージ

ハンマーがくるくる回っているイメージ

- `assets/ui/skill_icons/typist_hammer_spin.png`

### 演出

自身の周りにハンマーをくるくる回す（素材は `assets/effects/normal_attack_typist_weapon.png` ）
ハンマーの柄尻をキャラクターの中心に合わせ、キャラクターを起点としてハンマー全体を時計回りに回す。周囲の円だけを表示する演出は行わない。
自分のアニメーションもスプライト（各方向の基準となるスプライト）を高速に切り替えて時計回りに回っている感じを演出
その間は移動アニメーションはなくてよい（移動はできる）

### 課題

- 制限時間: 20秒
- ワード候補:
  - `Spin the Hammer, Scatter All`
  - `Hammer Spin Sends Foes Flying`
  - `Circle the Hammer, Crush All`
  - `Spin Hard, Launch Every Enemy`
  - `Clockwise Spin, Foes Scatter`
  - `Heavy Hammer Whirlwind Attack`
  - `Endless Spin Blows Foes Away`
  - `Hammer Spin Clears the Field`

### 効果

- クールタイム：3秒
- ハンマーを時計周りにぐるぐる回しながら移動することで相手に攻撃する（ハンマーが当たり判定）
- ハンマーの柄から先端まで全体に当たり判定を持たせる
- ハンマーはキャラクターを起点にぐるぐる回る。発動中はキャラクター自身も回転する
- ハンマーの大きさが、スコアによって変わる
- 持続時間：スコア30点で3秒、50点で6秒、70点で9秒、90点で13秒。中間スコアは線形補間し、30点未満は3秒、90点超は13秒とする
- ダメージ: `10 + floor(スコア × 0.2)`
- 移動速度：
    - スコア30点以下: 0.8倍
    - スコア40点以下: 0.9倍
    - スコア60点以下: 1.0倍
    - スコア80点以下: 1.05倍
    - スコア80点以上: 1.1倍

### 特殊効果

- スコア60点以上で、定期的にハンマーの先からキーボードキャップが飛んでいく。
- キーボードキャップのダメージは10ダメージ固定
    - 弾速：800
    - 存続時間：3秒
    - 貫通なし

## 2. 黄金時間III（おうごんじかん）

### 概要

ゾーン状態を付与する自己強化技。

### 説明文

クールタイム：70秒
制限時間：8秒

スキル説明
短いワードを打ち切ると、スコアに応じた時間だけタイピングゾーンモードIIIへ入る。黄金時間IIの追尾鍵片に加え、力強い打鍵音が周囲を傷つける波動になる。

### アイコンイメージ

アイコン中央に、やや上から見たキーボードを大きく配置する。キーボードの外形と全キーの輪郭を金色（`#DAB06C`）で3段階中もっとも強く発光させ、キーボードの周囲に外向きの円形波動を2本配置する。波動は、正しい打鍵ごとに発生するダメージ波動を表す。黄金時間IIと同様に右上へ曲がる細い弧を1本添える。IIIが最も強い発光であることを示しつつ、キーボード本体と波動の形状は判別できるようにする。背景、文字、ひし形フレーム、キー番号は含めない。
- `assets/ui/skill_icons/typist_typing_zone_iii.png`

### 演出

効果中は、打鍵士の周囲に薄い緑の残光を常時表示する。課題中に正しい文字を打つたび、対応する文字を表示したキーキャップを金色の残光とともに射出し、足元から薄い円形波動を広げる。

### 課題

- 制限時間：8秒
- ワード候補：
  - `Master the Typing Zone`
  - `Control the Golden Zone`
  - `Own the Entire Zone`
  - `Keep the Zone Alive`
  - `Rule the Typing Zone`
- 課題を成功するとモードを開始する。

### 効果

- このスキル自体に相手にダメージを与える効果はない。
- 成功時からX秒間タイピングゾーンモードIIIに入る。
  - スコアが30以下：X = 50
  - スコアが70以下：X = 60
  - スコアが71以上：X = 90

#### タイピングゾーンモードIII

- モード中は通常攻撃を使用できない。移動と各スキルの使用は通常どおり行える。
- モード中の間のみ、タイピングを課題とするスキルの入力中だけ、正しく入力した各文字をキーキャップとして1個ずつ発射する。スペースも1文字として扱う。
- キーキャップは文字を入力した時点の相手位置へ向けて発射し、弾速550、存続時間2秒、貫通なし、ダメージ3とする。
- 射出後2秒間、キーキャップは相手方向へ毎秒35度まで旋回する。発射方向からの補正角度は最大35度とし、相手の位置へ瞬時に曲がったりワープしたりはしない。
- モード中に成功したタイピング課題は、スコア計算に使う残り時間を実際の残り時間の1.25倍として扱う。計算に使う残り時間は、その課題の制限時間を超えない。成功条件は変えない。
- モード中に発動するタイピング課題の制限時間は1.25倍となる。
- タイプミス時のペナルティは0.9秒とする。
- 正しい文字を入力するたび、打鍵士を中心にダメージ波動を発生させる。スペースも1文字として扱う。
- 波動は打鍵士を中心に毎秒200pxの一定速度で外側へ広がり、1秒後に半径200pxへ到達して消滅する。ダメージは1、ノックバックなしとする。
- 正しい文字を入力するたび、入力した本人と相手の画面でタイピング音を通常音量の1.3倍で再生する。
- 同時に有効にできるタイピングゾーンモードは1つだけとする。後から発動した同系統のモードは、効果を重ねずに残り時間を更新する。
