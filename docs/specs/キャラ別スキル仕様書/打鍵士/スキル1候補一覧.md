# スキル1候補一覧

ここには打鍵士のスキル１に登録することができるスキル一覧である。

## 1. 鍵片追弾（けんぺんついだん）

### 概要
キーボードキーキャップ弾を相手に飛ばして攻撃する

### 説明文

クールタイム：2秒
制限時間：6秒

スキル説明
入力した文字数だけ鍵片を作り、相手へ順に射出する。高得点なら発射直後の鍵片がゆるく相手を追尾する、素早い入力向けの基本技。

### アイコンイメージ

キーボードキャップが1つ飛んでいくイメージ

- `assets/ui/skill_icons/typist_keycap.png`


### 演出

キーボードキャップが飛んでいく

### 課題

- 制限時間: 6秒
- ワード候補: `Track`、`Chase`、`Trace`、`Trail`、`Stalk`

### 効果

- クールタイム：2秒
- 正解入力した文字を、1文字につき1個のキーボードチップとして生成する。
- チップは0.5秒間隔で発射される。入力したスペースもチップとして扱う。
- 各チップは発射時点の打鍵士の位置から出現する。
- スコア79点以下では、発射時点での相手位置との方向を一度だけ計算し、発射後は追尾しない。
- ダメージ: `5 + floor(スコア × 0.1)`
- 弾速: 550
- 存続時間: 2秒
- 貫通: なし。相手に命中すると消滅する。

### 特殊効果

- スコア80点以上で、ゆるやかなホーミング機能を有効化する。
- 発射時の方向は通常どおり相手へ向ける。
- 発射後0.7秒間だけ、毎フレーム相手方向へ少しずつ回転する。
- ホーミング中の最大旋回速度は毎秒35度とする。
- 発射時の方向からの最大補正角度は35度とする。
- ホーミング時間終了後は、その時点の方向へ直進する。
- 相手へ瞬時に方向転換したり、相手の位置へワープしたりはしない。

## 2. 黄金時間（おうごんじかん）

### 概要

ゾーン状態を付与する自己強化技。

### 説明文

クールタイム：50秒
制限時間：3秒

スキル説明
短いワードを打ち切ると、45秒間タイピングゾーンモードへ入る。課題中に正しく打った文字が鍵片となって相手を狙い、スコアも得やすくなる。代わりに通常攻撃は使えない。

### アイコンイメージ

アイコン中央に、やや上から見たキーボードを大きく配置する。キーボードの外形とキーの輪郭だけを金色（`#DAB06C`）で弱く発光させる。発光はキーボード外へほとんど広げず、通常の黄金時間であることが判別できる控えめな光量にする。背景、文字、ひし形フレーム、キー番号は含めない。

- `assets/ui/skill_icons/typist_typing_zone.png`

### 演出

効果中は、打鍵士の周囲に薄い緑の残光を常時表示する。

課題中に正しい文字を打つたび、対応する文字を表示したキーキャップを打鍵士の位置から射出する。

### 課題

- 制限時間：3秒
- ワード候補：`Zone Mode`、`In the zone`、`Typing Mode`、`Typing Time`、`Focus type`
- 課題を成功するとモードを開始する。

### 効果

- このスキル自体に相手にダメージを与える効果はない。
- 成功時からX秒間タイピングゾーンモードに入る。
    - スコアが30以下: X = 30
    - スコアが70以下: X = 45
    - スコアが71以上: X = 60


#### タイピングゾーンモードI

- モード中は通常攻撃を使用できない。移動と各スキルの使用は通常どおり行える。
- モード中の間のみ、タイピングを課題とするスキルの入力中だけ、正しく入力した各文字をキーキャップとして1個ずつ発射する。スペースも1文字として扱う。
- キーキャップは文字を入力した時点の相手位置へ向けて直進する。弾速550、存続時間2秒、貫通なし、ダメージ3とする。
- モード中に成功したタイピング課題は、スコア計算に使う残り時間を実際の残り時間の1.25倍として扱う。計算に使う残り時間は、その課題の制限時間を超えない。成功条件、制限時間は変えない。
- タイプミス時のペナルティが、0.9秒になる
- 同時に有効にできるタイピングゾーンモードは1つだけとする。後から発動した同系統のモードは、効果を重ねずに残り時間を更新する。
