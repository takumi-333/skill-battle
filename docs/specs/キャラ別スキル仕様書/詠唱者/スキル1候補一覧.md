# スキル1候補一覧

ここには詠唱士のスキル1に登録することができるスキル一覧である。

## 1. 月柱（げっちゅう）・昇華

### 概要

### アイコンイメージ

相手の足元に現れ、光の柱を呼び出す月の魔方陣。

### 課題

- 目標紋章: 円
- 合格スコア: 45点以上

### 効果タイムライン

- クールダウン: 2秒
- 各エリアは生成時点の相手位置を取得し、その後は追従しない。
- 効果範囲は魔方陣内（半径80px相当）だけとする。光柱の幅は表示演出であり、魔方陣外へ判定を広げない。
- ローカル対戦・オンライン対戦とも、足元アンカーから12px上の横20px・縦30pxのキャラクター楕円と、半径80pxの魔方陣が重なる場合に命中とする。
- ダメージは光柱が現れる時点から0.5秒間隔で発生する。1回のダメージは `8 + round(スコア × 0.06)`。

| 経過時間 | 挙動 |
| ---: | --- |
| 0.0秒 | 相手の現在位置にエリア1を生成し、`chanter_area.png` の魔方陣を暗い状態から表示する。 |
| 0.0〜0.5秒 | エリア1の魔方陣を徐々に明るくする予告状態。 |
| 0.5秒から2フレーム間 | エリア1の `chanter_beam.png` を魔方陣直径の1/3の太さ・画面上部までの高さの1/3で表示し、継続ダメージを開始する。 |
| 続く2フレーム間 | エリア1の光柱を太さ・高さとも2/3まで伸ばす。 |
| その後〜2.0秒 | エリア1の光柱を、見えている部分が魔方陣と同じ直径になる太さ・画面上部まで伸ばす。この最大太さを終了直前まで維持し、最後の0.28秒だけ高さを維持したまま太さを細く薄くして消す。魔方陣は完全表示の明るさを保ち、光柱とともに消える。 |
| 1.5秒 | 相手の現在位置にエリア2を生成する。以後、エリア1と同じ0.5秒の予告、2フレームずつの伸長、継続ダメージを行う。 |
| 3.0秒 | 相手の現在位置にエリア3を生成する。以後、エリア1と同じ演出・継続ダメージを行う。 |
| 5.5秒 | エリア3が消滅し、スキル終了。 |

### 失敗フィードバック

- なぞりのスコアが合格点（45点）未満の場合は、既存の打鍵士・算術士の入力ミスと同様に課題ウィンドウを赤くし、横方向へ揺らしてから失敗を確定する。

### 描画順

- 魔方陣は地面効果としてキャラクターより背面に描画する。
- 光柱はキャラクターより前面に描画する。光柱の範囲内にいるキャラクターは黒いシルエットとして光柱の前面に描き直す。
