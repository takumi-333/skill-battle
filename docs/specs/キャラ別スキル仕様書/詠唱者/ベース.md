# 詠唱者

## 基本設定

| 項目 | 設定値 |
| --- | --- |
| キャラクターID | `chanter` |
| 表示名 | 詠唱者 |
| 課題形式 | 紋章なぞり |
| 通常攻撃ダメージ | 11 |

## キャラクター説明

紋章を正確になぞる能力で戦うファイター
呪文の詠唱で弾幕を張ることに特化している

## 課題ウィンドウ

- 位置: `(250, 185)`
- サイズ: `780 × 400px`
- 表示内容: スキル名、目標紋章、図形キャンバス
- 打鍵士・算術士と異なり、図形キャンバスを表示する。
- 全スキル共通で、発動までの制限時間は設けない。
- 前回の軌跡は課題開始時・終了時に消去する。
- マウスボタンを押している間だけ軌跡を記録し、ボタンを離した時点で一度だけ判定する。
- 開始位置・終了位置は指定しない。
- 始点・終点への到達では自動判定しない。目標紋章との距離・カバー率からスコアを算出する。
- 乖離が大きく合格スコアに届かない場合は、課題ウィンドウを赤くして横方向へ揺らし、効果を発生させずに失敗クールダウンを適用する。

## 集中

- 集中中の移動速度: 通常の35%
- 集中中にダメージを受けても課題は継続する。
