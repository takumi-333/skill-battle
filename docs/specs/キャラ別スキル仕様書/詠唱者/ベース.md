# 詠唱者

## 基本設定

| 項目 | 設定値 |
| --- | --- |
| キャラクターID | `chanter` |
| 表示名 | 詠唱者 |
| 課題形式 | 紋章なぞり |
| 通常攻撃ダメージ | 3 |
| 通常攻撃クールタイム | 3秒 |

## キャラクター説明

紋章を正確になぞる能力で戦うファイター
呪文の詠唱で弾幕を張ることに特化している

## 課題ウィンドウ

- 位置: `(250, 185)`
- サイズ: `780 × 400px`
- 表示内容: スキル名、目標紋章、図形キャンバス
- 打鍵士・算術士と異なり、図形キャンバスを表示する。
- 全スキル共通で、発動までの制限時間は設けない。
- 前回の軌跡は課題開始時・終了時に消去する。
- マウスボタンを押している間だけ軌跡を記録し、ボタンを離した時点で一度だけ判定する。
- 開始位置・終了位置は指定しない。
- 描画開始からの経過時間、記録点数、軌跡の総延長、隣接点間距離では足切りしない。入力軌跡は通信上限の512点以内に保ち、形状採点はサーバー側の共有 `TraceEvaluator` で行う。
- 始点・終点への到達では自動判定しない。目標紋章との距離・カバー率からスコアを算出する。
- 乖離が大きく合格スコアに届かない場合は、課題ウィンドウを赤くして横方向へ揺らし、効果を発生させずに失敗クールダウンを適用する。
- Dedicated対戦でも課題を行った本人に不合格結果を確実に通知し、赤表示・揺れ・ミス音を再生してから課題ウィンドウを閉じる。

## 音の再生

- 左マウスボタンを押下してキャンバス内を動かし、軌跡を描いている間だけ、描画している本人の画面で `assets/audio/writing_sound.wav` を通常再生する。再生中のマウス移動では再始動せず、音が最後まで再生された後の次のマウス移動で先頭から次の1回を再生する。マウスが90ms停止した時、ボタンを離した時、または課題が終了した時には再生途中でも直ちに停止する。
- なぞり結果が不合格で課題ウィンドウが赤くなり横に揺れる時は、なぞった本人の画面で `assets/audio/skill_miss.mp3` を再生する。

## 集中

- 集中中の移動速度: 通常の35%
- 集中中にダメージを受けても課題は継続する。
