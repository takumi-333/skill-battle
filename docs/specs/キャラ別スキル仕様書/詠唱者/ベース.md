# 詠唱者

## 基本設定

| 項目 | 設定値 |
| --- | --- |
| キャラクターID | `chanter` |
| 表示名 | 詠唱者 |
| 課題形式 | 紋章なぞり |
| 通常攻撃ダメージ | 11 |

## キャラクター説明

紋章を正確になぞる能力で戦うファイター。

## 課題ウィンドウ

- 位置: `(250, 185)`
- サイズ: `780 × 400px`
- 表示内容: スキル名、目標紋章、図形キャンバス
- 打鍵士・算術士と異なり、図形キャンバスを表示する。
- 発動までの制限時間は設けない。
- 前回の軌跡は課題開始時・終了時に消去する。
- マウスボタンを押している間だけ軌跡を記録し、ボタンを離した時点で一度だけ判定する。
- 始点・終点への到達では自動判定しない。目標紋章との距離・カバー率からスコアを算出する。
- 乖離が大きく合格スコアに届かない場合は効果を発生させず、失敗クールダウンを適用する。

## 集中

- スキル1/2の中断ゲージ: 30 / 50
- 集中中の移動速度: 通常の35%
