# スキル3候補一覧

ここには詠唱士のスキル3に登録することができるスキル一覧である。

## 1. 十六夜（いざよい）

### 概要

### 説明文

クールタイム：8秒

スキル説明
複雑な渦巻きの紋章をなぞると、四方から月光弾を連続射出する。高得点ほど周回数が増え、密度の高い全方位弾幕になる。

### アイコンイメージ

16方向に月光の弾が飛び出す様子。

- `assets\ui\skill_icons\chanter_evening_moon_stage_3.png`

### 課題

- 目標紋章: 中心から外側へ約3.5周する渦巻き

### 効果

- クールダウン: 8秒
- 弾の演出には `assets/ui/skill_effects/chanter_ball.png` を用いる。
- 発動者を中心に、真上と真下から同時に時計回りに16方向へ1発ずつ射撃する。さらに同時に左右から反時計回りに16方向へ1発ずつ射撃する。
- 1周は上記の時計回り列と反時計回り列を各1回含む。周回数はスコア30以下で1周、50以下で2周、75以下で3周、76以上で4周とする。
- 予約済みの弾は、発射時点の発動者の位置から射出する。発動者は射撃中に移動できる。
- 各弾は発射時に定まった方向を、その後変更しない。
- ダメージは1発につき `3 + floor(スコア × 0.05)`。
- 各弾は相手を貫通して飛び続けるが、同じ相手にダメージを与えられるのは1回だけとする。


## 2. 月蝕（げっしょく）:潮汐（ちょうせき）

### 概要

前方にブラックホールを発生させ、そこに相手を吸い寄せたところにレーザを放つ

### アイコンイメージ

杖からレーザーが出る感じ

### 演出

自分の前方の少し離れたところにブラックホールを発生させる
その間自分は動けない代わりに、前方すぐ目の前にレーザーをため始める
そしてたまり切ったらレーザを放つ

### 課題

- 目標紋章: 星
- 合格スコア: 45点以上

### 効果

- クールダウン: 10秒
- 発動時の発動者の位置と向きを固定する。スキル終了までの4.5秒間、発動者は移動・向き変更・通常攻撃・他スキルの使用をできない。
- ブラックホールの中心は、発動時の発動者の位置から固定した向きへ300px前方に配置する。
  - 配置先がステージ外となる場合、ブラックホールの中心をステージ内へ収める位置まで補正する。
  - この補正によって、ブラックホールが発動者のすぐ前方に配置される場合がある。
  - ブラックホールの中心が発動者の背後に回るような補正は行わない。
- ブラックホールは発動時からスキル終了時までの4.5秒間存在する。
- ブラックホールは、ステージ内のどこにいる相手も吸引対象とする。
- 相手を0.1秒ごとにブラックホール中心へ引き寄せる。1回の基礎吸引量は `A = 6 + floor(S × 0.16)px` とする。
  - 45点: A = 13px/0.1秒、60点: A = 15px、80点: A = 18px、100点: A = 22px。
  - ブラックホール中心からステージ四隅のうち最も遠い地点までの距離を `D`、相手の位置から中心までの距離を `d` とする。
  - 1回の実際の吸引量は `max(1, ceil(A × (1 - d / D)))px` とする。中心に近いほど強く、最遠地点でも1pxずつ吸引する。
  - 最大速度は100点時の220px/秒（22px/0.1秒）であり、プレイヤーの移動速度280px/秒を下回る。
  - 相手はブラックホールの中心まで引き寄せる。中心に到達済みの場合は移動しない。
  - 吸引後の位置はステージ内へ収める。
- 発動から2.0秒間、発動者のすぐ前方にレーザー核を出現させ、点から最大サイズまで拡大する。
- 発動から2.0秒後、固定した向きへ極大レーザーを2.5秒間放つ。
  - レーザーの始点は発動者の足元アンカーから固定した向きへ30px前方とする。
  - レーザーの終点は、ブラックホール中心ではなく、その方向のステージ境界と交差する地点とする。
  - レーザーの最大幅は300pxとする。始点では24pxから開始し、始点から100px離れた地点で最大幅に達する。
  - ブラックホールの中心は、レーザーの中心線上にある。
- レーザーの範囲と相手の当たり判定が重なる場合、発射開始時と以後0.5秒ごとにダメージを与える。
  - 命中時刻は発動から2.0秒、2.5秒、3.0秒の最大3回とする。レーザーの表示は4.5秒まで継続する。
  - 1回のダメージは `4 + floor(S × 0.13)`。
  - 45点: 9ダメージ（最大27）、60点: 11ダメージ（最大33）、80点: 14ダメージ（最大42）、100点: 17ダメージ（最大51）。
