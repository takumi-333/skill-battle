# スキル3候補一覧

ここには詠唱士のスキル3に登録することができるスキル一覧である。

## 1. 十六夜（いざよい）

### 概要

### アイコンイメージ

16方向に月光の弾が飛び出す様子。

- `assets\ui\skill_icons\chanter_evening_moon_stage_3.png`

### 課題

- 目標紋章: 中心から外側へ約3.5周する渦巻き

### 効果

- クールダウン: 8秒
- 弾の演出には `assets/ui/skill_effects/chanter_ball.png` を用いる。
- 発動者を中心に、真上と真下から同時に時計回りに16方向へ1発ずつ射撃する。さらに同時に左右から反時計回りに16方向へ1発ずつ射撃する。
- 1周は上記の時計回り列と反時計回り列を各1回含む。周回数はスコア30以下で1周、50以下で2周、75以下で3周、76以上で4周とする。
- 予約済みの弾は、発射時点の発動者の位置から射出する。発動者は射撃中に移動できる。
- 各弾は発射時に定まった方向を、その後変更しない。
- ダメージは1発につき `3 + floor(スコア × 0.05)`。


## 2. 月蝕:潮汐

### 概要

前方にブラックホールを発生させ、そこに相手を吸い寄せたところにレーザを放つ

### アイコンイメージ

杖からレーザーが出る感じ

### 演出

自分の前方の少し離れたところにブラックホールを発生させる
その間自分は動けない代わりに、前方すぐ目の前にレーザーをため始める
そしてたまり切ったらレーザを放つ

### 課題

- 目標紋章: 星
- 合格スコア: 45点以上

### 効果

- クールダウン: 4秒
- 自分を中心に16方向へ1発ずつ順番に射撃する。
- 16方向の射撃を3周繰り返す。
- 各弾は発射後に方向を変更しない。
