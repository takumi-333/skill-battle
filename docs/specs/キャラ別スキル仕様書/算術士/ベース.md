# 算術士

## 基本設定

| 項目 | 設定値 |
| --- | --- |
| キャラクターID | `arithmetic` |
| 表示名 | 算術士 |
| 課題形式 | 算術問題 |
| 通常攻撃ダメージ | 1 |
| 通常攻撃クールタイム | 5秒 |

## キャラクター説明

計算能力で戦うファイター
敵を妨害する能力で、相手の妨害に成功するほど解析をすすめ、自身の力を向上させる

## 課題ウィンドウ

- 位置: `(55, 410)`
- サイズ: `300 × 290px`
- 表示内容: スキル名、問題、入力フォーム、残り時間
- 図形キャンバスは表示しない。
- 課題中はゲーム側の入力処理がキー入力を受け取り、入力フォームへ明示的なフォーカス操作をしなくても入力できる。
- 問題は各スキル仕様に記載した候補から、スキルごとに1問をランダム出題する。

- 掛け算を先に計算し、その後に足し算を計算する。
- 解答は入力欄の内容で判定する。
- 解答ミスは即時失敗にせず、残り時間を1.8秒減らし、入力欄を空にする。ウィンドウは約0.22秒赤くなり、横に振動する。
- 時間切れ、中止時は失敗する。失敗時はスキル効果を発生させず、クールタイムを適用する。集中中にダメージを受けても課題は継続する。

## スコア判定

算術問題のスコアは、正解完了時点の残り時間だけから計算する。解答ミスによる1.8秒のペナルティも経過時間に加算され、残り時間に反映される。

```text
ratio = clamp(remaining_time / time_limit, 0, 1)
score = 100 * (ratio + 0.85 / (2 * PI) * sin(2 * PI * ratio))
score = clamp(round(score), 0, 100)
```

`remaining_time` は制限時間から課題経過時間を引いた値、`time_limit` はスキルごとの制限時間とする。スコアは四捨五入後に0〜100へ収める。

## 集中

- 集中中の移動速度: 通常の35%

## 固有のスキル仕様

算術士のスキルには各スキルに妨害ポイントが設定されている。そのポイントを集めて戦う

### ポイントの可視化
算術士を使っている場合
算術士側のプレイヤーのHPバーの下に常に
f(x) = axが表示される（aはその時のポイントを表す数字）
それが算術士の今の強化状態を表す

### ポイントについて
初期値はa = 1
f(x) = xとして表示される
aが1.1, 1.2,,,, 2などと増加していくと
f(x) = 1.5xのような表記になる

ポイントの増え方は各スキルに定義するが、
基本相手の妨害に成功したときに妨害ポイントを得る

### スキル詳細での表示

妨害ポイントの獲得条件はキャラクター説明欄には表示せず、各スキルの詳細説明に記載する。

- 「無限級数」: 相手の攻撃でデコイが消えるたび、妨害ポイントを0.1獲得する。
- 「最適解への収束」: 妨害ポイントを獲得しない。
- 「視覚妨害（ハックビジョン）」: ノイズ状態の相手が通常攻撃でプレイヤーへダメージを与えられなかった回数ごとに、発動者が妨害ポイントを0.5獲得する。デコイだけを破壊した場合も含み、プレイヤーへ直接命中した場合は獲得しない。

### ポイントによる強化
ポイントによって以下のようにステータスが変化する

- 通常攻撃のクールタイムが通常の1/aになる
- 通常攻撃の攻撃力がa倍される
- 移動速度が(a - 1) * 10 %早くなる
