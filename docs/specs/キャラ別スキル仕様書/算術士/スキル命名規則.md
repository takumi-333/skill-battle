# スキル命名規則

## 1. 基本方針

算術士のスキル名は、**数学を用いて世界を解析し、自ら導いた解を唯一の正解として扱う魔導学者**を表現する。

- 漢字名・英語読みの双方に数学用語を含める。
- 数学用語は飾りではなく、スキルの効果や見た目と意味を対応させる。
- 傲慢さは、他者を罵倒する言葉ではなく、「自分の計算と結論は絶対に正しい」という確信として表す。
- 無機質な専門用語だけで終わらせず、発動時に格の高さと支配的な印象が残る名称にする。

## 2. 表記形式

原則として、以下の形式を用いる。

```text
漢字名（英語読み）
```

- 漢字名は、数学用語を一つ以上含む二字から六字程度の漢語、または短い漢語句とする。
- 英語読みは、数学用語を一つ以上含む英語をカタカナ表記する。二語以上の場合は中黒 `・` で区切る。
- 英語読みは漢字名の逐語訳でなくてよい。ただし、両者とも同じ効果の側面を表すものとする。
- 助詞を含む長い説明文のような名称は避け、UI上で一目で読める長さに収める。

## 3. 使用する語彙

### 数学用語

漢字名には、以下のような数学用語を用いる。

`無限`、`級数`、`収束`、`極限`、`微分`、`積分`、`方程式`、`定理`、`証明`、`変数`、`定数`、`行列`、`座標`、`確率`、`零点`、`虚数`、`最適解`

英語読みには、以下のような数学用語を用いる。

`Infinity`、`Series`、`Convergence`、`Limit`、`Derivative`、`Integral`、`Equation`、`Theorem`、`Proof`、`Variable`、`Constant`、`Matrix`、`Vector`、`Function`、`Optimum`、`Zero`、`Imaginary`

### 知性への自負を示す語彙

数学用語と組み合わせる語として、以下を用いる。

`絶対`、`至高`、`唯一`、`完全`、`必然`、`究極`、`確定`、`支配`、`真理`、`解明`

これらは、効果の強さや性質を誇張するためではなく、算術士が自分の導いた答えを疑わない人物であることを示すために使う。

## 4. 命名の構造

| 構造 | 用途 | 例 |
| --- | --- | --- |
| 数学概念 + 絶対性 | 必中、固定、確定、強化 | 絶対極限（アブソリュート・リミット） |
| 数学概念 + 支配・操作 | 妨害、拘束、誘導、弱体化 | 収束支配（コンバージェンス・ドミニオン） |
| 数学概念 + 現象 | 分身、透明化、空間・視覚効果 | 虚数領域（イマジナリー・フィールド） |
| 解・証明 + 数学概念 | 高難度技、決着技、自己強化 | 唯一解証明（ユニーク・プルーフ） |

例は名称の構造を示すためのものであり、スキル候補として確定するものではない。

## 5. スキル効果との対応

- 分身・増殖・反復する効果には、`級数`、`無限`、`行列`、`Series`、`Infinity`、`Matrix` などを用いる。
- 透明化・離脱・位置のずれには、`虚数`、`座標`、`極限`、`Imaginary`、`Vector`、`Limit` などを用いる。
- 相手を誘導・拘束・弱体化する効果には、`収束`、`零点`、`方程式`、`Convergence`、`Zero`、`Equation` などを用いる。
- 攻撃・決着・自己強化には、`最適解`、`定理`、`証明`、`積分`、`Optimum`、`Theorem`、`Proof`、`Integral` などを用いる。

## 6. 避ける表現

- 数学との結び付きがない、一般的な魔法名・ハッキング用語だけの名称。
- 効果と関係のない数学用語を、知的に見せるためだけに重ねた名称。
- 読みが長すぎる英語や、英単語を三語以上つないだ名称。
- 単なる侮辱や残虐さで傲慢さを表現する名称。
- 漢字名・英語読みのどちらにも数学用語が含まれない名称。

## 7. 命名時の確認項目

- 漢字名と英語読みの双方に、意味の通る数学用語が入っているか。
- その数学用語は、スキルの効果・演出・役割のいずれかと対応しているか。
- 「この結論は正しい」と断言するような、算術士の知性への自負が感じられるか。
- 既存の「無限級数（インフィニティ・フラクタル）」と並べたとき、数学者の魔術として一貫して見えるか。
