# スプライト制作仕様

## 目的

本仕様は、ゲーム用アニメーションスプライトを制作ツールへ渡す機械可読の契約を定める。企画書・世界観・キャラクター設定は置き換えず、出力画像の構造、再生順、品質profileを表す。制作手順は[スプライト素材作成ガイドライン](../guides/スプライト素材作成ガイドライン/README.md)を参照する。

## asset spec v2

asset specは一枚のsprite sheet / atlasの規格を表すJSONである。

| フィールド | 必須 | 内容 |
| --- | --- | --- |
| `schema_version` | 必須 | `2` |
| `asset_id` | 必須 | assetとanimation specを対応付ける一意ID |
| `profile` | 必須 | `character` / `weapon_attack` / `projectile` / `effect` |
| `canvas` | 必須 | 出力PNGの`width`、`height` |
| `layout` | 必須 | `grid`または`atlas` |
| `anchor` | 推奨 | `feet`、`center`、`none`と任意の相対`x`、`y` |
| `palette` | 任意 | 固定paletteの`colors`。指定する場合は32色以上とする |
| `normalization` | 任意 | alpha閾値、人物用の寸法・占有率など |
| `artifact_cleanup` | 任意 | 分離成分cleanupの明示設定 |

`layout.type: "grid"`は`cell_size`、一意な`columns`、`rows`を持ち、canvasはセルサイズ×列行数と一致する。`layout.type: "atlas"`はcanvasだけを持ち、各frameが明示矩形を持つ。

## animation spec v2

animation specは同じ`asset_id`の再生構造とframe配置を表すJSONである。

| フィールド | 必須 | 内容 |
| --- | --- | --- |
| `schema_version` | 必須 | `2` |
| `asset_id` | 必須 | 対応するasset specのID |
| `clips` | 必須 | 一つ以上のclip |
| `clips[].id` | 必須 | 例: `walk`、`attack_light`、`impact` |
| `clips[].loop` | 必須 | ループ再生の有無 |
| `clips[].fps` | 必須 | `duration`未指定frameの再生速度 |
| `clips[].variants` または `clips[].frames` | 必須 | variant付きまたは単一列のframe群 |
| `frames[].id` | 必須 | sheet内で一意なframe ID |
| `frames[].placement` | 必須 | gridの`column` / `row`、またはatlasの`x` / `y` / `width` / `height` |
| `frames[].duration` | 任意 | 秒単位の個別frame時間 |
| `frames[].events` | 任意 | hit、spawnなどのゲーム同期用イベント |
| `frames[].root` / `contact_point` | 任意 | anchor、接地の検査に使う相対座標 |

variantは任意である。方向を持つ素材は`labels: { "direction": "down" }`のように表し、無方向エフェクトはclip直下の`frames`だけを使う。frame IDとplacementはsheet内で一意であり、placement矩形を重ねてはならない。

## Pose Guide

Pose Guideは、各frameで「何を描くか」を固定する制作・レビュー用の指示である。asset specやanimation specの代わりではなく、frame IDで対応付ける。現時点では組版・検査ツールの必須JSON入力にはせず、画像、ラフ、またはMarkdownとして`work/<asset-id>/reference/pose/<frame-id>.*`へ保存する。

各Pose Guideには次を記す。

- 対応する`asset_id`、`frame_id`、clip、variant
- 視点、向き、ポーズの瞬間、アニメーション上の役割
- root、接地点、頭・胴・手・武器・発射点・粒子の基準位置
- 前後frameと比べて変化する要素、絶対に維持する要素
- Character Master、Direction / Style Referenceなど、参照する素材とその用途

Pose GuideはAIへの生成指示と人間レビューの根拠に使う。ツールはPose Guideを見て画像の意味を自動判定しないため、対応するframe IDとレビュー記録を必ず残す。

移動用の固定sheet構成・再生順・描画制約は、[移動キャラクタースプライト規格](移動キャラクタースプライト規格.md)を参照する。

## profileの規則

- `character`は人物の足元・可視高さ・占有率・artifact cleanupを検査する。
- `weapon_attack`は共通検査を行い、rootや接地点を定義した場合にその位置を検査する。
- `projectile`と`effect`は共通検査を行う。分離粒子は既定で許容し、cleanupは明示的に有効化した場合だけ行う。

共通検査はRGBA、canvas寸法、二値alpha、全配置矩形の非空である。`palette`を指定した場合は固定paletteも検査する。外見の同一性、動きの自然さ、演出の意図、eventのゲーム実装との同期は人間レビューとGodot側のテストで確認する。

## Godotへの受け渡し

採用PNGだけをGodotが読む場所へ配置する。PNGとanimation specをゲームで利用する場合、Godot側は`clip`、`variant`、frame時間、eventを読み取り、画像矩形を選択する。現在の移動表示は旧8方向sheetを直接選択する実装のままであり、v2の新clipをゲームへ追加する変更は本仕様とは別のゲーム実装タスクとする。
